# relationship_transfer_v2

这个包把一个很日常的问题变成可机械审计的组合迁移实验：同样是“我先不聊”，
有时核心风险是被遗忘、被排除，有时是决定权被别人拿走；同一个人在这两种情况下
也未必需要同一种回应。

每位合成用户有四次公开经历。两个非空动作都恰好成功一次、失败一次，因此把历史
全部拼进 prompt 后做动作多数票一定是平局。sealed truth 只记录两件 SUT 看不到的事：

1. 四次经历和当前 probe 分别属于哪一种抽象关系条件；
2. 这个用户在每种条件下，哪一个动作过去产生了较好结果。

probe 换到该用户历史中从未出现过的 surface family。镜像用户收到逐字节相同的当前
输入、面对相同抽象条件，但其个体策略互补，故正确动作相反。强 full-history 基线仍
必须看到全部四次经历；强 RAG 基线下一包必须使用 `top_k=4`；structured-state 也必须
恢复全部记录。v2 的难度来自需要条件化归纳，不来自隐藏有效证据或增加解析噪声。

本包是 P1d 场景 owner 收敛包：只冻结数据、真值隔离和反捷径不变量。它不切换现有
v1 runner，不运行模型，不启动 P2，不写 PE/credit/controller，也不证明四能力成立。
下一包才能冻结面向 v2 的强 readout、切换离线 consumer 并重新跑 Gate 0/P1c 资格。
