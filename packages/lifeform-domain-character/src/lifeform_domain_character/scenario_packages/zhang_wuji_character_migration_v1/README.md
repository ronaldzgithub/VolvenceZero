# Zhang Wuji Character Migration Package v1

This package freezes the reference acceptance surface for migrating Zhang Wuji
from reviewed fictional material into the `lifeform-domain-character` vertical.
It is not a prompt persona and does not contain verbatim novel text.

Artifacts:

- `manifest.yaml` declares the package, owner, rollback keys, and R14 regime
  alignment.
- `ssot_fragment.json` defines the character SSOT, migration paths, and the
  end-to-end arc.
- `scenes.yaml` provides positive and negative migration/evaluation scenarios.
- `test_suite.yaml` defines semantic routing and coherence acceptance checks.

The package is SHADOW by default. Runtime integration must continue to go
through `CharacterSoulProfile`, `ChapterLiveThroughLedger`, semantic owner typed
proposals, CaseMemory/ModificationGate, and read-only behavior-fidelity
artifacts.
