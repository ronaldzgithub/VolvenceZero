## Page 2｜我们是什么

> **本页要让投资人明白（编排注释，不上屏）：** “持续学习”究竟指什么，以及它与长上下文、RAG 和每轮修改基础模型的区别。

# 持续学习大语言模型：把经历真正变成模型下一次的能力

今天的大模型主要在部署前完成学习。上线以后，它可以读取更长的上下文、检索更多资料，却不会因为一次真实经历，稳定改变下一次的理解和行动。

**Volvence 的定义是：**

> 一种在部署后仍能从自然交互、行为和真实结果中持续更新关系状态、长期记忆与决策策略，并在安全边界内把有效经验迁移到未来交互和任务中的大语言模型。

它把原本需要人和外部工作流完成的闭环，逐步内化为模型能力：

```text
目标 → 感知 → 判断 → 行动 → 结果 → 学习 → 下一次做得更好
```

### “实时在线学习”不等于每轮修改全部模型权重

- **实时层**：每次交互后，立即更新该用户的关系状态、有效记忆和未完成事项；
- **会话层**：把多轮互动巩固为稳定经验，修正对这个人的理解；
- **共享层**：只有经过重复结果验证、评测与安全门的共性经验，才进入共享模型更新。

**个体经验实时生长，共享能力受控进化。**

## Page 3｜它首先解决什么

> **本页要让投资人明白（编排注释，不上屏）：** 我们的第一个突破口是 AI 与人的长期关系；关系和记忆不是附加功能，而是在线学习的直接结果。

# AI 与人之间，第一次拥有可以长期生长的关系和记忆

普通大模型的问题，不只是“记不住”。它往往：

- 只跟随用户最后一句话，人格和立场容易漂移；
- 能检索过去说过什么，却不理解关系为什么发生变化；
- 记住事实，但不知道哪次处理有效、哪次伤害了信任；
- 每次都需要用户重新补充背景，依赖复杂上下文工程；
- 得到结果以后，不知道应该改变哪项判断或策略。

Volvence 持续维护四类状态：

| 状态 | 模型持续理解什么 |
|---|---|
| **人** | 目标、偏好、能力、边界与长期变化 |
| **关系** | 信任、距离、承诺、冲突、修复与合适时机 |
| **记忆** | 事实、经历、结果，以及经验为何有效 |
| **决策** | 此刻应该倾听、追问、研究、建议、行动还是停止 |

因此，模型不只是“记得这个人”，而是会根据与这个人共同经历的结果，逐渐学会下一次怎样更好地理解、表达和行动。

**关系不是 Prompt 中的人设，记忆也不是聊天记录；它们是模型持续更新的内部状态。**

## Page 4｜我们的产品

> **本页要让投资人明白（编排注释，不上屏）：** Volvence 最终不是一堆模块和 App，而是三款定位、能力和部署边界清晰的模型产品。

# 一个持续学习模型家族，三档关系智能

| 模型 | 产品定位 | 核心能力 | EQ 等级 |
|---|---|---|---:|
| **Volvence Mini** | 端侧小型对话模型 | 基础情绪理解、个人事实记忆、稳定人格和轻量陪伴；适合手机、玩具、录音豆及私有终端 | **3 / 6** |
| **Volvence Relationship** | 中等规模关系模型 | 强关系建模、长期记忆、承诺与边界、复杂决策支持和高情商教练；面向陪伴、家庭、教育、婚恋、顾问与数字员工 | **5 / 6** |
| **Volvence Flagship** | 面向具身智能的旗舰模型 | 在 Relationship 能力之上理解环境、对象、行动与后果，处理长期任务、多主体关系和现实世界反馈 | **6 / 6** |

### EQ 六级体系的含义

- **3 级**：能识别情绪、保持人格、记住关键事实并进行基本关系回应；
- **5 级**：能理解关系状态、边界和承诺，长期陪伴用户解决复杂问题，并从结果中修正策略；
- **6 级**：能把人、关系、环境、任务和行动后果统一建模，在现实世界中保持关系连续性并承担长期目标。

> EQ 等级是 Volvence 的内部能力分级，需要用统一关系基准、长期对话盲测和同基底对照实验持续校准，不冒充第三方行业评级。

## Page 5｜开发者怎么使用

> **本页要让投资人明白（编排注释，不上屏）：** 这不是一套需要客户自己集成的复杂系统；开发者只调用模型 API，就能得到关系、记忆与持续学习能力。

# 像调用普通大模型一样调用，但不再自己拼装用户画像和学习管线

```http
POST /v1/responses
```

```json
{
  "model": "volvence-relationship",
  "user_id": "user_8f31",
  "input": "我最近总和孩子吵架，不知道该怎么办。"
}
```

调用方只提供自然交互和用户授权，不需要自行维护长 Prompt、人格设定、关系状态、记忆检索、反馈接口和训练工作流。

Volvence 在模型内部自动完成：

```text
加载用户状态与记忆
        ↓
理解目标、关系和当前处境
        ↓
回答 / 追问 / 研究 / 行动
        ↓
从后续自然交互和真实结果中继续学习
```

### 开发者得到的价值

- **更少上下文工程**：用户状态在推理前自动加载，不要求用户或开发者反复整理背景；
- **更稳定的人格**：身份、目标、关系与边界持续存在，显著降低多轮交互中的人格漂移；
- **更少无依据回答**：事实与推断分离，缺少关键证据时主动追问、研究或明确保留判断；
- **可解释、可审计**：重要输出可追溯到证据、状态、记忆、模型版本、动作和更新记录；
- **兼容现有系统**：开发者通过标准模型 API 获得能力，不必重新搭建一整套 Agent、RAG 和训练基础设施。

> Volvence 的目标是通过同基底长期对照，显著降低人格漂移和无依据回答；这不是对“完全消灭幻觉”的不现实承诺。

## Page 6｜核心技术壁垒

> **本页要让投资人明白（编排注释，不上屏）：** 实现持续学习，模型必须根据行动结果修正后续策略，这本质上进入强化学习；而真实世界强化学习必须同时解决反馈稀疏和泛化迁移弱两大难题，这正是团队二十年来持续研究的主动学习与迁移学习。

# 强化学习的两个瓶颈，正是我们二十年的研究方向

持续学习不是把更多聊天记录存起来，而是让模型根据真实结果，改变下一次判断与行动。这要求模型具备强化学习能力。

但强化学习进入真实世界，必须跨越两个相互关联的难题：**在反馈极少的情况下仍然能够学习，并把学到的能力泛化到新的用户、任务和环境。**

| 强化学习的难题 | 为什么现有方法困难 | 团队的长期研究 |
|---|---|---|
| **反馈与标注稀疏** | 真实结果延迟、昂贵且有噪声，不可能为每一步提供奖励和人工偏好标签 | **主动学习**：主动选择最有信息量的样本、问题与专家反馈，提高每一次标注的价值 |
| **泛化与迁移能力弱** | 在一个用户、一段关系或一个任务上学到的策略，换场景后容易失效或发生负迁移 | **迁移学习**：从历史任务估计可共享先验，让新用户和新任务不再从零开始，并提供样本复杂度保证 |

**主动学习解决“有限反馈应该问什么”，迁移学习解决“已经学会的经验怎样用于下一次”。**

### 已发表：主动学习的理论基础

| 核心论文 | 顶会 / 顶刊 | 解决了什么 |
|---|---|---|
| [`Active Learning with a Drifting Distribution`](https://proceedings.neurips.cc/paper/2011/hash/1e1d184167ca7676cf665225e236a3d2-Abstract.html)，Liu Yang | **NeurIPS（当时名 NIPS），2011** | 数据分布持续变化时，如何同时控制预测错误和标签查询数量 |
| [`Minimax Analysis of Active Learning`](https://jmlr.org/beta/papers/v16/hanneke15a.html)，Steve Hanneke、Liu Yang | **JMLR，2015** | 提出 Star Number，刻画低噪声主动学习的 minimax 标注复杂度 |
| [`Surrogate Losses in Passive and Active Learning`](https://arxiv.org/abs/1207.3772)，Steve Hanneke、Liu Yang | **Electronic Journal of Statistics，2019** | 用可计算的替代损失服务最终分类目标，为更可实现的主动学习奠定基础 |
| [`Bandit Learnability can be Undecidable`](https://proceedings.mlr.press/v195/hanneke23d.html)，Steve Hanneke、Liu Yang | **COLT，2023** | 给出 bandit 学习能力的理论边界，说明系统必须知道何时不能可靠学习 |
| [`Reliable Active Apprenticeship Learning`](https://proceedings.mlr.press/v272/hanneke25a.html)，Steve Hanneke、Liu Yang、Gongju Wang、Yulun Song | **ALT，2025** | 不确定时向专家求助，知道时自主行动，并刻画接近最少的查询次数 |

### 已发表：迁移学习的数学基础

| 核心论文 | 顶会 / 顶刊 | 解决了什么 |
|---|---|---|
| [`A Theory of Transfer Learning with Applications to Active Learning`](https://doi.org/10.1007/s10994-012-5310-y)，Liu Yang、Steve Hanneke、Jaime Carbonell | **Machine Learning，2013** | 从历史任务估计可迁移先验；随着任务积累，新任务的长期平均样本需求可接近提前知道先验时的水平 |
| [`Bounds on the Minimax Rate for Estimating a Prior over a VC Class from Independent Learning Tasks`](https://www.sciencedirect.com/science/article/pii/S0304397517308551)，Liu Yang、Steve Hanneke、Jaime Carbonell | **ALT，2015；Theoretical Computer Science，2018** | 给出从多个独立任务估计共享先验的 minimax 收敛上下界 |

迁移学习在 Volvence 中不是“把所有用户混在一起训练”。每个人的事实、关系和记忆保持隔离；跨用户迁移的是经过结果验证的共性结构、决策规律和学习先验。

### 最新研究：把理论推进到大模型持续学习

#### 1. `Simpler Active Learning with Surrogate Losses`

**Steve Hanneke、杨柳、赵江波｜团队最新论文稿件**

沿着 EJS 2019 的替代损失主动学习主线，进一步研究更简单、可实现的主动学习算法，让系统从海量自然交互中筛出真正值得确认和训练的少量样本。

> 状态口径：公开学术数据库尚无正式会议录页面；最终作者顺序、投稿与录用期刊或会议以正式论文为准。

#### 2. `Active Learning + RLHF`（拟发表研究）

把主动学习用于奖励模型训练：模型主动选择最有信息量、最不确定或风险最高的问题、候选回答和实际结果，优先请求用户、标注员或专家反馈，用更少偏好标签持续学习奖励、偏好与决策策略。

```text
主动学习：从稀疏反馈中选出最值得问的一条
                         +
迁移学习：把验证过的共性经验带到新用户和新任务
                         ↓
持续强化学习：用真实结果不断修正判断与行动
```

> 状态口径：该论文处于拟发表研究阶段；正式题名、作者、结果和发表渠道应在投稿或录用后更新。

**真正的技术壁垒，不是单独一篇论文，而是同一团队把主动学习、迁移学习、强化学习与持续学习模型工程连接成完整链条。**

## Page 8｜从关系智能走向通用人工智能

> **本页要让投资人明白（编排注释，不上屏）：** 关系模型不是一个垂直终点，而是让模型学会长期建模、从结果学习，并进一步泛化到任务和世界的起点。

# 先学会长期理解一个人，再学会长期完成一个任务，最终理解真实世界

### 第一阶段：关系模型

让模型保持身份、理解关系、积累记忆，并从长期互动结果中学习。关系场景提供高频、连续、真实且可观察的反馈，是持续学习最自然的起点。

### 第二阶段：任务模型

把同一套持续学习机制泛化到销售、研究、编程、运营、教育和企业 Agent：理解目标，调用工具，观察结果，识别哪一步有效，并把经验迁移到下一次任务。

### 第三阶段：世界模型与具身智能

把人、对象、环境、行动和后果统一进入模型状态，让模型不仅理解语言，也能预测现实世界会如何变化，并在物理环境中持续修正行动。

```text
关系中的持续学习
        ↓
任务中的持续学习
        ↓
环境与行动中的持续学习
        ↓
能够在时间中积累经验的通用智能
```

**通用人工智能，不只是知道得更多，而是进入现实以后，仍能持续理解、行动、承担结果并不断成长。**
