## 一句话

**基础模型让机器拥有知识；我们让机器拥有经验。**
在通用基底之上补一层今天缺失的能力：让模型在**部署之后**仍能从真实交互中形成可积累、可迁移、**可审计**的经验。

## 我们不是又一家"记忆公司"——三点差别

| | 常见做法 | Volvence |
|---|---|---|
| **记忆** | 推理前检索几段文本 | 参与当前状态的形成，具备写入、巩固、衰减、冲突处理与迁移边界 |
| **学什么** | 人来决定标什么、训什么 | 系统在稀疏、昂贵、延迟的反馈下自己挑最值得问、最值得学的那一小部分 |
| **变化** | 变强靠下一次训练 | 每一次变化都受治理：权限、版本、审计、隔离、回滚；评测只读不回流 |

**技术主张一句话**：我们不是在已有方向之外发明第六个孤立算法，而是把预测误差、内部控制、架构化记忆、涌现结构、有界修改**组织成同一个在线闭环**。这是最值得被追问的地方，我们主动把它放在最前面。

## 与蚂蚁的分工：我们不抢平台，也不抢场景

| 层 | 谁做 | 提供什么 |
|---|---|---|
| 连接与结算层 | **蚂蚁 / 支付宝** | 入口、身份、连接协议、支付与履约闭环、生态分发 |
| 行业场景层 | **生态内行业伙伴** | 场景知识、供给、履约能力、行业合规 |
| **认知底座层** | **Volvence** | 长期个体表征、经验沉淀、主动学习、受治理的在线更新 |

**核心协同论点**：持续学习最稀缺的不是数据量，是**有结果的数据**。绝大多数对话只有"说了什么"，没有"后来怎么样了"。而在支付与履约闭环里，是否采纳、是否成交、是否退款、是否复购、是否投诉，都是可观测的**延迟结果标签**——这是我们最需要、也最难自己造出来的监督来源。
我们回馈生态的是**长期关系的复利**：让 Agent 从"能用一次"变成"值得一直用"。

## 三个候选试点｜按可验证性排序

**A. 商家私域经营 Agent** — 长期客户经营、跟进时机、可审计接管 → 授权率、30/90 日留存、转化与复购、人工接管率
**B. 生活服务型长期顾问** — 育儿 / 健康 / 家庭生活决策的长周期陪跑 → 问题解决率、持续使用周数、建议采纳率与 1/7/30 日效果回流
**C. 企业内数字员工** — 客户成功 / 知识官 / 销售辅助 → 上岗通过率、单员工承载量、审计事件率、私有化 SLO

**明确不做**：个性化投资建议、信贷与风控的替代性决策、医疗诊断。结果信号很强，但风险与合规成本不匹配当前阶段。

## 节奏与边界

| 阶段 | 只验证 |
|---|---|
| 0–30 天 | 一次 60 分钟对齐：贵方内部对"长期交互 + 结果回流"的价值判断是否与我们一致、是否已有内部安排 |
| 30–90 天 | 单场景 PoC：授权 → 长期状态 → 决策 → 结果回流 → 受控更新全链路可审计、可删除、可回滚 |
| 90–180 天 | 对照实验：同场景 vs 通用大模型 + 记忆/RAG 基线，在留存或任务成功率上给出可重复差异，**或明确证伪** |
| 180–365 天 | 第二场景复用同一底座，单位经济成立，生态接入形态确定 |

**数据边界（写在系统里，不只写在合同里）**：数据归属不变 · 个体级事实进可删除的外部记忆而非权重 · 按范围删除并产出删除证据 · 跨租户硬隔离 · 评测只读 · **合作与融资解耦**。

## Ask 与合作形态

**本轮**：人民币 **6,000 万元**，投前估值 **5 亿元**。资金**不用于重训通用基础模型**，用于验证并放大持续学习闭环（研发 40% / 数据评测 20% / 标杆场景 20% / 基础设施 10% / 人才运营 10%）。

**三种形态可选**：① 战略投资 + 生态接入（首选）②纯生态合作（API / 私有化 / 联合试点）③ 联合研发（长期交互评测标准与开源轻量版共建）。

**18 个月要拿到的三件事**：学习效率优于随机采样与常规人类反馈流程 · 连续任务优于"大模型 + RAG/文本记忆"基线且遗忘受控 · 至少一个标杆场景证明持续学习提升任务成功率、留存或收入。

**杀死条件**：若严格消融下内部条件化不优于外部控制、主动学习不优于随机采样，我们主动收缩为产品型的长期记忆与决策支持公司。这条写在内部文档里，不是这次谈话才想出来的。
