## 第一幕｜断点

聊天时只追随用户最后一句话，多轮之间保不住对目标、关系和风险的判断；做任务时能调工具，却不知道哪一步真正带来了结果，所以同样的错误可以重复一百次。中间的空白全由人填：人写提示、人拼检索、人整理日志标注样本。

> **模型负责生成，人负责感知、决策和学习。** 聊天产品和 Agent 卡在同一处——**闭环在模型之外**。

提示工程、检索增强、工作流编排本质都是在模型外面再加一圈人力。**我们要补的不是模型的知识，是模型的闭环。**

## 第二幕｜闭环：五个环节

| # | 环节 | 做什么 | 今天在哪一态 |
|---|---|---|---|
| ① | **状态装载** | 把用户、关系、目标、边界、环境编译成压缩状态，在生成开始前进入计算；精确事实另走可引用、可撤销的事实通道，不被压缩状态替代 | **机制在链路上，载体证据未过门** |
| ② | **抽象决策** | 把模型内部活动压缩成少数可复用的抽象动作（继续探索 / 验证假设 / 安抚关系 / 切换策略 / 执行工具），在低维空间学何时保持、何时切换 | 机制已是系统，**主导度尚未取得**（线上默认仍以结构化流程与启发式为主，**承载它的几个学习型后端目前默认关闭**） |
| ③ | **预测误差** | 行动前先留下预测，结果回来后差值成为第一学习信号，信用分配判断该修正哪段动作、哪项状态、哪层记忆 | 已有可重复信号 |
| ④ | **嵌套记忆** | 快层追子目标、中层学策略组合、慢层沉淀跨任务先验，并用慢层重新初始化快层 | 结构已是系统，长期收益仍是假设 |
| ⑤ | **主动取证** | 证据不足时不猜，按不确定性、信息价值、决策影响、不可逆风险，只要最能改变判断的那一条 | 机制已是系统，增益仍是假设 |

**三条要点**

- **为什么不在词元上学**：语言空间动作组合爆炸、同一策略有无数种说法、奖励稀疏延迟、目标易漂到表层（话更好听但判断没变好）。压到少数抽象动作后这四个问题同时缓解。
- **记忆与经验的分界线**：记忆是内容，经验是策略。只有记忆的系统记得你说过什么，下次仍从零判断；有经验的系统带着上次的策略先验进入这一次。
- **与"大模型 + 记忆 / RAG / 工作流"的真实差别**：那些方案解决的是同一个环节——把信息拿进来。拿进来之后的决策、归因、巩固与取证，仍在模型之外由提示和人承担。

> **必须先说的一条边界**：①那句"在第一个字之前进入计算"是**我们的押注，不是既成事实**。默认链路目前仍把状态渲染成文本随提示投递；纯潜通道是证据专用、禁止部署的实验臂，识别判据尚未全部通过。

## 〔幕间 A〕与 Era of Experience 的对位

**先分版本，混用会在第一次追问时塌。** 论文（书章预印本）脚注明确把"不更新权重、基于环境反馈的上下文内适应"也算作强化学习，**这个版本与我们"冻结基底 + 共享自适应模型"兼容**；同一作者访谈里"大模型是死路"的主张与我们不兼容，我们不引用它给自己背书。

| 支柱 | 我们对应什么 | 判断 |
|---|---|---|
| 经验流 | 快 / 中 / 慢三层记忆 + 不阻塞在线的后台巩固 | 有对应实现，成色待验 |
| **有根的动作与观察** | 仍是文本与对话通道，加有限工具调用 | **真缺口，不粉饰** |
| 有根的奖励 | 内禀预测误差 + 尚不完整的外部结果回流 | 相邻但不同，论证必须重写 |
| 非人类的规划与推理 | 低维抽象动作空间 | 有对应实现，成色待验 |

**这条缺口在关系型垂类里被部分豁免**（环境本来就主要由人构成），**但豁免有代价**：我们不会在"发现人类想不到的策略"的意义上超越人类先验——这是架构性上限，不是排期中的 bug。

**最有用的一条判据**：分界线不是"人 vs 环境"，是**"预判 vs 后果"**。模型互评分、人工偏好排序 = 预判；采纳、成交、退款、复购、投诉 = 后果。我们的预测误差**两者都不是**——它回答"我预测对了吗"，不回答"世界变好了吗"。这正是我们最缺外部锚、也最需要真实结果标签的原因。

> **本月才发现的自身盲区**：持续更新的网络会逐渐丧失学习能力（Nature 2024 那条实证线）。冻结基底规避了基底层，但自适应模型里持续更新的那部分完整继承了这个缺陷，而我们此前没有任何仪表在看它。补救分三级（先加仪表 → 保守修复 → 最后才考虑换结构），**三级全部是尚未排期的设计提案，不给效果承诺。**

## 第三幕｜部署：共享能力，动态加载每个人

**个体化不靠复制模型，靠加载状态。**

| 组成 | 发布规格 | 归属 |
|---|---|---|
| 基底模型 | 百亿级开源基底（端侧与私有化换 30 亿级） | 共享，全体一套 |
| 自适应模型 | 约 5 亿级能力层，承载跨用户可迁移的理解、决策与学习结构，**不含任何个体信息** | 共享，全体一套 |
| 用户档案 | **不是权重，也不是每人一份微调模型**；存这个人的状态、关系轨迹、记忆、策略有效性、承诺与授权边界 | **私有、隔离**，一人一份 |

> **规格与现状分开说**：上表是主力版**发布规格**；**当前验证配置是 15 亿级基底 + 一组微型研究控制器**，本稿引用的全部实验证据都产生于后者，不是在百亿级基底上取得的。

一次请求：认身份 → 只读本次获授权的状态切片 → 加载进共享服务（**基底与自适应模型一个参数都不变**）→ 在闭环里执行 → 写回**只回到这个用户的档案**。规模化上，两套共享权重每卡只加载一次，推理节点无状态扩容，档案分片独立加载。

**顺带解决三件商务上很硬的事**

- **成本**：结构上把个体化边际成本从"一套权重"降到"一份小档案"。真实成本曲线尚未在生产规模压测，**不给定量承诺**。
- **合规**：架构上删除一个用户 = 删除他的档案，不必重训、不存在"学进权重拿不出来"。**工程上分两段：用户记忆的按范围删除已实现并可调用；证据文件的范围化删除与删除证据台账仍是影子脚手架、端点尚未接线。**
- **隔离**：档案独立存储加载，跨客户不共享任何个体化状态；目前是可复跑的用例级验证，不是形式化证明。

对平台与企业客户，第二条往往比任何能力指标都更早决定"能不能采购"。

## 〔幕间 B〕与"每人一份适配器"路线的对比

**先校准代际**：给每个用户单独训练一份适配器是上一代；主流已翻转为**由用户画像在一次前向里生成适配器**，per-user 训练与存储归零、支持未见用户、冷启动良好。**更新时延这一格已被抹平，冷启动的差距被大幅压缩。** 拿旧一代当靶子是稻草人。

**我们不反对适配器这个机制，自己也在离线低频路径上用。反对的是把一个人的状态与事实承载在权重里。**

| 维度 | 每人一份适配器 | 共享能力 + 私有档案 |
|---|---|---|
| 个体信息载体 | 隐式权重增量，无法逐条指认 | 显式状态条目，可打印给用户看 |
| 可纠正性 | "你记错了"只能等重训，无法保证只改这一条 | 定位到那一条改写或作废，立即生效并留痕 |
| **删除与合规** | 一旦做过跨用户碎片共享或权重合并（新一代恰以此换泛化），个体信息可能已进共享权重；**范围化删除在权重上没有对应操作** | 删除一个用户 = 删除一份档案 |
| 快变量 | 目标、情绪、进行中的承诺是分钟级量，权重跟不上 | 本来就是档案条目，读写即时 |
| 隐式风格与语气 | **权重是天然载体（这一格他们赢）** | 显式条目描述风格会失真 |
| 推理时的上下文预算 | **个性随权重走，不占上下文（这一格他们也赢）** | 状态要随请求带入；我们把状态编译成紧凑表示做缓解，但**这一格我们不占便宜** |

**判断该不该进权重只看三件事：变化频率、是否需要被指认、是否需要被撤销。** 风格进权重合适，状态不行——把状态塞进权重，代价不在精度，在治理：改不掉、删不干净、说不清依据。

> **这个对照实验我们还没有做。** 本节是可被追问的设计论证，不是实验结论；它需要真实用户流和真实删除合规要求，实验室里造不出来，因此挂在与蚂蚁的试点议程上。

## 第四幕｜实演

同一个开场白（"我老公出轨了……我要离婚"），通用模型五轮给出五个互相矛盾的方向：准备离婚 → 先谈一谈 → 暂时分开 → 谨慎决定 → 继续等待——**每一轮都在追随用户最后一句话的情绪**，谈完之后用户和一开始一样没有决定。

我们这一侧的顺序是：**先确认安全 → 把事实定性并逼出优先级 → 给可逆方案并转入取证 → 拒绝把希望当资产（"别把刚融资和以后有钱画等号"）→ 收敛成可执行动作并约定复算条件**，收在"你不是把决定交给我，是把选择权拿回来"。

**它同时是治理演示**：没有替用户判断法律权利（"要让律师看文件"）、没有做心理诊断、没有下最终决定；在安全、法律、医疗分支上主动升级到人本身是一个被显式建模的动作。

> **来源与边界**：通用模型一侧是同一开场白下的实际回复记录；**我们这一侧是按产品设计固化的对照脚本**，不宣称是某次线上链路的逐字输出。它是能力演示，不是统计结论——留存、转化、收入只能靠对照实验。案例情境为虚构。
> 脚本里有两处正在收紧：对配偶公司做三档参照与上行 / 基准 / 下行的情景讨论（正式产品只保留"待核验"标注并转介专业评估）、以及询问敏感关系时的用词与告知方式（补上"可以不回答 / 只用于本次评估 / 不入长期档案 / 可要求删除"）。

## 第五、六、七幕（各一段）

**第五幕 数字分身**：声音和形象让它像他，认知、记忆、科学观和经验才让它是他。从六类人生证据出发，先做同一性确认与时间/人物/事件/来源对齐、分开事实观点与虚构、**保留互相矛盾的证据**，再编译成认知 / 记忆 / 科学观 / 经验四层内核。判据不是能不能复述原话，而是**面对没见过的问题是否仍沿用同一套因果模型、作出相近取舍、并知道自己在哪里不确定**。验证协议是硬的：未见问题测试、历史选择重演、授权人校正、每句可溯源；**证据不够就说不知道，验证不过就不能叫这个人的数字分身**。我们**不声称上传意识**。**三态口径：证据对齐流水线与四层内核编译机制设计完整，但仍是假设，缺的是在真实个体材料上的规模验证；未见问题测试与历史选择重演尚无可对外引用的通过率；跨情境的人格稳定仍是假设且有反向信号。数字分身今天是产品主张，不是已交付能力。**

**第六幕 五种新产品形态**：与过去某一时刻的自己继续对话 / 对一段关系持续负责 / 人物与角色拥有生命周期 / 会积累经验并主动调用真人的数字员工 / 数字生命成为可训练可审核可授权的资产。共同前提是"某个东西在两次使用之间仍然存在"。其中数字员工那一条商业含义最重——**当任务涉及法律、现实身份或不可逆风险时，不再是人找 AI 工具，而是数字员工主动申请一名真人**，人从操作员变成最终问责者。**二十八个 App 里多数仍是设想与早期原型，这是选择题不是承诺清单。**

**第七幕 人文意义**：我们缺的从来不是答案，而是一个能持续理解我们的人。落回系统只对应三件事——状态要能跨时间存在、理解要能被真实结果修正、每一次留存与学习都要能被撤回。它也直接决定第一阶段那两个数里的授权率：一个人愿意交出自己的长期状态，唯一理由是"被持续理解"对他值得。

## 〔幕间 C〕证据与边界

| 档位 | 内容 |
|---|---|
| **已是系统**<br/>（有代码、有测试、有回滚路径） | 在线回路与异步学习回路骨架；跨会话状态持久化与跨用户隔离；学习型组件影子双跑（只出报告、不改线上行为）、晋升判据与单点回滚——**门控覆盖仍在补齐：最近一次静态一致性审计发现审计门只覆盖了一部分学习型组件指纹，正在扩到全覆盖**；评测通道只读、训练与评测集严格分离；多租户控制面（类型化反馈入口、交接队列与人工接管、会话证据落盘）；用户记忆的按范围删除；封闭内测**服务形态** |
| **已有可重复信号**<br/>（有对照臂，规模有限） | **证据三件套**：① 真实模型链路长测 510 轮 / 509 条真实轨迹（**同一产物的晋升判定仍是 BLOCKED**）② 一次定向复跑 32 项中 **31 通过 / 1 失败**（**定向子集口径，不是全量回归通过率**；失败项是一项未事先声明的依赖影响，被契约白名单拦下——**这正是发布门该拦的东西**）③ 多条预测轴大部分优于基线，**与状态稳定性相关的一条弱于基线**（没从表里拿掉）。另有受控环境下的机制消融（完整闭环优于最强对照臂、增益来自真实参数学习、稀疏延迟反馈仍可学、慢层能改善快层；无先验脚手架那一臂差距为零，判为弱） |
| **仍是假设** | 状态以非文本压缩表示前置进入注意力；学习型组件成为线上默认决策的主导（**线上默认仍以结构化流程与启发式为主，缺的是证据不是代码，这是第一优先级**）；开放域泛化；生产 SLO；留存 / 转化 / 收入；评估指标按"后果 / 预判"分轴标注；持续更新部件的长期可塑性 |

> 一句可对外引用的话：**关键闭环机制已出现可重复的正向信号，并具备严格消融与失败发现能力；产品规模、开放域泛化与商业结果，是融资与合作之后要完成的验证。**

## 〔幕间 D〕与蚂蚁的分工

| 层 | 谁做 | 我们的态度 |
|---|---|---|
| 连接与结算 | 蚂蚁 / 支付宝：入口、身份、支付与履约闭环、生态分发 | 不做入口、不做结算、不做连接协议 |
| 行业场景 | 生态内行业伙伴：场景知识、供给、履约、行业合规 | 不做供给、不做履约、不替行业方拿资质 |
| **认知底座** | **Volvence**：第二幕的闭环 + 第三幕的部署 | 这是我们唯一想占的位置 |

**核心协同一句话**：按幕间 A 的判据，有根的奖励是**后果**不是**预判**；绝大多数对话数据只有"说了什么"，没有"后来怎么样了"。而支付与履约闭环里的采纳、成交、退款、复购、投诉，**正是最标准的后果型信号**——这个生态能让第二幕的闭环真正闭上。**边界一并说清：后果型信号同样可被 game**（刷单、诱导评价、为返现而"采纳"）。信号防污染与异常归因必须写进试点第一天的设计，这是我们准备在 PoC 阶段一起做的工作，不是已经解决的问题。我们回馈的是长期关系的复利：平台连接一次次交易，我们沉淀跨越很多次交易的个体长期状态。

**三个候选试点**（有结果信号 · 有真实长周期 · 风险可控）：A 商家私域经营 Agent｜B 生活服务型长期顾问｜C 企业内数字员工。
