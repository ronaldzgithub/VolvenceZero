## 第一幕｜会回答，不等于会从结果中学习

聊天时，模型只追随用户最后一句话，保不住对目标、关系和风险的稳定判断。做任务时，它能调用工具，却不知道**哪一步真正带来了结果**。中间的空白由人填：人写提示、人拼检索、人整理结果、人标注重训。

> **模型负责生成，人负责感知、决策和学习。** 聊天产品和 Agent 卡的是同一处：**闭环在模型之外。**

## 第二幕｜把状态、决策、结果和学习放回模型内部

| | 环节 | 做什么 |
|---|---|---|
| ① | **状态装载** | 从经过审计的状态装载用户/关系/目标/边界/环境，**在第一个字生成之前**进入注意力计算；精确事实另走可引用、可追溯的事实通道，不被压缩状态替代 |
| ② | **抽象决策** | 把模型内部活动压缩成少数可复用的抽象动作（继续探索 / 验证假设 / 安抚关系 / 切换策略 / 执行工具）；**不在海量词元上试错，在低维空间学何时保持、何时切换** |
| ③ | **预测误差** | 行动前留下预测，结果回来后差值成为第一学习信号，信用分配判断该修正哪段动作、哪项状态、哪层记忆 |
| ④ | **嵌套记忆** | 快层追子目标、中层学策略组合、慢层沉淀跨任务先验，并**用慢层重新初始化快层** |
| ⑤ | **主动取证** | 证据不足时不猜，按不确定性/信息价值/决策影响/不可逆风险，只要**最能改变判断的那一条** |

> 别的方案能把信息拿进来；**拿进来之后的决策、归因、巩固与取证仍在模型之外**。我们把这五件事放回模型内部，共用同一条误差信号。

## 第三幕｜共享能力，动态加载每个人

**共享**：百亿级基底（语言/知识/推理/工具）+ 约 500M 自适应模型（怎样理解、怎样决策、怎样从结果中学习）
**私有隔离**：用户档案——**不是模型权重，不是每人一份微调模型**，只存这个人的状态、关系轨迹、记忆、策略有效性、承诺与授权边界

两套共享权重每张 GPU 只加载一次，每个用户只带一份小档案进同一批次；推理节点无状态扩容，后台学习不阻塞在线服务。

> **共享的是语言、决策与学习能力；隔离的是每个人的状态、关系与记忆。**
> 顺带解决三件硬事：**成本**（个体化不复制模型）· **合规**（删除用户 = 删档案，不必重训，不存在"学进权重拿不出来"）· **多租户隔离**（无跨客户经验串流）。

## 第四幕｜不替用户下结论，和用户一起把问题解决

同一个开场白："我老公出轨了，他是一家 AI 公司的老板，我要离婚。"

- **通用模型**：说要离就帮着离，说舍不得孩子就劝慎重，说恶心就劝搬走——四轮后四个互相矛盾的建议，用户还是没有决定。
- **Volvence**：先确认安全 → 让用户排优先级 → 列出关键未知 → 逐项取证 → 对公司股权做上行/基准/下行折价、**"别拿婚姻赌公司未来"** → 没看过文件就**"股权只能标成待核验"** → 问该问但不好问的（有没有新的稳定关系）→ 给出"先分开三个月"的可执行结论，并约定**三个月后用同一张表重算**。

> **"你不是把决定交给我，是把选择权拿回来。"**
> 边界同样是演示的一部分：法律交律师、不做诊断、不替用户下最终决定；安全、法律、医疗分支上**主动升级到人本身就是一个被显式建模的动作**。
> **它是能力演示，不是统计结论**——留存与转化要靠对照实验。

**仍是假设**：开放域泛化 · 生产 SLO · 留存/转化/收入。**线上默认决策仍以结构化与启发式为主——缺的是证据，不是代码**

## 与蚂蚁：三层分工

**蚂蚁**做连接与结算（入口、支付与履约闭环、生态分发）｜**行业伙伴**做场景大脑｜**Volvence**做认知底座（第二幕闭环 + 第三幕部署）

> **核心协同**：第二幕③说预测误差是第一学习信号——系统要的不是数据量，是**有结果的数据**。绝大多数对话只有"说了什么"，没有"后来怎么样了"；而支付与履约闭环里，是否采纳/成交/退款/复购/投诉都是可观测的**延迟结果标签**。**蚂蚁生态能让第二幕的闭环真正闭上。**

**三个试点**：商家私域经营 Agent｜生活服务型长期顾问｜企业内数字员工　**不做**：个性化投资建议 · 信贷风控替代决策 · 医疗诊断
**节奏**：0–30 天对齐 → 30–90 天单场景 PoC → 90–180 天对照实验（可重复差异**或明确证伪**）→ 180–365 天复用与规模化
**第一阶段只看两个数**：授权率 · 结果回流率
**数据边界**：归属不变 · 个体状态在可删除档案里不在权重里 · 按范围删除并出证据 · 跨租户硬隔离 · 评测只读 · **合作与融资解耦**
