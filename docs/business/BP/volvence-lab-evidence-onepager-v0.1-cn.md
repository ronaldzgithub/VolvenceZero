**定调**：今天的大模型会生成，不会从结果中学习。感知、归因、学习这三件事都在模型之外由人补，所以"记得更多"从来解决不了"学会了没有"。我们要补的是闭环本身——在**冻结的基座**上，让系统把自己的内部状态**命名读出**，只从**预测误差**产生的信用里学习，并在**有界、可回滚**的门控下决定何时干预。**这套范式已经在一个无法作弊的编程环境里被端到端证明，并且量化地打败了两个最强的对照：把历史全塞进上下文，和无脑一直干预。**

## 一、我们押的是一句可被证伪的话

> 在冻结的基座之上，一个有界的控制器可以只依靠**行动后果**，学会**何时**修改自己的判断——而且这件事必须比"把上下文堆满"更省，比"总是干预"更好，比"随机干预"更准，并且**随时可以一键回滚**。

这句话的每一个分句都被设计成可以判死。下面是判决结果。

## 二、Coding Lab：范式已在机械判决环境中闭环

**为什么选编程域先证**：判决权交给 pytest，不交给人也不交给另一个模型。通过就是通过，无法用文风讨好评委。隐藏的验收测试在评测时才注入，改测试无效。基座全程冻结——可训练参数 **0**。

**证据 ① 结构化经历 vs 堆上下文 vs 无记忆（240 个真实 API 编程回合，预注册 `f72dc17e…`）**

| 臂 | 任务通过率 | 上下文 token |
|---|---|---|
| **结构化经历（我们）** | **0.5125** | **882** |
| 全历史堆上下文 | 0.4625 | 9,027 |
| 无记忆 | 0.4000 | 0 |

三条预注册门同时通过：对无记忆的增益 bootstrap 5% 下界 **+0.0061**（正）；对全历史的非劣下界 **−0.0046**（阈值 −0.05）；**上下文 token 降到 1/10**（比值 0.0977）。

**最能说明"它在学"的一个读数**：环境里埋了一条没人告诉它的团队编码约定。结构化经历臂的违反率在一条任务链的前半到后半从 **0.50 降到 0.17**；全历史臂是 **0.53 → 0.50**，几乎不动。**不是记得更多，是学会了那条规矩。**

**证据 ② 学会"何时"干预（5 个 seed，838 条源轨迹，冻结 15.4 亿参数基座）**

| 策略 | 决策点 NLL（越低越好） |
|---|---|
| 不干预 | 2.4831 |
| **学到的择时门控（我们）** | **1.1760** |
| **一直干预** | **5.3183** |
| 随机干预 | 4.4834 |
| 全知上限 | 1.0123 |

**请先看"一直干预"这一行：它比"不干预"还差一倍多。** 这正是整个范式的要点——干预能力本身不值钱，**知道何时该干预**才是能力。六条预注册门全过：收敛改进 **2.3461**（阈 0.2）、对不干预的**最差 seed** 置信下界 **0.9239**（阈 0.3）、对一直干预 **4.6786**、对随机干预 **3.6472**、门控选择性 **0.9052**（阈 0.3）。

学到的策略还是可读的：信念过时的时候干预率 **0.03**，信念新鲜的时候 **0.92–0.95**。它自己学会了"什么时候该闭嘴"。

**证据 ③ 内部状态可读、学习信号只来自预测误差**：语义预测误差在 10,000 次置换检验下能显著区分任务成败（p ≈ 1e-4，两条独立读数各自成立）；跨进程重启后每条任务链恢复 976–979 条记忆。基座在整个强化学习期间可训练参数为 **0**，无自由偏置项，不干预时严格为零输出。

**证据 ④ 可回滚是被验证过的，不是承诺**：产物晋升经离线修改门审查，判决 `allow`，契约完整性 **1.0**、回滚韧性 **1.0**、回退依赖 **0.0**，回滚已实测。

## 三、Relationship Lab：同一方法论迁到关系域，规模已经就位

编程域的方法论正在被复制到关系域——把 pytest 换成会反应的用户，把隐藏编码约定换成个体隐藏的关系动力学。**当前规模**：112 个 root × 3 臂 × 40 个评估决策 = **13,440 条决策**，5,376 个互不相同的环境 seed，20,000 次配对 bootstrap，全链内容寻址冻结。

**当前可报的一条读数（有条件干预 vs 严格不干预）**：正向 outcome 率 **65.22% vs 4.64%**，差 **+60.58pp**；**同时 95% 置信下界 58.84pp**，预注册实用地板 5.00pp；5 个评估阶段（翻转后、修复中、修复后、久别重逢、混合压力）**全部为正**；安全侧同时更好 **8.17pp**（过度指导率反而下降）。

> **这条读数的口径必须随本页一起转出**：属 **development 档**，root 为**合成个体**而非真人，执行动作为**类型化动作**而非残差级干预。它的判词是"可以据此设计正式功效实验"，**不是**"效果已成立"。关系域的正式档证据、真人验证与生产接线均未授权。本页不据此声称任何四能力轴成立。

## 四、为什么这些数字可信：这台仪器会否决我们自己

投资人真正该问的不是"你们跑出了什么"，而是"你们跑不出来的时候会怎么办"。我们的答案有记录：

- 一条**预报能力**的判据没通过（p = 0.584），我们把 `false` 原样封存在正式报告里，没有降阈值。
- 关系域最大的那个数字（+36pp）**被我们自己判定无效**——因为对照臂的门控更新次数是 0，它等价于"不干预"，量的不是学习。报告状态直接写成"对比无效，不作主张"。
- 一次 112 个 root 的完整运行**被自己的校验器否决**，原因是账本第 6 行混入了墙钟时间戳，破坏了逐字节可重放性。跑完了也不要。
- 一条效率门第一次以 0.1088 未过 0.10，我们修的是仪器，然后**重新跑满 240 个回合**，而不是改阈值。

预注册在执行前锁定并按 sha256 冻结；全部产物内容寻址、可逐条复核。**在一个到处是精选 demo 的市场里，一台会 fail closed 的证据机器本身就是可定价的差异化——它也是上面第二节那些数字为什么值得信的唯一理由。**

## 五、这一轮买的是什么

编程域已经回答了**科学问题**："冻结基座 + 有界控制器 + 只从后果学习 + 可回滚门控"这条路走得通。关系域剩下的是**工程问题**，而且瓶颈已经被精确定位到可执行的修复项上——不是"继续研究"，是三件有名有姓的活加上真人锚点采集。

**这一轮买的是把编程域已经赢过一次的范式，在关系域完成同等强度的正式证明。** 科学赌注已经下过并且赢了；剩下的是把它搬过去。

**杀死条件**（写在内部文档里，不是这次谈话才想出来的）：若在严格消融下，关系域的有界干预不优于外部控制、择时不优于随机，我们主动收缩为一家产品型的长期记忆与决策支持公司——仍有真实业务，但不再宣称持续学习的完整命题。
