## 3. Codex（最终答复）

_2026-07-24T22:05:11.387Z_

结论：**最近这轮 ecology 已经不只是改环境和蚂蚁外壳，而是在实质性修正核心学习算法；但整个 ecology 项目的代码体量，仍有很大一部分是环境、训练设施和蚂蚁机制。**

可以分成三层看：

- 环境与蚂蚁机制：黄油、火柴、木棍、热感通道、路径积分、携食返巢、碰撞、curriculum、forced-return 等。这些主要让测试环境更丰富、更可解。
- 实验与工程设施：五臂 matched control、checkpoint/journal、冻结评估、probe、容量控制、schema 和可恢复训练。这部分代码很多，但不等于算法能力提升。
- 核心算法：近期真正重要的改动集中在 `vz-temporal` / runtime learning：
  - runtime replay 从错误的 signed prediction residual 改为真实 `action_payoff`；
  - 修复非终局 transition 被当作 terminal，补回 TD bootstrap；
  - 引入 `beta_t` 多步 segment credit，让稀疏结果能传播到前序动作；
  - 修复 action head 对 hidden-state 坐标的错误解释；
  - 修复 action-head bias 淹没状态条件策略的问题；
  - factor gradient 改为学习 centered state covariance，避免“隐式固定转向”；
  - 修复 coherent option exploration，并让不同 episode/body 不再重复同一探索噪声；
  - 修复冻结评估仍发生 owner 写入的问题。

所以，如果问“最近的工作重心”，我的判断是：

> **表面上 ecology 仓库改动很多在环境和实验 harness，但最近连续定位出来的 blocker，大多已经落到了 ETA/Internal-RL 的核心控制与信用分配实现。**

不过现在还不能说“核心算法已经被证明显著改善”。证据更准确地说是：

- 近场闭环明显恢复；
- 若干结构性算法 bug 已被实验证实并修掉；
- state-conditioned mapping 已经出现，但曾被固定 bias 淹没；
- 中距离 butter 仍然失败；
- learned arm 尚未证明优于 no-optimize；
- 正式 P1 仍然是 `BLOCK`。

因此当前状态是：**核心算法得到了不少真正的修正，但这些修正目前属于“恢复正确学习条件和消除假学习”，尚不是已经验证成功的新算法突破。** 下一轮新版本正式复跑，特别是 `learned vs no-optimize` 的冻结 paired evaluation，才会回答这些核心修正确实带来了多少学习增益。
