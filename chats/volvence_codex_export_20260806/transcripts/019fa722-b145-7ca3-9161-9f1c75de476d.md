## 5. Codex（最终答复）

_2026-07-28T05:15:35.263Z_

已解决。根因不是 macOS 26 版本号，而是 Codex 沙箱阻止了 GPU/Metal 访问。

同一个 Python 在沙箱外验证成功：

```text
mps_built True
mps_available True
device_count 1
tensor([1.], device='mps:0')
```

机器、arm64 PyTorch wheel 和 M4 GPU 都正常。后续 MPS 任务应在普通终端运行，或在 Codex 中授权沙箱外执行；`SYSTEM_VERSION_COMPAT` 和 `PYTORCH_ENABLE_MPS_FALLBACK` 都不能解决设备枚举权限问题。PyTorch 官方仓库也记录了这一相同现象：[MPS unavailable inside Codex sandbox](https://github.com/pytorch/pytorch/issues/177819)。

这次没有修改仓库代码，也不需要转 CPU 证据。
