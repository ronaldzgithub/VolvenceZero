## 3. Codex（最终答复）

_2026-07-24T21:38:02.158Z_

不用现在跑 `run_companion_bench_p1.sh`，除非你准备正式生成 CompanionBench P1 跑分证据。

它和蚂蚁没有代码/数据冲突，但可能有算力冲突：

- Companion 默认使用 `VZ_SUBSTRATE_DEVICE=mps`，还会启动 9 条评测轨道，运行很重。
- 蚂蚁默认是 CPU；只有显式使用 `--device mps` 或设置 `VZ_TENSOR_DEVICE=mps` 才占 MPS。
- 如果蚂蚁正在用 MPS，不建议同时跑 Companion，容易争抢统一内存、触发 swap/OOM，并让两边速度明显下降。
- 最稳妥是等蚂蚁完成后再跑 Companion。

只是检查配置可以安全执行，不会启动 MPS 或产生付费 API 调用：

```bash
bash run_companion_bench_p1.sh --dry-run
```

正式运行前还要确认 `.local/llm.env`、本地 Qwen 权重和至少 15 GiB 空闲磁盘。若一定要并行，可以让 Companion 走 CPU：

```bash
VZ_SUBSTRATE_DEVICE=cpu bash run_companion_bench_p1.sh
```

但会慢很多。综合建议：现在先不跑，蚂蚁结束后再单独跑 Companion。
