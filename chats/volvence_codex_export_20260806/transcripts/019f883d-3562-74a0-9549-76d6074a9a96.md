## 1. 这次实验想证明什么

ecology-v2 的问题定义是清晰的：

- 黄油：正价态，蚂蚁应学会接近、拾取、带回巢穴。
- 火柴：负价态，蚂蚁应学会避免有害热区；如果被放入热区，应尽快逃离。
- 木棍：中性物理约束，没有负奖励，只要求在障碍存在时仍能完成任务。
- Composite：同时存在食物、木棍和热源，检验能力组合。

设计上没有向控制器泄露对象坐标、目标方位或推荐动作。环境只发布局部食物、巢穴信息素、热量变化和 pickup/delivery/heat 等事件，让行为从 learned `z_t` policy 产生。这一点符合实验目标，见[实验规范](/Users/mengfu/Documents/GitHub/volvence/docs/specs/digital-ant-embodiment.md:236)。

训练过程采用：

1. 共享初始 checkpoint。
2. 训练前做左右成对探针，确认 food/heat 信息能传到动作。
3. Butter：near → medium → far。
4. Burning match：near forced-escape → medium → far。
5. Composite：near → medium → far。
6. 已学阶段定期 interleave replay，抑制遗忘。
7. 从完全相同的初始状态和训练布局分叉四个训练臂：

   - learned
   - no-optimize
   - local-valence-off
   - segment-credit-off

8. validation 与 held-out 均关闭学习，检查泛化而非继续适应。
9. 最后经过 15 个 promotion gates，任一个失败都 BLOCK。

这个框架本身是严谨的。尤其好的地方是：

- no-optimize 确实没有持久化策略更新。
- 各臂重放完全相同的训练 schedule。
- held-out seed 与训练 seed 分离。
- 不用训练 reward 代替行为指标。
- checkpoint 恢复、损坏回滚、replay lineage 都有审计。
- 木棍已经改成真正中性，不再靠“撞木棍/避木棍奖励”过门。

## 3. 训练过程发生了什么

### Butter

训练汇总：

- 5 pickups
- 4 deliveries
- mastery 判定通过

但这些成功几乎全部来自 near episode：

- Near：5 pickup / 4 delivery
- Medium：0 / 0
- Far：0 / 0
- 后续 interleave：1 pickup / 0 delivery

这说明它学到的更像是“食物出生得很近时可以碰到”，并没有证据证明学会了中远距离觅食和回巢。

当前 mastery 是跨 near/medium/far 累积计数：只要总 pickup ≥2、delivery ≥1 就通过。于是 near 的成功可以完全掩盖 medium/far 的失败。这是本轮最重要的实验设计缺口之一。

### Burning match

训练汇总：

- 8 pickups
- 2 deliveries
- 3 heat entries
- 7 heat escapes
- mastery 通过

但 near episode 是 forced escape：蚂蚁直接出生在热区内。这非常适合建立初始负价态样本，但它也让 escape mastery 容易通过。

到了 held-out route-avoidance：

- 只有 1 pickup
- 0 delivery
- 0/3 seed 完成完整任务
- 有害热暴露率很低，约 0.69%

低热暴露不能单独解释为“学会避热”，因为蚂蚁同时也没有到达食物。它可能只是没有接近任何关键对象。

### Composite

训练结果：

- 0 pickup
- 0 delivery
- 54 次木棍接触
- 1 次进入热区、1 次离开
- mastery 明确失败

这是最干净的失败信号：组合场景没有形成任务闭环，而且木棍成为明显瓶颈。

值得注意的是，木棍接触不计入奖励或扣分，因此这不是 reward 设计惩罚了蚂蚁；而是策略在有障碍时无法保持觅食能力。

## 4. Held-out 的真实表现

各场景汇总如下：

| 场景 | Learned | 关键对照 | 判断 |
|---|---|---|---|
| Butter only | 1 pickup / 0 delivery | cold 2/0，no-opt 2/0 | learned 更差 |
| Butter + stick | 0/0，11 contacts | 所有臂几乎都失败 | 障碍上下文不鲁棒 |
| Heat route | 1/0，5 harmful ticks | cold 2/1，37 ticks | 热暴露较少，但任务失败 |
| Forced escape | 12 escapes，40 harmful ticks | no-opt 12 escapes，38 ticks | 会离开，但没有优势 |
| Composite | 0/0，16 harmful ticks | 所有臂 0 delivery | 完全未形成组合能力 |

15 个 gate 只通过了 4 个：

- policy_changed
- no_optimize_policy_stable
- action_smoothness
- checkpoint_archive_roundtrip

其余 11 个失败。

这意味着目前得到的是“策略参数确实变了”，而不是“策略行为变好了”。

## 5. 最关键的机制性问题

### 5.1 感觉进入 latent，但没有稳定进入动作

训练前 probe：

- food turn delta：0.0035
- heat turn delta：0.0117

训练后：

- food turn delta：0.0036，仍存在
- heat code delta：0.0998，说明热信号进入了 latent
- heat turn delta：0.0，左右热源产生完全相同的转向

也就是说：

```text
heat sensor → latent code：通
latent code → directional motor action：断
```

这不是简单的“感知不到热源”，而是训练把原来存在的 heat directional action sensitivity 消掉了。可能涉及：

- causal action head 权重塌缩；
- latent 变化落在 motor readout 的零空间；
- PPO 更偏好低转向、低风险的局部最优；
- 多任务训练覆盖了 heat 的方向响应；
- turn-local mixture 或动作裁剪抹平左右差异。

这是下一轮最应该优先定位的地方。

### 5.2 Temporal controller 没有真的工作起来

15 个 learned held-out 轨迹中：

- `switch_count = 0`
- `longest_segment_length = 24`

24 正好是强制 segment 上限。说明 segment 主要是被 timeout 关闭，不是被真实 beta switch 关闭。

所以虽然 segment-credit 管线是 ACTIVE 的，但高层 temporal abstraction 没产生行为状态切换。实际更像：

```text
固定抽象状态
  → 连续小幅度动作
  → 24 步超时闭合
  → 再继续相似动作
```

这也解释了为什么动作非常“平滑”——平均 turn delta 约 0.02–0.04，远低于 0.55 门槛——但平滑并不等于聪明。这里的 smoothness 更接近策略僵化。

而且 segment-credit-off 的综合分数是 5.09，高于 learned 的 4.53。当前没有证据证明 segment credit 带来收益。

### 5.3 训练 mastery 被偶遇事件高估

目前 mastery 按整个阶段的 aggregate event count 判断，而且是 4 只蚂蚁合并统计。这会产生三种假阳性：

- near 成功掩盖 medium/far 失败；
- 一只蚂蚁的成功掩盖其他个体失败；
- forced-start escape 掩盖主动 route avoidance 失败。

因此“butter mastered”和“burning_match mastered”只能表示训练数据中出现过足够事件，不能表示策略掌握了能力。

更合理的 mastery 应至少要求：

- medium、far 分别达到最低成功率；
- 按 seed/episode 成功，而不是只累积事件；
- 报告每只蚂蚁的成功覆盖率；
- forced escape 与主动避热分别判断；
- delivery 必须跨多个布局出现。

### 5.4 Learned 没有超过对照

综合 outcome：

- learned：4.53
- valence-off：4.02
- segment-credit-off：5.09

paired CI：

- 对 cold：learned 显著偏低
- 对 no-optimize：learned 偏低
- 对 valence-off：区间跨 0
- 对 segment-credit-off：区间跨 0

因此现在不能主张：

- optimization 带来行为增益；
- local dense valence 有因果贡献；
- segment credit 有因果贡献。

还有一个命名上的注意点：`local-valence-off` 只关闭连续的 food/home/heat shaping，pickup、delivery、heat entry/escape 等稀疏事件奖励仍然存在。因此它更准确的名字应是 `dense-local-shaping-off`，不是完全的 ecology reward-off。

### 5.5 冻结评估仍有状态变化

Replay 的硬指标其实很好：

- settlement coverage：1.0
- lineage coverage：1.0
- drop：0

但两个 learned held-out 运行中 temporal-learning fingerprint 发生变化：

- butter-only，seed 307
- forced-escape，seed 101

评估配置已经设置 `learning_enabled=False`，所以这说明至少有一块被 fingerprint 覆盖的 temporal state 仍在评估期变化。它可能是：

- 本应归类为运行时状态，却被包含进 learning fingerprint；
- 或者确实存在 evaluation leakage。

在搞清楚之前，held-out 的严格冻结性不能成立。

## 6. 方案本身还缺什么

按照项目自己的正式 claim 标准，本轮还缺少：

- ≥5 held-out seeds；
- 8-ant 正式规模；
- PE-off；
- ETA-off；
- FixedRule baseline；
- end-to-end RL baseline；
- random floor；
- per-ant 而不是 colony aggregate 的行为覆盖；
- 中远距离 mastery；
- 多次独立训练 run，而不仅是多个 evaluation seed。

目前的多个 held-out seed 只测同一个 trained checkpoint 的地图泛化，不能估计训练本身的随机性。正式结论最好至少有 3–5 个独立 training seeds，每个再跑 held-out layouts。

另外，[formal v3 partial 日志](/Users/mengfu/Documents/GitHub/volvence/research/ant/results/ecology_formal_v3.partial.trainlog.txt)仍包含独立 `wood_stick` 训练阶段，与当前 v3 “木棍只是中性组合上下文”的规范不一致。因此它属于旧语义的中断运行，不应继续接着跑或与当前 neutral-v2 结果合并。

## 7. 我建议的下一轮顺序

现在不适合直接把预算扩大到 8 ants × 5 seeds × 120 rounds。因为当前失败不是纯粹的统计功效问题，扩大预算很可能只是更昂贵地复现塌缩。

### P0：先做三个短机制实验

1. Action-head regression

   在每个训练 episode 后立即运行 food/heat 左右探针，记录：

   - code delta
   - turn delta
   - 转向符号是否正确
   - causal action-head 参数范数
   - motor readout 对 latent 的局部 Jacobian

   目标是定位 heat turn sensitivity 在哪个阶段消失。

2. Temporal switch audit

   用固定可控轨迹制造 food→carry→home、cold→hot→escape 状态变化，确认：

   - beta switch 是否触发；
   - 哪个阈值阻止切换；
   - segment 是事件闭合还是 24-step timeout 闭合。

3. Frozen-evaluation audit

   对一次 10–20 step evaluation 前后逐 owner 比较 fingerprint，找出具体哪个 owner/state 在 `learning_enabled=False` 下变化。

### P1：把课程门槛改成真正的能力门槛

- Near 只用于 bootstrapping，不计入最终 mastery。
- Medium、far 必须各自在多个 seed 成功。
- Butter 要求 pickup 与 delivery 成对完成。
- Heat 分成 forced escape 和 route avoidance 两个 mastery。
- Composite 必须先在无热/有木棍条件下通过，再加入热源。
- 统计 per-ant success coverage。
- 训练失败立即停止后续对照臂，节省计算。

### P2：单能力先过，再跑组合

建议顺序：

```text
Butter medium/far 泛化
    ↓
Heat 左右响应与逃逸时延
    ↓
Butter + neutral stick
    ↓
Butter + heat
    ↓
完整 composite
```

只有前三个短实验确认 action sensitivity、真实 switch、冻结评估都正常后，再运行正式 8-ant / 5-seed 版本。

## 最后的结论

这轮最值得肯定的不是蚂蚁“学会了”，而是评估系统没有把参数变化、近场偶遇和漂亮的平滑轨迹误报成智能。

当前差距可以浓缩为一句话：

> 我们已经把 reward 送进了学习系统，也确实改变了策略参数，但尚未把价态稳定地变成具有方向性、可切换、可泛化的行为策略。

我认为下一步第一优先级不是调 reward，也不是加训练轮数，而是沿着 `heat sensor → latent → causal action head → turn` 和 `state change → beta switch → segment credit` 两条链做逐拍诊断。只要这两条链打通，后面的 curriculum 和规模化才有意义。
