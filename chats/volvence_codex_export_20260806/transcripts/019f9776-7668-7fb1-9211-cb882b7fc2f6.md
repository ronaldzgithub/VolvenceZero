## 2. Codex（最终答复）

_2026-07-25T04:11:15.560Z_

还有不少，按沟通流程可以这样分：

**开始 / 定位**
- `frame`：建立语境、框架
- `contextualize`：补充背景
- `anchor`：给对话一个落点
- `align`：对齐目标或理解
- `scope`：限定范围
- `prime`：预热、铺垫

**理解 / 澄清**
- `clarify`：澄清
- `probe`：追问、探询
- `surface`：把隐含信息显性化
- `reflect`：复述/映照对方意思
- `paraphrase`：换句话说
- `confirm`：确认
- `disambiguate`：消歧

**推进 / 引导**
- `prompt`：提示对方回应
- `cue`：给提示信号
- `nudge`：轻推
- `guide`：引导
- `redirect`：转向
- `bridge`：承接并过渡
- `transition`：转换话题或阶段
- `sequence`：安排先后顺序

**说服 / 表达**
- `position`：定位观点
- `emphasize`：强调
- `reframe`：重新框定
- `contrast`：对比
- `validate`：认可对方感受/判断
- `acknowledge`：承认、回应
- `challenge`：提出挑战或异议
- `counter`：反驳

**节奏 / 控制**
- `hold`：暂停、稳住、不急着推进
- `pause`：停顿
- `defer`：暂缓
- `contain`：收束情绪或范围
- `pace`：控制节奏
- `de-escalate`：降温
- `summarize`：总结
- `close`：收尾

**行动 / 转化**
- `call to action` / `CTA`：行动号召
- `invite`：邀请
- `ask`：提出请求
- `offer`：给出选项/帮助
- `recommend`：建议
- `commit`：承诺下一步
- `handoff`：交接
- `follow up`：跟进
- `next step`：下一步

如果你是在给某个沟通系统/agent 设计标签，我会优先选这一组核心动词：`frame`, `clarify`, `reflect`, `validate`, `probe`, `reframe`, `guide`, `hold`, `summarize`, `close`, `invite`, `commit`。
