# 03 · 对 Volvence 的借鉴意义

> 裁决基调：这是一篇**感知基底层**的论文，与 Volvence 的认知/关系层隔了一个抽象层级。它的价值不是"可搬运的模块"，而是在一个完全独立的域（视觉传感）、独立的团队（清华 CBICR）、独立的物理约束（芯片带宽/功耗）下，**再次收敛到我们已经采用的四条设计原则**——互补分解、SSL 建立标准表示、owner 生成 SSOT 供下游消费、学习出的条件化门控。同构证据的价值在于降低"我们的 R 不变量是偶然偏好"的概率；同时它有三处明确**不可类比**，误引会污染我们的证据链。

---

## 1. 同构证据（支持既有设计，可入外部证据索引）

### 1.1 "差分信号与状态信号分开采样、由下游学习融合" ↔ R-PE + R8

Tianmouc 最深的一刀：AOP 测**变化量**（时间差分 TD、空间梯度 SD，高频稀疏），COP 测**绝对量**（完整 RGB，低频精确），两者信息互补完备，融合交给学习。这与 Volvence 的信号分层同构：

| Tianmouc | Volvence |
|---|---|
| AOP（TD/SD，10,000 fps，稀疏多比特差分） | Prediction Error / 残差流 readout（一级原始信号，逐 turn） |
| COP（RGB，30 fps，完整强度） | 不可变快照（owner 发布的完整语义状态，慢通道） |
| IGFNet 学习融合，门控条件于传感状态 | 控制器层消费 PE + 快照，条件化决策 |

论文从**芯片物理约束**（带宽不允许把所有信息都以最高频采） 推出这个分解；我们从**认知架构约束**（PE 是一级信号、快照是唯一通道）推出同构分解。两条独立路径到达同一点，是 R-PE"变化量信号必须一级采集，不能事后从状态序列重建"的域外印证。

### 1.2 e-VGT 是 SSOT 哲学的感知版 ↔ R8 + steering-human-anchor

论文里所有下游消费者——深度伪标签生成、VIS 人工标注、下游感知模型——**都消费内部模型发布的标准表示 e-VGT，没有一个直接消费原始传感数据**。且有实证：在 e-VGT 上标注比在原始 RGB 上标注错误更少（Extended Data Fig. 7b）；DAM-V2-L 零微调即可在 e-VGT 上产生尺度对齐深度（Extended Data Fig. 5）。

这正是我们的两条既有约束在感知域的重演：

- **R8**：唯一 owner（internal model）负责生成标准表示，consumer 不从原始数据各自重建——"谁拥有数据谁负责描述"；
- **`docs/specs/steering-human-anchor.md`**：人类标注在 owner 发布的锚上做，不在原始 token 流上做。论文给了一个可引用的定量理由：**在标准表示上标注/监督，质量更高、成本更低**。

### 1.3 SSL 建立冻结标准表示 → 下游冻结复用 ↔ R2 + R13

Bottom-up 全程自监督（零标注、零 reward）建立 internal model；top-down 阶段**整体冻结** encoder + fusion（含记忆库），只训下游 decoder。这是 NL"SSL 压缩先行、慢频建基底"的前半段在感知域的完整实例：

- 监督信号来自**数据内禀物理一致性**（梯度域与强度域必须一致，Poisson 方程），不是外部 judge——与 R12"评估只读、不做学习源"兼容的监督来源选择；
- 表示学习（慢、一次性）与任务适应（快、每任务）被冻结边界干净隔离——R2 的"稳定基底 vs 自适应层"。

### 1.4 学习出的条件化门控，且门控可读出 ↔ R3/R4 + Readable 轴 + no-keyword-matching

`M·E + (1−M)·F` 的门 M 是从传感状态特征**学出来**的逐像素 sigmoid，不是任何手写规则（没有"若过曝则用 SD 路"的 if/else）；且 M 可直接可视化读出（recon rate / flow rate）。这是两条仓库规则的域外印证：

- `no-keyword-matching-hacks.mdc`：有意义的路由/切换应当从数据中**涌现**（此处 = 从退化免疫训练中被逼出来），不是预定义映射；
- Readable 轴：内部控制状态（这里是通路信任分配）天然应可命名读出——论文直接把 M 图当解释工具用。

## 2. 可移植机制（具体做法层面，按可操作性排序)

### 2.1 退化免疫融合训练（最值得移植的一条）

训练时对两条输入通路**分别独立**随机 patch 遮挡 + 加噪（`dataAug`），使门控层的唯一稳定解是"按条件分配信任"。鲁棒性是被结构性逼出来的，不是数据堆出来的。

**Volvence 落点**：任何"多源融合读出"的控制器训练都可采用——最直接的是 vz-memory 的 CMS 多层读出融合与 vz-temporal metacontroller 对多上游快照的汇聚。若未来预注册"记忆读出鲁棒性"类实验，训练期随机屏蔽一个 stratum/一个上游 slot 的方案有了外部先例。**边界**：这是训练管线机制，不改变运行时契约；不要把它实现成运行时的随机丢快照（那会违反契约确定性）。

### 2.2 记忆读出 = 残差注入 + 方差约束 + 一键关断

`new_z = z + mem_readout * mem_scale`，训练加 std≈1 约束防坍缩，`mem_scale=0` 即完全旁路（消融开关）。与我们 steering 三件套的"norm cap、无 free bias、strict noop、单字段回滚"是同一设计语汇。**落点**：State-KV / CMS readout 若引入可学习记忆槽，此实现（XMem 式 affinity readout + 残差 + 方差约束）是一个经同行评审系统验证过的参照实现。

### 2.3 "基础模型零微调可消费"作为快照标准性的判据

e-VGT 的质量标准不是重建 PSNR，而是**通用基础模型（DAM-V2）零微调能否直接在其上工作**。移植为我们快照 Readable 质量的可操作判据：owner 发布的快照描述，是否"标准"到一个未见过本系统的通用 LLM 零 prompt 工程即可正确消费？这可以变成快照契约测试的一类断言（语义可消费性测试），比"字段齐全"更强。

### 2.4 结构先验做自监督 teacher

用物理/结构一致性（Poisson、光流一致性、时间积分）当监督，替代人工标注与模型打分。**Volvence 对应物**：对话域的内禀一致性约束——承诺与执行的一致性（`commitment` vs `execution_result`）、时间引用一致性、跨 turn 状态连续性——原则上可充当 SSL 目标而不触碰 R12（它们是数据内禀约束，不是 judge 分数）。这是一个值得记录的方向，但目前不建议立项：我们的 Learnable 轴主线是 PE→credit，先不增加第二种学习源的复杂度。

## 3. 明确不可类比（误读警告）

1. **它的记忆不支持 Appendable**。128 槽记忆库训练后冻结，部署时零写入——是"场景状态字典"不是在线记忆。**禁止**引用本篇为"在线记忆/持续学习"的证据；它对 CMS 的价值仅限 readout 机制参照（§2.2）。
2. **它的 top-down 不是运行时 steering**。工程形态是训练期表示复用 + 伪标签蒸馏；运行时唯一的自适应是门控 M（且属于 bottom-up 模型内部）。与我们 Steerable 轴的"运行时有界条件化残差干预"是不同层的东西，不能互为证据。
3. **只覆盖 NL 的 SSL 半边**。无 RL、无 credit assignment、无多时间尺度在线适应、无自修改——对 R9/R10/R13 的 RL 侧、R15 无任何支持。
4. **COP/AOP ≠ World/Self 双轨**。前者是功能分离（认知 vs 行动，Goodale-Milner），后者是语义隔离（R7）。松散类比可以启发，不能当论据。
5. **感知域结论不自动外推**。"互补分解 + 门控融合"在视觉上成立依赖 TD/SD/RGB 的信息完备性有物理定义；对话/情感域的"信息完备分解"没有等价物理保证，任何移植主张需要自己的证据。

一句话总结：**这篇论文用一颗芯片和一个自监督框架，在感知域独立重演了我们在认知域的四条公理（信号分层、SSOT、冻结基底、涌现门控），它最大的用处是作为"这些公理不是我们的偶然偏好"的域外证据——前提是引用时永远带上它的三条边界（记忆冻结、top-down 非运行时、无 RL 半边）。**
