# 访谈思想拆解：从口号到可检验命题

## 1. 访谈的完整论证链

Sequoia 访谈不是几个孤立判断，而是一条相互依赖的论证：

1. 互联网文本与人类反馈是有限、外部生产的数据；
2. 当前大模型在部署后通常冻结，无法把行动后果沉淀为新的长期内部能力；
3. 如果直接长期更新普通深网，它又会逐渐丧失学习新事物的能力；
4. 因此需要从一开始就为持续学习设计的学习器；
5. 该学习器通过参数级步长和 generate-and-test 保持可塑性；
6. 它从连续经历里发现跨时间抽象，用抽象建立模型并规划；
7. 智能的边界由真实世界持续扩大，而不是由人类预先制作的数据集决定。

这条链中，第 3 点有 Nature 直接证据；第 5 点有小规模机制证据；第 6 点是 Alberta Plan / OaK 的研究路线；第 1、2、7 点主要是范式判断。把这些证据层级混为一谈，容易得出“论文已证明完整持续心智”的错误结论。

## 2. “苦涩的教训”：不要手工编码智能的上限

### Sutton 的主张

[The Bitter Lesson](https://www.incompleteideas.net/IncIdeas/BitterLesson.html) 从国际象棋、围棋、语音和视觉的历史归纳：长期成功的方法通常是能随计算扩展的搜索与学习，而不是把人类对领域的理解直接编码进系统。访谈把这条原则扩展到数据生产：如果模型的经验仍由人类挑选、标注或设计，它的上限仍受制于人类。

### 最强、最有价值的解释

它不是“人类知识没有价值”，而是：

- 人类知识可以提供初始条件、界面、先验和安全约束；
- 但改进机制必须能从数据与环境结果中自行发现规律；
- 随规模增加，系统不应要求专家以同等速度增加规则、标签和例外。

### 边界

- 这是历史归纳，不是任何具体系统都必然成立的定理。
- 安全、协议、法律、同意和产品边界不能靠开放式学习“自行发现”；它们仍需明确约束。
- 通用方法也包含设计选择：表示、目标、行动空间、传感器和反馈通道仍由人定义。

### 对 Volvence 的含义

Volvence 禁止关键词路由、prompt 补丁和 evaluation 回灌，与这条教训一致。进一步的检查标准应是：任何新“智能”是否会随经历改进，还是仅把专家规则换成更长 prompt。

## 3. “权重不变，所以不是真学习”：一个有意收窄的定义

### 访谈中的判断

Sutton 把当前助手称为非 experiential：部署后的模型权重通常不变，上下文只让模型暂时看到更多信息。Javed 也承认上下文可与学习共存，但他希望经历最终改变系统的长期内部参数。

### 这个区分为什么有用

它迫使我们区分四种看似都叫“学习”的行为：

| 行为 | 跨 turn | 跨 session | 改变未来策略 | Sutton 访谈的严格定义 |
|---|---:|---:|---:|---|
| prompt / 当前上下文 | 是 | 通常否 | 暂时 | 不算长期学习 |
| 检索外部记忆 | 可 | 可 | 通过输入间接改变 | 倾向于视为使用知识而非学习 |
| 更新小控制器、记忆参数或世界模型 | 可 | 可 | 是 | 算经验学习 |
| 更新基础模型权重 | 可 | 可 | 是 | 算，但不是唯一可能的参数载体 |

因此，问题不应简化为“LLM 权重有没有变”，而应问：**经历是否以可恢复的持久状态改变了后续预测、信用和行动，并能在新后果到来后继续修正？**

### Sutton 自己的公开定义并不完全一致

[*Welcome to the Era of Experience*](papers/era-of-experience-2025.pdf) 的脚注把由环境反馈驱动的“权重更新或 in-context adaptation”都纳入 RL 适应。也就是说：

- 访谈采用的是较强的“长期内部权重变化”标准；
- 观点论文采用的是较宽的“由环境反馈改变行为”标准。

这不是致命矛盾，但说明“只有基础模型权重变化才算学习”不能当成普遍定义。

### 对 Volvence 的含义

Volvence 冻结基础模型，并让 CMS、控制器、语义 owner 和 gated artifact 按不同时间尺度变化。按访谈强定义，它是**部分持续学习系统**：基础 substrate 不学，但其他持久参数/状态可以学。按 Era 的宽定义，它完全可以成为经验学习系统，前提是变化确实由环境 PE / credit 驱动并跨 session 保留，而不是只把历史塞回上下文。

## 4. “合成数据是巨大错误”：反对替代现实，不是反对所有模拟

### 原话的上下文

Sutton 在访谈中用很强的措辞批评合成数据。他的论据有三层：

1. 如果合成数据仍由人类选择任务、评判答案或构造生成器，瓶颈仍是人类的数据生产能力；
2. 固定模拟器只保留现实的一小部分，智能体会优化模拟器的缺口；
3. 真正开放的世界总会包含模型未预见的状态、其他行动者和新因果因素。

自动驾驶例子表达的不是“永远不用仿真”，而是车辆最终必须利用真实驾驶中的预测偏差持续修正，而不能只在工程师维护的模拟器里封闭训练。

### 必须区分的三类“合成”

| 类型 | 目的 | 是否替代现实后果 | Sutton 批评的适用程度 |
|---|---|---:|---|
| 静态合成训练真相 | 扩充题目、答案、偏好，再训练下一代模型 | 是或接近是 | 强烈命中 |
| 受控机制基准 | 隔离漂移、噪声、遗忘、可塑性等变量 | 否 | 不命中；Nature 自己也构造序列任务 |
| 学到的世界模型 / 反事实 rollouts | 规划、比较候选行动、提出假设 | 否，最终需真实结果校正 | 条件性可用；Era/Alberta Plan 都需要模型和规划 |

一个更精确的规则是：

> 合成数据可以负责提出候选、覆盖边界、控制变量和预演；不能负责把自身宣布为世界真相，也不能绕过真实结果对 prediction error 和 credit 的结算。

### 这一主张的证据边界

- Big World 是假说，作者明确承认其证据是间接的，且某些问题并不满足。
- AlphaGo Zero 的自我对弈仍发生在规则完全已知、可精确模拟的封闭环境中，不能直接证明开放世界模拟无效。
- 机器人、自动驾驶、芯片、药物和安全测试中，真实数据昂贵或危险，仿真具有不可替代的筛选价值。
- learned world model 如果持续被真实 prediction error 校正，不能简单归为“人类静态合成数据”。

### 对 Volvence 的含义

[synthetic experience corpus spec](../../docs/specs/synthetic-experience-corpus.md) 已区分 `generator_truth`、`rendered_text` 和 `runtime_observation`，并禁止 evaluation/model prediction 成为运行时学习真相。这正是应保留的设计。需要强化的是证据标签：每项结论都标记来自 sandbox、offline evidence 还是 live consequence，晋升只接受预先定义的真实结算条件。

## 5. “大模型只完成了四分之一智能”：方向提醒，不是测量

### 访谈中的含义

Sutton 把语言能力视为智能的一个重要部分，其他部分包括感知、行动、规划和在长期经验中持续改变自身。他给出的 20–25% 是定性估计。

### 为什么它有启发性

它提醒团队不要用语言流畅度替代以下系统能力：

- 在行动前形成可检验预测；
- 接收行动后的环境结果；
- 归因误差而非只评价回答好坏；
- 让经验跨 session 改变未来行为；
- 形成跨时间抽象并用于规划；
- 在资源和安全边界内持续进行上述过程。

### 为什么不能拿来做路线比例

- 没有智能维度的共同度量，也没有四等分模型。
- 语言本身包含感知、规划和世界知识的代理能力，维度并不正交。
- 对不同产品，“缺失的四分之三”完全不同。

Volvence 应把它作为 coverage checklist，而不是把项目写成“已完成剩余 75%”。

## 6. 可塑性损失与灾难性遗忘：两个方向相反的失败

### 访谈的通俗表达

访谈把长期学习的核心障碍概括为：网络要么不更新，要么更新后覆盖旧知识。随后又把 Nature 的可塑性工作放入这个叙事。

### 技术上必须拆开

- **遗忘**：为了新数据更新后，旧能力变差；对应 stability。
- **可塑性损失**：网络训练很久后，即使当前任务数据充足，也越来越难学会；对应 plasticity。

一个学习器可以同时有两者，也可以只有一个。CBP 为不断引入随机新特征，主要解决第二个问题；它甚至可能增加第一个问题，所以 Nature 扩展讨论明确说当前算法没有解决 forgetting。

### 对 Volvence 的含义

CMS 的“记忆能否保留”和 band MLP 的“还能否吸收新关系”必须用两组曲线测，不能用一个 continuity 分数代替。关系状态还需要第三组 coherence / consent safety 指标。

## 7. 步长优化：把稳定—可塑性选择下沉到参数

### 访谈中的主张

Javed 用“每个连接有自己的学习速度”描述其方向：已经承载稳定知识的权重慢一些，需要适应变化的权重快一些。普通 Adam / RMSProp 主要按梯度统计归一化更新，并不直接优化整个生命期的未来损失。

### 论文实际支持什么

[*Step-size Optimization for Continual Learning*](papers/step-size-optimization-2401.17401.pdf) 用 IDBD 类 meta-gradient 在简单线性长期流中优化参数级 step-size，并与 oracle / Adam 等比较。结果支持：

- 参数级步长可以跟踪不同变化率；
- 归一化与优化不是一回事；
- 在所测问题上，IDBD 可接近合适的 oracle。

但它没有证明：

- 深层网络每个权重的 IDBD 已经稳定；
- LLM 规模可承受其额外状态和 meta-gradient；
- 它与 CBP 联合后能解决 forgetting；
- 一个 meta-step 超参数可跨尺度通用。论文中的目标尺度变化会让适宜 meta-step 跨越多个数量级。

### 对 Volvence 的含义

当前 learned update rule 产生 band / target 级 `step_scale`，不能命名为 IDBD。可以在 CMS 小网络中对比 parameter/group step-size，但要用 PE / credit 构造生命期目标，并对 step-size 做显式界限、观测、checkpoint 和回滚。

## 8. Generate-and-test 与 continual backprop：持续提供“新材料”

### 核心思想

标准 backprop 的能力不只来自梯度，也来自训练开始时的小随机初始化。随着训练持续：

- 一些单元失活、饱和或输出近似常数；
- 权重变大，网络难以快速改变；
- 表征有效秩下降；
- 初始随机多样性被耗尽。

generate-and-test 把“初始化一次”改为“持续、小剂量地初始化”：提出少量新特征，观察其贡献，淘汰长期低效用的成熟特征，再让 backprop 检验新特征。

CBP 是这一思想的一个具体实现，不是完整的抽象发现算法。它对隐藏单元进行局部替换，不会自动生成具有人类可读语义的 option、subtask 或世界模型。

### 最容易被误解的三点

1. **持续随机性不是持续扩容。** 网络宽度保持固定，旧单元被替换。
2. **低 utility 不等于旧知识无用。** 当前 utility 主要看近期数据的局部贡献，可能误杀只在稀有状态有用的单元。
3. **输出保护是瞬时的，不等于知识保护。** 清零新单元 outgoing weights 让替换当下近似不改变输出，但后续学习仍可能干扰旧能力。

### 对 Volvence 的含义

generate-and-test 最适合映射到两层：

- 小型 CMS / controller 的隐藏特征：可用 CBP 风格的低效用 feature renewal；
- rare-heavy artifact / temporal abstraction：生成候选，经预测、规划效用、PE/credit 和 `ModificationGate` 检验后晋升或退休。

绝不能把它映射成“随机删除 semantic snapshots”或“在线重置基础 LLM 神经元”。

## 9. 自主时间抽象与规划：Oak 最重要、也最缺证据的部分

### 目标

Oak 认为真正的心智不只做下一 token / 下一状态预测，还要自行发现：

- 跨多个时刻有持续预测力的 feature；
- 值得追求或避免的 subtask；
- 实现 subtask 的 option；
- option 对后续状态和值的 model；
- 能改善长程决策的规划组合。

抽象的价值不由人命名，而由两个回路检验：它能否持续预测，以及它是否让规划做出更好的行动。

### 当前公开证据

- Alberta Plan 给出从 feature 到 STOMP，再到 Oak utility feedback 的步骤。
- OaK 官方页重述“self-verifiable”和“useful for planning”。
- 2025 RLC 页面提供讲座入口。
- 截至 2026-08-22，没有公开 OaK 算法论文、实现、benchmark 或消融。

因此这是一个高价值设计目标，不是可以直接依赖的外部组件。

### 对 Volvence 的含义

Volvence 的 `z_t / beta_t`、temporal state 和 planning 意图在概念上接近，但既往 `kill-eta` 明确否证了某一 operationalization。下一版必须把“候选抽象是否让 prediction / counterfactual planning 更好”写成预注册 gate，不能因名字相近就认为已实现 OaK。

## 10. 从头训练、多个心智与 20W

### 从头训练

Javed 在访谈中说，这套机制不能简单套在现有静态模型上，应从头训练一种“学会如何继续学”的 foundation model。最合理的理解是：持续学习偏置需要贯穿表示形成过程；后装机制可能被已僵化表征限制。

但现有证据还不足以要求 Volvence 重训基础模型：

- Nature 没有 LLM 实验；
- OML 说明离线学习“适合未来在线更新的表示”有价值，但也承认在线自生表征仍是开放问题；
- 小型外接控制器和记忆可先检验闭环是否有效。

### 多个心智

同一架构因环境和经历不同而形成多个实例，这与关系型产品的主体连续性相容。但它也带来模型分叉、身份、隐私、删除、迁移和 audit 问题。Volvence 的 frozen snapshot 与 owner 边界对此比“一个共享在线模型”更合适。

### 20W

20W 万亿参数是类脑能耗愿景。访谈中的推导主要是把计算效率按约 18 个月翻倍外推 10 年；它没有处理内存带宽、持续写入、通信、传感器、训练开销、精度或硬件利用率。它可以提醒团队测 joules / settled experience，但不应成为近期架构门槛。

## 11. 访谈中最值得保留的原则

去掉夸张表述后，可留下六条可用于 Volvence 评审的原则：

1. **部署不是学习终点。** 每个长期状态都要说明如何被新后果修正。
2. **环境结果高于数据生产者意见。** 人类规则负责边界，PE/credit 负责经验学习。
3. **可塑性必须作为一等运行指标。** 不能只看当前性能和旧知识保持。
4. **新表征需要持续生成、检验和退休。** 固定拓扑只能作为阶段性实现。
5. **抽象必须同时可预测、可用于规划。** 可读标签或 prompt route 不是时间抽象。
6. **资源约束是问题定义的一部分。** 不用“保存并重放所有历史”回避长期学习。
