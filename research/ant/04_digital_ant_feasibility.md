# 数字蚂蚁可行性评估

> 本文档回答核心问题：**能不能用 VZ 现有这套系统（R-PE + R1-R20 分层架构）做出一个真的数字蚂蚁？**
>
> 先给结论，再给架构映射、差距清单和分阶段路线图。

## 0. 先把问题劈成两个,因为答案完全不同

"数字蚂蚁"这个词至少对应两条完全不同的路径,答案是**一个能做、一个现在不该做**：


| 路径            | 目标                                                                                                 | 能不能做                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **A. 功能等价路径** | 用 VZ 已有的分层原理（冻结基底 + 有界控制器 + 多时间尺度记忆 + PE 一级信号 + 快照隔离）实现一个行为上等价的数字生命体——能路径积分回巢、能学路线、能跟信息素、能在群体中涌现分工 | **能**，而且是当前 VZ 架构的一个极佳低成本验证床                                                                            |
| **B. 结构复刻路径** | 逐神经元/逐突触复刻 CRANTb 连接组数据,做出"数字版真实蚂蚁大脑"                                                              | **不能**，也不应该现在投入——见 [`03_counter_evidence.md`](03_counter_evidence.md) 反证 2，果蝇这条路径都还在大量简化假设阶段，蚂蚁的数据成熟度更低 |


下面全部围绕路径 A 展开。路径 B 只在第 5 节给出"什么时候可以重新评估"的判据。

## 1. 为什么这是个好主意（不只是好玩）

VZ 的 R1-R20 分层假设目前主要在 LLM-based companion 场景下被验证——substrate 是冻结 LLM,controller 在 token 之上的 latent 空间操作。这带来一个没人能回答的问题：**这些分层原则是不是独立于"底层是不是 LLM"这件事本身而成立的?还是说它们其实依赖了 LLM 的语言/推理能力才显得"work"?**

数字蚂蚁提供了一个几乎完美的反面测试：把 substrate 换成一个**完全不涉及语言**的、几百到几千维的感觉运动原语层,如果 R2/R3-R4/R5-R6/R-PE 这些分层原理在这个语境下依然能产生"path integration、路线学习、集体觅食、分工涌现"这些教科书级的、有几十年行为学 ground truth 可比对的现象,这就是对 VZ 架构假设**独立于 LLM 的**最干净证据。

反过来说,如果做不出来,或者做出来发现某个分层假设在非语言语境下站不住,这个信号同样极其有价值——说明某个 R-ID 可能隐式依赖了 LLM 提供的能力(比如"语义泛化"),需要重新审视。

### 2.1 三层生物学 ↔ VZ 精确对齐（修正版，避免"改基底"歧义）

`03_counter_evidence.md` 反证 1 详细讨论过这一点：分工重编程改的是**基因表达程序**,不是基因组本身。完整对齐关系是三层,不是两层：


| 生物学层                           | 时间尺度       | 是否可逆      | VZ 对应                                                     |
| ------------------------------ | ---------- | --------- | --------------------------------------------------------- |
| 基因组（DNA 序列，克隆蚁间完全相同）           | 从不变        | 不可逆       | **frozen substrate**（vz-substrate，对应 base LLM 权重）         |
| 基因表达程序（组蛋白修饰/染色质状态/受体密度）       | 天到周级，严格窗口期 | 窗口期外基本不可逆 | **rare-heavy artifact refresh**（R2 例外条款，离线训练管线，产出个体初始化参数） |
| 突触权重 / 瞬时神经活动（MB 关联学习、CX 朝向积分） | 秒到分钟级，持续在线 | 可逆        | **online-fast controller**（vz-temporal 的 z_t/β_t）         |


数字蚂蚁的 substrate（感知编码器 + 动作解码器,见第 3 节）对应第一层,应该在整个实验过程中保持字面意义上的不变；rare-heavy 角色初始化对应第二层,只在离线训练循环里跑,产出的是"个体倾向性参数",运行时不可触发；controller + 记忆的在线学习对应第三层。三层各自独立、不能互相越权,是这次调研对 R2 措辞最直接的一条修正建议。

### 2.2 连接组"动力学信息"（正负号/权重/神经肽广播）具体怎么处理

这两类信息不该被当作"数据"直接搬进数字蚂蚁,而应该被当作"该怎么设计契约边界"的启发：

- **突触正负号 + 权重** = 拓扑之上的、需要被学出来的东西,不是结构先验能替代的。数字蚂蚁里,任何"谁影响谁"的连接拓扑（比如"信息素梯度感知器的输出会喂给朝向 controller"）可以在设计时定好,写进这个原型自己的 contract 文档;但具体的影响强度和方向,必须由 PE 循环通过学习获得,不能从蚂蚁连接组数值里抄——那些数值目前也没被真实测出来（反证 2）,抄一个没验证过的假设没有意义。落地做法：controller 内部的权重是该模块的私有学习参数,永不作为跨模块契约暴露。
- **神经肽广播** = 需要在 `DATA_CONTRACT.md` 里新增一类 slot："broadcast/modulation"（区别于现有的"point-to-point/business" slot）：单一 owner（对应神经分泌系统的角色，比如一个 vitals-like 模块）发布一个低维、只读的偏置快照（如"当前警戒度"）,允许被多个下游模块显式订阅、当作可选偏置输入,但快照本身仍然不可变、单一发布者、版本化——只是消费模式从一对一变成一对多。这是数字蚂蚁项目如果要引入"觅食 vs 警戒"这类全局状态漂移时,唯一不违反快照隔离铁律的做法。

## 3. 架构草图：Digital Ant v0

一个不依赖 LLM、不依赖连接组数据、纯粹用 VZ 分层原理搭建的最小可行数字蚂蚁：

```
感知层（substrate，冻结）
├── 视觉：光流传感（模拟 optic flow，向量场）
├── 嗅觉：食物气味梯度向量 + 信息素浓度梯度向量（读取群体快照总线）
├── 本体感觉：步数计数器 / 已走距离
└── 报警通道：专用高优先级信号线（天敌/坍塌等硬编码触发条件，绕过下面所有学习管线 —— 这是 panic glomerulus 的直接实现）

控制器层（vz-temporal 对应，非 LLM 的 z_t/β_t）
├── 环形吸引子式朝向状态（连续向量，角速度积分更新）
├── 期望朝向计算（回巢向量 = 路径积分累积 / 信息素梯度上升方向，二者按 β_t 式切换门加权）
└── 导航模式切换：{outbound-search, homebound, trail-following, panic-flee} 作为涌现的、非硬编码的模式,由期望朝向与当前朝向的持续偏离度驱动切换,而不是 if-else 状态机

记忆层（vz-memory 对应）
├── online-fast: 稀疏随机投影层（Kenyon-cell 式）+ 一次性学习的熟悉度读出（Willshaw-net 等价物，即 PE 主链）
├── session-medium: 当前觅食行程内的路线关联权重（MBON 式,趋近/回避两条并行读出）
└── background-slow: 跨行程的路线巩固 + 觅食效率的反思（是否该换路线）—— 异步、不阻塞下一步移动决策

群体层（快照总线，跨个体唯一通道）
├── 信息素场快照：{位置, 浓度, 类型(食物/回巢/警报), 时间戳}, 只追加 + 定时衰减
├── 每个数字蚂蚁个体只读取/写入这个共享快照,不直接调用其他个体的内部状态
└── 群体级 readout（可选,用于观测）：食物发现率、路线收敛度、分工分布——只读评估,不反向进入学习信号

rare-heavy 层（独立训练管线,不在 runtime 主循环里）
└── 角色重编程：类似分工重编程,是一个离线的、有时间窗口的"个体倾向性"调整通道,产出的是个体初始化参数（比如更高的探索倾向 vs 更高的巡岗倾向）,不是运行时可以随时触发的东西
```

这套草图里,**没有一处需要 token/语言**,也**没有一处需要 CRANTb 连接组数据**——它完全建立在 VZ 已经验证过的分层原理之上,只是换了一个感觉运动的 substrate。这正是第 1 节说的"独立测试床"的意义。

### 3.1 两个冻结向量函数的具体定义（之前写得不够清楚，这里补全）

substrate 层就是**两个确定性函数**，中间夹着 controller。下面给出可以直接写代码的具体定义，不是隐喻。

**世界侧的两个场（环境本身的状态，不属于 substrate，是仿真环境要提供的）**：

- 食物气味场：`I_food(x) = Σ_k A_k · exp(-‖x - p_k‖ / λ_food)`，`p_k` 是第 k 个食物源位置，`A_k` 强度，`λ_food` 衰减常数。
- 信息素场（按类型分开，至少两种）：`P_home(x, t)`、`P_trail(x, t)`，是一个会衰减的 2D 网格：每 tick 执行 `P ← P · (1 - decay_rate)`，蚂蚁经过时对当前 cell 执行 `P[cell] += deposit_amount`。

**感知编码器 `sense_encode`（substrate 的第一个冻结函数）**：

在蚂蚁身体两侧各放一个虚拟"触角"采样点，相对当前朝向估计 `ĥ`（这个朝向估计是 controller 内部维护的状态，不是环境给的 ground truth）偏移 `±φ`（比如 ±30°），距离体心 `r`：

```
left_probe  = position + r · (cos(ĥ+φ), sin(ĥ+φ))
right_probe = position + r · (cos(ĥ-φ), sin(ĥ-φ))

s_t = [
  I_food(left_probe),  I_food(right_probe),      # 食物气味，双触角差分 = 转向信号来源
  P_home(left_probe),  P_home(right_probe),      # 回巢信息素
  P_trail(left_probe), P_trail(right_probe),     # 招募/食物信息素
  turn_command_{t-1},                             # 本体感觉：上一步实际发出的转向量（效仿真实的 efference copy / 步幅计数）
]
```

`s_t` 是固定 7 维向量，`sense_encode` 整个过程是纯确定性代数运算，不含任何可学习参数——这就是"substrate 冻结"在这个原型里的字面含义。真实蚂蚁的嗅觉受体到小球的映射也是这个性质：终身不因经验改变。

**动作解码器 `motor_decode`（substrate 的第二个冻结函数）**：

controller 的输出永远是一个抽象的"期望朝向单位向量 + 期望速度"`(d_t, v_t)`，`motor_decode` 把它转成物理执行指令：

```
angle_diff   = atan2(d_t.y, d_t.x) - ĥ                       # 期望方向与当前朝向估计的夹角
turn_command = clamp(angle_diff, -max_turn_rate, +max_turn_rate)
step_command = v_t · fixed_step_size

# 执行后更新 controller 内部的朝向估计（这是路径积分的核心更新）：
ĥ ← ĥ + turn_command
```

这两个函数是这次调研里唯一需要新写、且目前 VZ 代码库里完全没有对应物的部分（第 4 节差距 1）。它们本身不需要任何机器学习框架，普通 numpy 函数就够；会学习的部分全部在中间的 controller（把 `s_t` 映射成 `(d_t, v_t)` 那一步），这正是 `vz-temporal` 分层原则要验证的东西。

**关于实现方式的补充说明**：这两个函数目前 VZ 里完全不存在,需要新写。且它们**不需要是神经网络**——这不是简化偷懒,而是对应生物学现实：真实蚂蚁的嗅觉受体-小球映射本身也是遗传固定、个体一生不"学习"的（论文 4/5）。这部分代码建议独立于 `vz-substrate` 存放（它是一个不同 embodiment 的 substrate,不该塞进语言模型专用的包里），等 Phase 0/1 验证出结果后再决定是否要往主线迁移或保留为独立研究沙箱。

## 4. 当前差距清单（2026-07 实现后复核）

早期版本所列的非 LLM substrate、2D 环境、信息素快照总线和 rare-heavy 离线通道均已实现；
`AntWorld → AntSession → EnvironmentOutcome → PE/credit` 机制闭环也已打通。当前差距已经从
“有没有代码”转为“正式行为证据是否成立”：

1. **learned foraging 仍是 BLOCK**：现有多 seed 结果里 learned 与 no-optimize 都没有 held-out
   delivery 增益，不能把 latent synthetic proof 当作蚂蚁行为 proof。
2. **公平实验协议刚闭合**：kernel arms 现在按训练地图 → owner checkpoint → held-out 地图运行，
   并从同一初始 checkpoint 分叉；正式 artifact 需要按新协议重跑。
3. **四个 torch backend 生产默认仍为 DISABLED**：ant active-evidence 只在隔离候选配置中逐项
   真正启用并评估，绝不自动 flip 生产默认值。
4. **生物学量级**：AntBot homing 现已通过——根因是原实现用**纯 efference-copy dead reckoning**
   对标带天空偏振罗盘的 AntBot，量纲不公平（纯积分航向误差按 √N 随机游走，物理上到不了 0.5%）。
   已给 `AntNavigator` 补上与 AntBot 一致的天空罗盘绝对航向通道（互补滤波，σ≈0.4°），并把阈值口径
   从单条 14m 轨迹 0.47% 改为更有代表性的 AntBot 聚合 0.67%（26 次）。这是补一个本该有的传感器 +
   诚实标定，不是调小噪声偷分。Ardin 的 errors-per-route 与 exposure novelty 不同量纲，继续禁止伪造叠图。
5. **群体与角色 claim 尚未通过**：kernel bus 必须显示多 seed 正增益；rare-heavy 必须在
   held-out 行为上随压力产生可复现聚类变化，artifact 参数切片不再算 PASS。
6. **可视化与复现入口已补齐但不改变 verdict**：`scripts/run_ant_pipeline.py` 提供 demo/formal
   profile；实时 Dashboard、HTML replay、GIF/MP4 和 manifest 全部读取同一不可变 turn replay。

## 5. 分阶段路线图

按照 workspace 的收敛包工作流（多文件架构变更走有界收敛 + 可回滚),建议分三个独立可交付的阶段,每阶段都有明确的成功判据,且都可以独立产出研究价值,不需要等到最后一步才有结果：

### Phase 0 — 单个体导航验证（对应 R2/R3-R4 的独立测试）

- 范围：单个数字蚂蚁,2D grid world,无群体、无信息素场。
- 实现：环形吸引子朝向状态 + 路径积分回巢 + 稀疏码路线记忆（PE 主链）。
- 成功判据：能复现 AntBot 量级的回巢精度,且路线学习速度符合 Ardin 2016 的量级（几十次曝光内稳定）。
- 产出价值：独立验证"非 LLM substrate 下,R2 冻结基底 + R3-R4 latent 控制器 + R-PE 一级信号"这套分层是否真的能在无语言的最小系统里跑出来。这个结果本身对 VZ 主线（哪怕完全不做群体部分）就有直接反哺价值。

### Phase 1 — 群体协作与信息素快照总线（对应 SSOT 快照隔离铁律的独立测试）

- 范围：多个体共享同一个信息素快照总线,验证集体觅食效率/选址收敛。
- 实现：按第 4 节差距 3 设计好"多写者只追加带衰减"的快照 slot,先写 `docs/DATA_CONTRACT.md`。
- 成功判据：复现 Bayesian superorganism 论文范式下的集体决策收敛,且能证明个体之间零直接调用（可通过静态代码检查/import 边界测试验证,类似现有的 `tests/contracts/test_import_boundaries.py` 思路）。
- 产出价值：这是快照隔离铁律在一个"天然多智能体"场景下的独立压力测试,比任何单 companion 场景都更容易暴露"消费者悄悄重建生产者状态"这类违规。

### Phase 2 — 角色分工涌现（对应 R2 substrate 重编程边界的独立测试）

- 范围：引入 rare-heavy 角色重编程通道,观察分工是否在群体统计层面涌现,且不通过硬编码规则分配角色。
- 实现：按第 3 节"rare-heavy 层"设计一个离线训练循环,产出个体倾向性初始化参数;运行时不允许直接调用这个通道。
- 成功判据：群体涌现出稳定但非均匀的角色分布(比如探索型/巡岗型比例),且这个分布随环境压力（食物稀缺度、天敌威胁）系统性变化——对标论文 17-20 的分工可塑性范式。
- 产出价值：直接检验反证 1 提出的"substrate 级重编程需要独立于 online-fast 的时间窗口通道"这一应对策略是否真的可行、是否需要进一步收紧 R2/R9/R10 的边界条款。

### 何时重新评估路径 B（连接组级复刻）

只在以下条件**同时**满足时才值得重新评估：

1. CRANTb 或后续项目发布了**配套的功能验证数据**（钙成像/电生理,能反推突触权重正负号和强度,不只是解剖连接）；
2. 出现了不止一个个体的连接组数据（用于估计个体间连接结构的方差,判断"单个体连接组"在多大程度上能代表整个物种）；
3. 果蝇 FlyWire 路线的仿真精度在更多行为范式上得到独立验证（不只是味觉/梳理这两个已发表的电路）。

在此之前,把资源投入连接组级复刻是在赌一个连果蝇都还没完全验证的方法论,性价比远低于路径 A。

## 6. 现实影响力评估（不要过度期待，也不要低估）

诚实分两块说，不要把两块价值混在一起吹。

### 6.1 不会带来的影响力（提前排除期望）

- **不是昆虫神经科学的新发现**。AntBot、Ardin 2016 这些工作已经把"路径积分 + 菌体路线记忆"验证过了，我们做的是**用自己的架构复现**已知结果，不是发现新生物学机制。真正的蚁科学家不会因为这个项目引用我们。
- **不是新产品线**。数字蚂蚁不会变成一个能卖的东西，也不该占用面向 companion 产品的工程资源——它是研究/验证性质的旁支项目，投入规模应该长期保持在"几周而不是几个季度"的量级（对应第 5 节 Phase 0 的范围）。
- **不构成 R-ID 的实证"证明"**。行为学对照精度再高，也只是一个 toy 尺度（几百维向量、几千 tick）的证据，不能替代 companion 主线在真实语言交互规模上的证据。它是**独立信号**，不是**充分证明**。

### 6.2 真正会带来的影响力（价值集中在这两处）

1. **架构证伪能力（对内，价值最大）**：这是目前 VZ 唯一一个能在**完全不涉及语言、完全不依赖 LLM 推理能力**的情况下,独立检验 R2/R3-R4/R5-R6/R-PE/SSOT 是否成立的测试床。如果 Phase 0 做不出可用的路径积分/路线学习行为，这是一个极其廉价（几周、不需要 GPU 集群）就能拿到的重大信号——说明某个 R-ID 可能隐式依赖了语言模型的能力，需要回头重新审视分层假设本身，而不是在 companion 主线里花几个月才发现同样的问题。反过来如果做成了，这是"分层原理独立于 LLM 而普遍有效"这个论点目前唯一站得住的独立证据来源。
2. **传播/技术信任杠杆（对外，价值次之但很直接）**：见第 7 节。这类"看得懂、看得见"的具身演示，对投资人/技术评审/招聘候选人建立信任的边际效率，往往比同等工程量投入到抽象架构文档里高得多——因为受众不需要先理解"R-PE""nested learning"这些术语，就能直接看懂"一群没有硬编码规则的数字蚂蚁自己学会了分工"这件事本身有多难。

### 6.3 一句话校准

**这个项目的性价比来自"验证成本极低 + 演示直观性极高"的组合，不是来自它本身的技术难度或商业价值**——如果因为它"看起来很厉害"就投入超出 Phase 0/1 范围的资源，反而是被这次调研自己指出的"演示效应"给绕进去了。

## 7. 如何形象地证明这套架构的威力

如果要做,建议不要只做"一个能跑的数字蚂蚁"，而是设计成**几个能让人一眼看懂对比差异的实验**，因为"厉害"这件事本身需要一个可对比的基线才能被感知到，单独一个能跑的 demo 说服力有限。

### 7.1 拳头实验：同一套 controller 代码，同时驱动数字蚂蚁和语言 companion

这是最直接、最难被竞品复制的证明：把 `vz-temporal` / `vz-memory` / `vz-cognition` 这几个包**原样复用**（不是重新实现同一套原理，是真的 import 同一份代码），一份接上数字蚂蚁的感觉运动 substrate，另一份接上现有的 LLM companion substrate,side-by-side 跑。

- 对投资人/技术评审最有冲击力的画面：左边屏幕是一只在 2D 世界里觅食、跟着信息素回巢的数字蚂蚁；右边屏幕是一个正常对话的 companion；中间标注"同一份 `vz-temporal`/`vz-memory` 代码，零业务逻辑修改"。
- 这句话背后的技术主张是"我们的分层原理不是为聊天机器人量身定做的话术包装，是一套通用的认知架构"——这是任何纯 prompt engineering 或者纯 RLHF 调出来的竞品**做不到**的事，因为他们的"智能"是和语言表达焊在一起的，没有可以拆下来复用的 controller 层。这个演示本身就是对"R2/R3-R4 独立于 substrate"这个核心卖点最难反驳的证据。

### 7.2 对照实验：涌现式 vs 硬编码脚本蚁群

同一个环境（食物源移动、路径被堵、突然出现"天敌"信号）分别跑两组：

- A 组：经典硬编码有限状态机蚁群（对应传统 ACO/NetLogo 风格：if 靠近食物 then 采集、if 携带食物 then 沿信息素梯度回家……）。
- B 组：我们的分层架构版本，没有任何"if 情况 X then 行为 Y"的规则，只有 R-PE + controller + 记忆。

当环境被扰动（食物源突然搬家、原路径被堵死）时，A 组会表现出脚本覆盖不到的场景就卡死或行为荒谬，B 组应该能通过重新探索/重新学习平滑适应。**这个对比本身就是"学习到的架构 vs 硬编码规则"这条设计哲学最具体、最可视化的证明**，观众不需要懂任何架构术语，看两组蚂蚁在同一个扰动下的反应差异就懂了。

### 7.3 定量对照：把仿真曲线叠在真实生物学数据上

第 4 节列的验证 ground truth（AntBot 7cm/14m 回巢精度、Ardin 几十次曝光内学会路线）不只是内部验收标准，本身就是**极好的对外证明素材**：把我们数字蚂蚁的"回巢误差 vs 行程距离"曲线、"熟悉度 vs 曝光次数"曲线，和已发表论文里真实蚂蚁/AntBot 机器人的曲线画在同一张图上。如果曲线形状/量级吻合，这是一张一图胜千言的图——"我们的架构不是自说自话，复现了几十年行为学文献里的真实生物学曲线"，这种可外部核验、可引用论文对照的证明比任何自我宣称都有分量。

### 7.4 戏剧性小实验：安全反射的"一票否决"演示

针对 ModificationGate/安全边界这条设计（对应反证 3 的 panic glomerulus），做一个几秒钟就能讲清楚的演示：给蚂蚁展示一个模拟"天敌"信号，不管当时 controller/记忆处于什么学习状态（哪怕人为注入一个错误/混乱的中间训练状态），报警反射通道都能在固定延迟内触发逃跑，绕开所有还在学习中的路径。这是"安全关键路径独立于、且优先于学习中的主逻辑"这个工程原则最容易被非技术观众理解的具象化证明。

### 7.5 优先级建议

如果只能做一个，做 7.1（同代码双 substrate）——它是唯一一个直接证明"架构原理可复用、不是话术包装"这个核心商业主张的演示，其他三个是很好的辅助证据，但 7.1 是不可替代的。

## 8. 结论

用 VZ 现有系统做一个"行为等价"的数字蚂蚁——能路径积分回巢、能学路线、能靠信息素协作、能在群体里涌现分工——**是可行的,而且是一个成本极低、信号极强、完全独立于 LLM 的架构验证项目**。它不需要等待更多连接组数据,也不需要引入神经形态硬件,只需要把 VZ 已经在设计文档里写清楚的分层原理,搬到一个昆虫级复杂度的感觉运动 substrate 上跑一遍。

真正的"逐神经元复刻真实蚂蚁大脑"这条路径,目前不该做,原因不是能力不够,而是这条路径本身在方法论上还未成熟——即便是数据量和验证程度远超蚂蚁的果蝇,也还在"结构 + 大量简化假设"的阶段。把这条路径列为长期观察项,不列为近期投入项。
