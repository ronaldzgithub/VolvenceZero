## 0. 为什么单独建这个专项（先把名字归位）

起因：内部讨论里出现过把 **"正交权重调制 / OWM"** 挂到首席科学家 **杨柳博士**名下的说法。需要明确纠正两件事：

1. **OWM 在本仓库查无此项**——`vz-*` / `lifeform-*` 代码、`docs/specs/*`、`docs/DATA_CONTRACT.md`、现有 `research/*` 里都没有 OWM 的实现或引用。它从未进入过我们的架构。
2. **OWM 不是杨柳博士的工作**。OWM（Orthogonal Weights Modification，正交权重调制）是 **Zeng, Chen, Cui & Yu, 2019（中科院自动化所）** 提出的一条**持续学习（continual learning）**路线，属于"正则化派"防灾难性遗忘方法，和 EWC / SI / IMM 同族。

杨柳博士的真正学术谱系（见 `docs/business/Volvence-技术领先性与唯一性-3页.md`、`docs/scenarios/sea/*`）是**主动学习 / 漂移分布 / 主动学徒学习**：
- *Active Learning with a Drifting Distribution*（NIPS 2011）
- *Learning with a Drifting Target Concept*（ALT 2015）
- Hanneke & Yang, *Minimax Analysis of Active Learning*（JMLR 2015）
- *Reliable Active Apprenticeship Learning*（ALT 2025）

两条线**机制完全不同、可被独立核验、不可混淆**。混淆的根源大概率是两边都打了"**约 10 个样本就能学一个新任务**"这张牌——但二者达成"少样本"的原理南辕北辙（见第 3 节对照表）。本专项只就 OWM 论文本身做技术分析，并判断它对 VZ 的真实价值与边界。

## 1. 一句话判断

OWM 的价值不在"又一个防遗忘 trick"，而在它给出了**有界塑性（bounded plasticity）的一个干净几何实现**：

> 不冻结任何权重，而是把每一步梯度更新**投影到与"全部历史输入子空间"正交的方向**上——于是新任务的学习在几何上不可能干扰旧任务，且系统的"剩余学习容量"被一个可测量的量（投影器 `P` 的秩）显式记账。

对 VZ 而言，OWM **不是**要引入的运行时机制（它有一条直接违反 R2 的用法，见第 6 节），而是为 R10（有界自修改）、R2（冻结基底 + 自适应控制器）、R14/R7（context 是几何对象不是 prompt 标签）提供了一个 2019 年就跑通的**外部结构证据 + 可借用的算子原语**。

## 2. 论文核心：两个互相独立的组件

论文其实是两件事拼在一起，**必须拆开看**，因为它们解决的是正交的两个问题。

### 2.1 OWM 算法——防灾难性遗忘（continual learning）

问题：神经网络顺序学多个任务时会**灾难性遗忘**——学新任务的梯度会破坏旧任务已学到的映射。

OWM 的解法：约束权重更新方向。训练新任务时，权重**只能沿着"与所有此前学过的输入张成的子空间"正交的方向**改动。直觉：旧输入落在子空间 `S` 里，只要权重改动 `ΔW` 与 `S` 正交，那么对任意旧输入 `x ∈ S`，`ΔWᵀx ≈ 0`，旧任务输出不变 → 不遗忘。

构造正交投影器：

```
P = I - A (AᵀA + αI)⁻¹ Aᵀ
```

其中 `A = [x₁, …, xₙ]` 的列是历史输入向量，`α` 是小正则常数。实际权重更新：

```
ΔW = κ · P · ΔW^BP
```

`κ` 是学习率，`ΔW^BP` 是标准反向传播算出的更新。关键工程点：

- **不存历史数据、不扩网络**。`P` 用类似 **RLS（Recursive Least Squares）**的递归式在线更新，只需当前输入和上一任务的 `P`，规避了存全部 `A` 和求逆。复杂度 `O(Nₙ·N_w²)`，与 EBP 同阶。
- **"少样本"来自 RLS 的二阶收敛**：RLS 比 LMS（≈标准 BP）收敛快得多，所以约 10 个样本就能学好一个新类。**这是 OWM 少样本性的全部来源——纯优化器收敛速度，与"选哪个样本"无关。**
- **容量是可记账的**：层容量 = `rank(P)`。每学一个任务 `rank(P)` 单调下降，趋近 0 时该层再无学习容量。全网容量 `rank_tot = Σ_l rank(P_l)/rank(βI)`。论文实验证明性能下降与 `rank(P)` 下降高度相关。

实验结论（节选）：

| 任务 | OWM | 对照 |
|---|---|---|
| Shuffled MNIST 100 任务 | ~85.4% | EWC ~70.8% / SI ~82.3% |
| Disjoint MNIST | 96.6% | EWC 52.7% / IMM 94.1% |
| Disjoint CIFAR-10（端到端） | 52.8% | EWC 31.1% / IMM 32.4% / MA 40.5% |
| 手写汉字 3755 类顺序学 | ~92%（接近人类 ~96%） | — |

**重要论断（直接反哺我们 README 的 primitive #6）**：论文明确指出 **"EWC 在某些条件下可视为 OWM 的特例"**。EWC 是"冻结重要权重"（减少自由度），OWM 是"让冻结的权重仍可在不擦除旧知识的前提下移动"——所以 OWM 在同类正则化方法里给出了**更强的梯度屏蔽**，资源浪费更少。

### 2.2 CDP 模块——上下文相关处理（context-dependent processing）

这部分**与持续学习无关**，是受灵长类前额叶皮层（PFC）启发的独立模块，解决的是："同一个输入，在不同 context 下要给出不同的映射"。

机制：在分类器前加一层 **rotator**，用 context 信号 `C`（来自任务名的词向量，经一个可训练 encoder 编码）对感觉特征 `F` 做**逐元素调制**：

```
Y^out = g(W_inᵀ F) ⊙ C
```

数学上等价于**在特征空间里"旋转"输入向量**——改变表示而不破坏信息内容。于是同一张脸的特征，在"判断性别"和"判断是否微笑"两个 context 下被旋到不同方向，**单个分类器**就能复用来学 40 个不同属性。

关键性质：
- **context 通过几何变换（旋转）生效，不是通过 gating 选子网，也不是 prompt 标签**。
- 对比 Masse et al. 2018 的 context-gating：那种方法要求 train/test 都提供同样的 context 信号；CDP 不需要这种限制，因为 context（环境线索、当前任务）对任何需要上下文处理的输入"本来就总是在场的"。
- encoder 能从带噪输入里**推断出有意义的 context 信号**（Supplementary 验证），且 CDP 神经元呈现与真实 PFC 一致的**混合选择性（mixed selectivity）**。

## 3. 与杨柳博士工作的严格区分（防混淆对照表）

| 维度 | **OWM（Zeng et al. 2019）** | **杨柳博士 active learning 线** |
|---|---|---|
| 学科归属 | 持续学习 / 防灾难性遗忘（正则化派） | 主动学习 / 漂移分布 / 主动学徒学习 |
| 核心问题 | 顺序学多任务时**怎么不忘旧的** | 数据稀缺时**该查询哪个样本** |
| 关键机制 | 梯度向**历史输入正交子空间**投影 | **信息论样本复杂度**下界 + 选择性采样 |
| "少样本"来源 | RLS **二阶收敛快**（优化器性质） | 选**高信息量**样本（`O(log n)` 标签复杂度） |
| 是否需要标注预算 | 否（被动喂正样本即可） | 是（主动学习的核心就是查询预算） |
| 数学对象 | 投影矩阵 `P`、`rank(P)` 容量 | VC 维 / disagreement coefficient / minimax 率 |
| 单位 | 中科院自动化所 | CMU 谱系（师从 Avrim Blum / Jaime Carbonell） |
| 与 VZ 关系 | 外部证据 + 可借原语（本专项） | 我们"主动学习支柱"的**理论地基** |

**结论**：二者正交、互补，甚至理论上可叠加（OWM 管"学了不忘"，主动学习管"少而精地学"）。但它们**不是同一个人、不是同一条线**，对外叙事和内部 spec 都不得混为一谈。

## 4. 对 VolvenceZero 的咬合（R-invariant 映射）

### 4.1 R10 / R9：有界自修改 = 正交投影（最强咬合点）

VZ 的 ModificationGate / R10 要求自修改**有界**；README 第 3 节引用 Two-Gate（自修改 agent 要保留学习保证，policy-reachable 模型族 VC 维必须有界）。OWM 是这条原理的一个**构造性实例**：

- 它不靠事后审计来限制改动，而是**在梯度层面就把改动方向约束死**——更新只能落在不伤旧知识的正交子空间里。
- 它的"剩余可改空间"被 `rank(P)` 显式记账，单调收缩。这等价于一个**自带、可测量的修改预算**——非常贴合 R10"有界 + 退出条件"和 R15"可观测 + 可回滚"的精神。

借用方式（仅在控制器/adapter 层）：当我们在 `vz-substrate` 的 bounded adapter-delta 入口或 `vz-temporal` 的控制器层做在线适配时，OWM 式的"正交投影约束 + 秩预算 telemetry"可作为**一种比 L2/EWC 更不浪费的有界更新算子候选**。

### 4.2 R2：冻结基底 + 自适应控制器（既是支撑也是警告）

- **支撑**：OWM 印证了"不必冻死、可以有界地动"的中间路线——比硬冻结（EWC）保留更多自由度，且论文自证 EWC 是它的特例。这与 R2"冻结基底、把适应放进有界控制器层"同向。
- **警告（关键）**：OWM 论文在 Disjoint CIFAR-10 里是**端到端在线更新整个网络（含特征提取器）**。这**直接违反** R2 的红线"禁止对整个基础模型做在线端到端梯度更新"。所以 VZ 对 OWM 的态度必须是：**只取其控制器层的有界更新几何，绝不取其 substrate 端到端在线训练用法**。

### 4.3 R14 / R7 / R3-R4：CDP = "context 是几何对象，不是 prompt 标签"

CDP 是一个 2019 年的早期证据，说明**上下文/体制可以通过对表示空间的几何变换（旋转）来调制行为，而无需 prompt、无需关键词→行为映射、无需 gating 选子网**。这与多条 VZ 不变量同构：

- **R14（持久体制身份）/ R7（双轨）**：regime 是运行时几何状态，不是 prompt 标签——CDP 的"context 旋转特征空间"是这句话的早期工程版。
- **R3/R4（token 空间之上的潜在控制）**：context 在**潜在特征空间**里调制处理，不溢出到表达层。
- 呼应 README primitive #5 / #7（Persona/Refusal 是残差流里的低维方向，可读可控）：CDP 的"旋转"和"混合选择性"是同一思想更早的雏形——**身份/语境是几何的，不是语言的**。
- 同时满足 `no-keyword-matching-hacks` 规则：context 驱动行为靠**学出来的旋转**，不是 `if keyword in text` 这种硬编码映射。

### 4.4 R6 / R1：容量边界与多时间尺度

OWM 把持续学习压进**单层定容矩阵**，`rank(P)→0` 即耗尽——这恰好暴露了单点方案的天花板，反向论证 VZ 为什么要走**多 stratum CMS（R6）+ 多时间尺度（R1）+ 有界 adapter + 可回滚**的分层路线：把持续学习摊到多个 owner、多个时间尺度上，而不是赌一个会被秩耗尽的固定矩阵。

### 4.5 在 README"7 primitives"里的定位

README 把 OWM 的同族（EWC）列在 **primitive #6 "Bounded self-modification"**。本专项的增量结论：**OWM 是 EWC 的更强同胞，且论文自证 EWC ⊂ OWM**——所以 primitive #6 的"代表算法"可从 EWC 升级标注为"EWC / OWM（正交投影屏蔽，EWC 为其特例）"。这是一处可直接回填的 README 精度修正（但属可选，非本次必须）。

## 5. 领先性判断

- **算法领先性（在 2019 语境）**：在不存旧数据、不扩网络的约束下，正交投影屏蔽比当时的 EWC/SI/IMM 给出更干净的遗忘防护，且把"容量"做成可测量的秩——这是把"防遗忘"从启发式提升到有几何/线性代数解释的一步。
- **跨学科领先性**：OWM↔RLS↔扩展卡尔曼的联系，以及 CDP↔PFC 混合选择性的对应，是少见的"算法 + 计算神经科学"双向印证。
- **范式价值（对 VZ）**：它独立地、用一个老问题（防遗忘）证明了 VZ 反复坚持的两件事——**(a) 自修改应当有界且可记账；(b) 语境应当几何化而非 prompt 化**。

## 6. 明确不应做的事

- **不把 OWM 引入 substrate 在线端到端更新**。论文里的端到端 CIFAR 用法违反 R2，是反例不是范例。
- **不把 OWM 当作 VZ 持续学习的整体方案**。它是单层定容、会被 `rank(P)` 耗尽的局部机制；VZ 的持续学习是多 stratum + 多时间尺度 + 可回滚的系统级答案。OWM 顶多是某个 stratum 内一个 adapter 的更新几何候选。
- **不新建 `OWMModule` / `OWMMemory` 之类的独立模块**。若未来吸收，只能作为既有 owner（如 `vz-substrate` adapter-delta 入口或 `vz-temporal` 控制器）内部的一个**有界更新算子**，并先落 `docs/DATA_CONTRACT.md` 的 slot 注册与 `WiringLevel`。
- **不把论文 benchmark 数字转写成 VZ 性能 claim**。它们只支持设计原则。
- **对外叙事里不得把 OWM 归到杨柳博士名下**，也不得用 OWM 替代/混淆我们真正的主动学习理论支柱。

## 8. 结论

OWM（Zeng et al. 2019）是一篇值得放进 VZ research 视野的持续学习论文，但它的角色要摆正：

1. **它不在我们仓库里，也不是杨柳博士的工作**——这是本专项首先要钉死的事实。
2. **它的真正价值是两个外部结构证据**：有界自修改可以做成"正交投影 + 秩预算"（咬合 R10/R9/R2、Two-Gate）；语境可以做成"特征空间几何旋转"而非 prompt 标签（咬合 R14/R7/R3-R4，呼应 persona-as-geometry）。
3. **它的端到端 substrate 用法是 R2 的反例**，只能在控制器/adapter 层借其几何，绝不照搬到基底在线训练。

一句话：**OWM 是别人用一个老问题，替我们再次验证了"有界、可记账、几何化"这条路是对的；我们借它的原理与算子，不借它的越界用法，更不借它的署名。**
