## 1. 一页摘要

这 95 分钟材料的中心不是某个具体产品，而是一套彼此咬合的取舍：

- **目的**：DeepSeek 把 AGI 视为主线；C 端聊天、B 端 API 和阶段性收入是技术推进过程中的产物，而不是反过来决定研究方向的目标。
- **组织**：愿景和共识比 KPI、层级与创始人命令更重要；唯一明确不能牺牲的核心利益是团队稳定。
- **竞争策略**：开源、低价和不过度占有产业价值既是价值取向，也是降低阻力、提高做成 AGI 概率的长期战略。
- **技术路线**：语言模型 → 思维链 → Agent → 持续学习 → AI 辅助迭代 AI → 具身智能。材料把“持续学习”视为 Agent 之后真正的关键瓶颈。
- **资源判断**：中国与美国头部模型的主要差距被归因于算力和实验次数，而不是人的智力；效率优化可以缓解差距，但无法消除总资源约束。
- **国产算力**：高级编译层和 AI 辅助编程可能削弱 CUDA 生态壁垒；即便软件生态改善，芯片性能、能效与产能仍是硬约束。
- **商业化**：商业化不是被拒绝，而是被安排在 AGI 主线之下。合理利润、现金流和 API 业务的作用是让研究组织长期活下去。

把这些观点串起来，可以得到一条更精确的逻辑链：愿景凝聚研究团队；团队把精力集中在智能主线上；开源和克制降低外部阻力；低成本同时扩大社会使用和内部实验能力；API 把中间成果换成现金流；现金流再转成算力和稳定团队；最终目标仍是持续学习与 AGI，而不是最大化某一代产品的市场份额。

## 2. 按视频顺序的详尽转述

> 时间标记是为了方便回看目标视频而给出的近似主题区间，不应当作原始 3 小时 44 分钟会议的时间戳。

### 00:00–约 06:00：创立初衷、愿景驱动和“克制”

开场先解释公司为什么存在。材料中的发言认为，最初参与公司的人不是为上市、资本市场或最终赚多少钱而来；更接近的共同动机，是相信人工智能对人类有用，愿意做一件超越金钱回报的事情。后来技术对应的利益越来越大，诱惑必然出现，但若忽略最初动机，就无法解释公司后来的许多选择。

对组织管理的判断也由此展开。大公司不能只靠规章制度和考核运行，真正把人组织起来的是愿景。这里的愿景不是墙上的标语，也没有被写成一份严密宣言；它体现在实际决策、工作方式和对待外部世界的态度中。不同成员的理解会有差异，但大方向应当相容。DeepSeek 因而被描述为一个愿景驱动、传统组织结构较弱、较少依赖 KPI 的团队。这种模式有明显缺点，规模扩大后也必须调整，但它解释了早期团队为何能聚合。

开源被放在同一个框架里。发言不是把开源说成竞争压力下的妥协，而是愿景的自然要求，也是一种宏观商业判断：AI 可能影响人类经济中极大的部分，没有任何一家公司能够长期独占全部收益。越试图把利益全部攥在手里，越可能招致竞争、社会与监管阻力，反而降低成功概率。于是“克制”不是放弃商业，而是主动限制自己索取利益的范围。

材料强调，团队起点并没有特别多的钱、算力、名气或号召力，也不把成员描述成不可替代的天才。它偏好“一群平凡的人做出不平凡的事”的叙事。愿景与克制被视为让普通成员形成合力的关键，而不是事后包装出来的文化故事。

### 约 06:00–12:00：API 定价、合理利润与为什么不追 C 端流量

API 定价的出发点不是利润最大化。材料给出的内部口径是：买入一批服务器后，大约十个月收回设备成本，就可视为足够合理的回报。服务器在财务上可能按三至五年折旧，但公司还承担前期研发、运营和需求风险，因此十个月回本被认为已经满意。这个数字来自网传转写，不能当作正式财务指引。

发言还举了一个模型降价的例子：因为一开始担心需求过大，价格定得较高；后来大幅降价，团队内部反而很高兴。原因是他们希望自己花大量精力做出的模型既有效又足够便宜，让更多人能够充分使用。只要公司获得可持续的合理利润，价格就不应被推到用户仍勉强愿意接受的上限。

为什么不继续无限降价？材料的回答是需求弹性。当价格已经低到大多数用户不再因价格而减少使用时，进一步降价既不明显增加需求，也不显著增加社会价值。低价是手段，不是脱离成本和需求的姿态。

同一套克制逻辑也解释了 C 端策略。用户在某个时间点突然增长时，公司没有把自己改造成流量竞争者，也没有把目标设成下一家字节或腾讯。C 端用户需要被服务好，也可能成为长期资产，但不值得为了抢一个入口而停下 AGI 主线。材料用“前面是芝麻、后面还有西瓜”来表达这种排序：芝麻可以顺手捡，却不应让组织忘记更大的目标。

### 约 12:00–18:00：开源为什么不必摧毁商业模式

材料认为最强模型也可以继续开源，且开源版与自用版不应故意制造能力差。理由之一是，即使权重或原理公开，第三方仍需解决部署、算子、集群、延迟、稳定性和成本控制，公开设计不等于每个组织都能以同样成本提供同样服务。

DeepSeek 想建立的壁垒不是单纯藏住权重，而是以更低的综合成本运行同等质量的模型。如果自己的部署效率足够高，又只获取合理利润，独立第三方未必能在价格上形成优势。只有当公司企图获取极高垄断利润时，开源才会直接破坏那种利润结构。

因此，公司不仅不必害怕别人部署开源模型，还可以帮助社区正确复现，避免因为工程细节错误而得到更差效果或更高成本。市场足够大，应用、数据和行业价值可以由更多伙伴创造；基模公司没有必要把所有环节和收益都内部化。

### 约 18:00–24:00：AGI 阶梯、Agent 与持续学习

这部分提出整段材料中最重要的技术路线：

1. 语言模型提供基础表示与生成能力；
2. 思维链让模型在输出前进行更多内部计算，提高复杂任务能力；
3. Agent 在模型与思维链之上调用工具、执行长任务并扩大可完成工作的范围；
4. Agent 接近当前范式上限后，真正的瓶颈转向持续学习；
5. 持续学习若成立，模型就可能在长期经验中改进，并帮助研发下一代模型，使 AI 加速 AI 研究；
6. 在更强智能和自我迭代基础上，再进入具身智能，处理家务、养老和其他现实世界的人力需求。

材料区分“上下文内表现”与“长期成为组织成员”。今天的模型在上下文充分、指令清楚时，许多任务已经可以超过普通人甚至专家；但人进入公司后，会在数周或数月里逐渐理解同事、流程、隐含惯例和历史原因。AI 每次都需要别人重新解释这些背景，就很难真正融入长期工作。这个差距不是简单把聊天记录无限拉长，而是要让系统从经验中更新，同时避免遗忘、噪声污染和错误累积。

“奇点”因此被描述成连续但非线性的过程，而非某一天突然打开的开关。当 AI 开始显著提高下一代 AI 的研发效率时，反馈回路会让曲线变陡。持续学习被放在路线中心，并不意味着会议已经给出了解法；相反，材料明确承认它同时包含算法与工程难题，全球尚未完整解决。

### 约 24:00–31:00：C/B 端是中间产出，团队稳定是唯一硬边界

做 AGI 会自然产生可以服务用户的阶段性能力。把这些能力做成 C 端产品或 B 端 API，不需要把研究目标改写为“服务某类客户”；它更像用中间产出换取现金流。材料甚至认为，专注更高的技术目标会对阶段性产品形成某种“降维”优势：更强愿景能凝聚人才，而技术进步又自动提高产品能力。

这并不表示产品、用户体验或企业客户不重要。区别在优先级：商业化发生，但商业目标不反向控制基础研究路线。过去突然获得大批 C 端用户、后来 B 端增长被看作该策略可能有效的证据，而不是转向流量或销售组织的理由。

在可以克制的诸多利益之外，材料只划出一个不可退让的核心：团队稳定。逻辑是，资金、资源和一次实验失败都可能通过时间补回；核心团队离开则会带走很难写进论文、代码或文档的共同经验。只要关键成员仍愿意一起做，挫折意味着晚半年或一年，而不是主线永久中断。融资和期权的一个重要作用，便是降低团队流失风险。

### 约 31:00–38:00：合作边界、世界模型、多模态与什么才是“智能主线”

材料主张尽量不把互联网大厂或其他模型公司定义为敌人。只要利益边界允许，即使被视作竞争者，也可以帮助对方复现开源成果。DeepSeek 只专注自己认为属于 AGI 的智能主线，其他应用和产业环节交给伙伴完成。

视频生成、3D 和部分“世界模型”研究被放在主线之外，不是因为这些方向没有商业价值，而是发言者判断它们当前并不是抬高智能上限的必要步骤。多模态会做，对 C 端也很重要，但更像组件，类似搜索能力；它并不自动等于智能主线。

这是一项带有强烈路线偏好的判断，而非已被证明的普遍定理。材料自己也承认，不同公司可能拥有不同路线图。其真正想表达的是：一个方向很热、很好卖或被市场视作“AI 公司必须做”，不足以让它自动成为 DeepSeek 的研究优先级。当前更重要的是把训练做好，然后解决持续学习。

### 约 38:00–44:00：中美差距首先是算力和实验次数

材料把与美国头部 AI 公司的最大差距归结为资源，而不是人的智力。人才流动有很大随机性，中国并不缺聪明人；但算力少意味着能训练的模型更小、能做的实验更少，也意味着研究人员缺乏通过大量失败实验形成经验的机会。所谓人才差距的一部分，实际是实验预算差距的下游结果。

网传数字称，当时 DeepSeek 约有两万张 H 系列等效算力，且不少是近期到位；美国最大模型的激活参数可能达到约 800B，而国内仍多在几十 B；训练相近规模可能需要约五万张 GB300 或二十万张某国产卡。这些具体数字高度敏感且易受识别错误影响，不宜脱离原始上下文引用。相对稳定的观点是：当前资源仍不足以对最大规模模型做充分研究，融资到账后，若价格合理，优先把资金转化为可产生实验和服务能力的算力。

材料并没有因为资源受限就否定 Scaling。模型尺寸更小主要是资源约束下的选择，不是判断 Scaling 已经结束。短期策略是在能够承担的规模上做更多实验、提高效率，等资源增加后再扩展激活参数规模。

### 约 44:00–50:00：模型竞争的终局与国产芯片机会

材料把模型公司的长期差异归纳为三项：成本、时间和用户体验。成本是以多低的总成本提供同等质量；时间是同样能力能早几个月还是晚几个月做出；体验会形成黏性，但相较前两项不那么本质。比较模型能力必须把成本放在同一水平线上，否则结论并不公平。

国产芯片的机会来自软件生态可能出现松动。过去的障碍不仅是芯片本身，还包括 CUDA 的成熟工具、算子与工程经验。AI 辅助编程和 TileLang 一类更高级的编译/算子描述层，可能降低为不同硬件重建软件栈的成本。若模型实现不再深度绑定单一厂商底层生态，同一套上层表达便更容易迁移到国产硬件。

不过，材料没有说国产芯片已经等同英伟达。其更谨慎的判断是：生态“不好用、用不起来”的问题可能先改善，随后产能、单卡性能、能效和交付规模会成为更硬的约束。网传的“四张顶一张”“落后两年”等换算只能视为未经证实的现场估算。

### 约 50:00–58:00：不做全产业链，以及为什么产品规划不能过早

DeepSeek 会自建大规模集群，因为这直接属于模型训练与服务能力；但是否自研芯片，取决于市场能否以合理价格提供硬件，以及自己进入上游能否产生足够收益。材料用“运营发电厂不必自己造发电机”的类比说明，垂直整合并非天然正确。市场足够大，一家公司只需把最擅长、最关键的一层做好，也可能获得很大价值。

同样的选择也适用于下游。广告、电商、本地生活或垂直行业应用在某个时点可能看起来是合理商业路径，但技术变化太快，半年以前制订的产品规划很可能迅速失效。过早把组织改造成商业产品公司，会消耗最宝贵的研究注意力，并把路线锁在寿命很短的假设上。

材料并非主张永远不商业化，而是认为彻底转向以商业化为中心的时点还很远。现有 C 端和 B 端已经证明商业化在发生；更多应用则可以让生态伙伴去做，让产业价值分散在更广的参与者中。

### 约 58:00–65:00：共识决策、竞争格局与合理利润的均衡

公司重大技术和业务决定被描述为建立在共识上，而非由创始人单方面发号施令。管理者可以引导，却无法让团队长期投入一件他们不认可的事。创始人的权威也来自大家对判断的持续认可，而不是职位本身。

在行业竞争上，Anthropic、OpenAI、Google 等公司的领先可能是交替的。某家公司在 Coding Agent 上先发，不等于永久全面领先。中国在全球 AI 供给中的结构性优势可能主要表现为成本和产品体验：电力、制造和互联网产品经验，加上资源约束倒逼的效率优化，可能使中国成为高产量、低成本的一极。

“只赚合理利润”也被描述成竞争均衡。想抽取更多产业价值的公司，会受到愿意收取更少利润的竞争者挑战；而价格低到无法生存也不可持续。长期结果并非零利润，而是找到足以支持研发、设备与风险的合理回报。

### 约 65:00–73:00：Scaling、效率、数据和持续学习研究

多模态会进入后续模型，但 Scaling 仍然成立：更多参数、更多训练与更好数据通常继续提高能力，当前尚不能因为美国讨论 Scaling 放缓，就推断资源更少的中国团队已经触及同一上限。

低成本同时服务两个目标。对外，它让更多人用得起模型；对内，它使同样一批卡能够进行更多训练和实验。在资源充足的组织中，很多问题可以靠继续增加算力解决；对资源受限的团队，算法、架构、部署和编译效率就是核心研究能力，而不只是商业优化。

持续学习、CoT 等未知问题不一定都需要立刻投入巨量算力。材料把部分探索形容为“摸奖”：关键可能是一种想法，需要许多人持续思考和小规模尝试，但无法提前知道谁会找到突破。大规模资源则主要消耗在正式训练、发布和效率实验中。

数据仍是关键投入。高质量标注不是简单廉价劳动力问题，真正复杂的数据工作在中国和美国都很贵，而且能力积累需要时间。融资可以扩大后训练和数据投入，却不能把多年形成的流程、人员和判断力瞬间买出来。材料还声称核心研究人员中有相当比例参与数据工作；这一数字同样需要独立核验。

### 约 73:00–81:00：组织从“无组织”走向混合结构

随着人数增加，早期极度分散、依赖默契的组织方式不可能原样保留。未来更可能是混合结构：发布、工程、运营等需要明确责任和严谨层级的部分建立正式组织；前沿研究仍尽可能保持扁平和松散。

材料将内部工作分成两条线：一条是自上而下的正式任务，例如模型发版，需要全公司协作；另一条是自下而上的自主探索，让研究人员自己判断问题并使用可用算力尝试。正式任务最好不要占满每个人的全部时间，至少应保留相当部分给自主研究。

它也不鼓励把长期加班当作研究效率来源。未知问题需要松弛、好奇心和不被排满的注意力；公司之所以能少加班，也部分因为主动不做许多非主线业务。当然，这种选择会带来产品细节不够完善等代价。

### 约 81:00–88:00：Coding Agent、具身智能、商业保底与行业收敛

近期 Agent 的优先级更偏向通用能力，尤其 Coding Agent，而不是先做金融、法律或医疗等垂直 Agent。代码是 AI 参与 AI 研发的直接入口：能理解工程、修改代码、运行实验和定位问题的模型，首先提高的是 DeepSeek 自己研发下一代模型的效率。下一代模型因而应先让内部研究人员真正觉得有用。

长期仍会走向具身智能，因为普通人的实际需求涉及吃穿住行、家务和养老，而不只是拥有更聪明的电脑。但路线顺序是先解决持续学习和 AI 辅助 AI，再借助更强系统推进机器人；这样比在智能不足时完全依赖人力开发具身技术更经济。

科研理想与资本市场并非必然冲突。材料提出一个保底场景：即使前沿技术停止进步，只把现有模型和 API 服务经营好，也可能形成足以维持公司的业务。这个现金流底座使组织可以继续追求更远的 AGI 目标，而不必把每个季度的商业机会变成研究指令。具体收入预测属于未经官方确认的信息。

行业最终可能收敛到少数几家基模公司。人才短缺会随培养而缓解，但过多公司重复做相近基模会分散算力和人才。少数充分竞争的基础模型提供者已经足以形成价格压力；应用、数据和垂直行业价值则由更广泛生态承接。

### 约 88:00–91:16：TileLang、迁移效率和结尾

最后的问题回到放弃部分 CUDA 依赖是否会牺牲推理效率。材料给出的回答是，总方向是提高而非降低效率。TileLang 等更高层语言用更少代码表达算子，重写和迁移速度更快，也为 AI 辅助生成底层实现创造条件。

在单个算子的极限执行效率上，抽象层可能带来小幅损失；网传转写提到约 1%–2%，但该数字不应视为已验证基准。发言者认为，相比开发效率、跨硬件迁移和削弱生态锁定，这种损失可以接受。目标不是立即在每个微基准上赢过手写 CUDA，而是让模型软件栈更快演化，并能在不同硬件上复用。

视频在这一技术问答附近结束。它没有覆盖完整 3 小时 44 分钟会议的全部上下文，因此不应把这份 95 分钟材料标为“完整现场实录”。

## 3. 对 Volvence 最相关的研究信号

这一节是基于材料的工程解读，不是视频原话。

### 3.1 持续学习的定义比“长上下文”更严格

材料最有价值的技术区分，是把长期适应与无限堆叠对话历史分开。模型要在工作中吸收经验、更新内部可用状态、避免遗忘和污染，并让下一次行为发生变化。这与 Volvence 的四能力轴高度相容：经历必须可追加，内部状态必须可读，更新必须有合法学习信号，干预必须能改变下一拍状态。它不能被简化为 prompt history。

### 3.2 “AI 帮 AI”需要闭环证据，而不仅是 Coding Agent 演示

Coding Agent 能提高研发效率，是可检验的中间目标；但要形成材料设想的非线性反馈，必须证明它确实缩短后续模型/控制器研发周期，并且经验能够被正确结算、追加和复用。单次代码任务成功不等于持续学习，更不等于自我迭代已经成立。

### 3.3 低成本同时是服务目标和实验能力

材料把效率与社会可及性、内部实验次数连在一起，这是比“便宜 API”更深的理解。对 Volvence 而言，受限控制器、快照交换、分频更新和 rare-heavy gate 不只是安全结构；它们还应减少每次适应的资源成本，使更多真实经历能够被结算和复盘。

### 3.4 团队隐性知识提示了语义快照的重要性

“核心团队带走写不进论文和代码的共同经验”说明，组织知识不能只停留在个人头脑或聊天文本里。Volvence 的对应问题是：owner 是否把经验命名为不可变快照，是否有明确时间尺度写入 CMS/State-KV/semantic snapshot，是否能够跨 session 恢复。否则系统会复制同一种脆弱性。

### 3.5 路线聚焦值得借鉴，但不能把判断当作事实

视频对世界模型、多模态和视频生成的排序是一个组织选择，不是科学定论。Volvence 可以借鉴“区分智能主线与商业热点”的决策纪律，却不应把某位发言者的路线偏好硬编码为架构真理。任何新增能力仍需唯一 owner、公共交换、退出条件和可回滚证据。

### 3.6 国产硬件观点的可迁移部分是“抽象层解耦”

对 Volvence 最有用的不是具体芯片换算，而是通过更高层、正式接口降低底层锁定的思想。其对应物正是 contracts、snapshot 和 WiringLevel：consumer 依赖正式交换，不依赖 producer 的内部实现；底层实现可在 ACTIVE/SHADOW/DISABLED 间迁移与回滚。
