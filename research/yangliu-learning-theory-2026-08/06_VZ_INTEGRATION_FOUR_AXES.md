## 1. 一句话总判

杨柳（Liu Yang，CMU ML PhD 2013，Blum & Carbonell 门下，Hanneke 长期合作者）的 40 篇论文对 volvence 的价值**不是可移植的算法库，而是一套"查询/标注/验证预算的数理会计学"**：她的职业主线——"与 oracle 交互的数学理论"——恰好覆盖 volvence 当前最缺理论语言的三个部位：(a) Learnable 轴 Gate 4 之后"省标签主张还能怎么立"（簇 1）；(b) C2 人类验证锚"预算多小才够、为什么只能是验证锚"（簇 1/2/4）；(c) Appendable 轴"记忆保鲜多快、consolidation 多频才统计上正确"（簇 3）。她的**负结果与正结果同等重要**：多篇下界直接构成 volvence 对外表述的禁语清单（§6）。

40 篇档位分布（以簇文档深读判定为准，索引已同步）：**A 档 16 篇**（进入直接理论模板/设计定标），**B 档 12 篇**（思想级参照），**C 档 12 篇**（背景登记，含 3 篇无公开版）。四轴覆盖：Learnable 最厚（簇 1 全部 + 簇 2 大半），Appendable 次之（簇 3 全部 7 篇均 A），Readable 有一个干净的审计理论面（簇 4），Steerable 得到一个高同构度的形式参照系（#03）加一条判词纪律元定理（#01）。

## 3. 逐轴综合

### 3.1 Learnable（最厚的一轴）

Gate 4 的 `causal not-supported`（labels-saved = −1.0）在本论文集视角下**是理论一致的结果而非工程失误**，且"下一步怎么立主张"有明确的理论指引：

1. **目标形式钉死**（#07 ↔ #25 正负对偶）：省标签主张只能挂在 **0-1 型择时决策**目标上（查询集中于符号不确定区 DIS(V) / deadzone 边界），凸目标/连续信用值估计下 minimax 判零改善。Gate 4 后继 prereg 的主判据必须是择时方向正确性，一切"信用值拟合误差省标签"表述引 #25 打回。
2. **效应量上限模板**（#09 star number + 噪声 regime 二分）：对话域证据（A1 全 CI 跨 0、v2 readout d=0.592）处于高噪声 regime——省标签只有多项式因子（≈1/ν），绝对结算量 ν²/ε²·d 依旧庞大，假设类结构不再帮忙。prereg 用该主项做 power 核算，禁止承诺指数级改善。
3. **基线纪律**（#04）：分布无关层面内容盲随机筛已近优，学习型 selector 只在数据存在"低概率高信息"结构时才赢——任何未来送标/选样 selector 的 evidence 必须带内容盲随机对照臂（`active-learning-off` 先例）。
4. **架构必然性**（#30/#31 + #16）："C1 免费 PE 主信用 + C2 昂贵验证锚"由 oracle 选择判据 `c_j/(1/2−α_j)²` 理论化——免费 oracle 只在其方向噪声率逼近 1/2 时让位（= 主线方案 §4.2 升级条件的形式化）；#16 熵下界证明 96 assignments 的信息量与 gate 策略空间的熵相差数量级，**C2 不能当学习源是信息论必然，不只是契约选择**。
5. **信用保真**（#17）：选择性清洗的信号可能比忠实噪声信号更糟——C1 arm-independent 全量入账的理论辩护，预置对未来"信用过滤"提案的反对论据。

### 3.2 Appendable

簇 3 把 Appendable 两个悬而未决的"值不值 / 多快"问题变成定理族，三层对应干净（跨用户先验 / 单用户漂移 / 非 i.i.d. 对话流）：

1. **记忆保鲜量纲**（#12/#06）：有效窗口 `√(d/Δ)`（分类型信号）或 `d^{1/3}γ^{−2/3}`（PE 型连续信号）；跟踪误差地板 `Ω(√(dΔ))`；超窗口的旧数据是负资产——**decay 的第一性理由，不是容量妥协**。#12 的自适应扩窗统计量（向过去扩窗直到最优拟合失配超出 Θ(d·log m) 噪声线）是全论文集唯一"信号合法 + 无需漂移率先验 + 任意 VC 类适用"的即插构件。
2. **cadence 的统计必要性**（#06）：β-mixing 相关流上有效样本量 = m/k，间隔化更新是收敛率层面的正确做法，每 turn 同频更新可以是零统计收益；调度间隔应随运行时长按幂律增长。副产品：C3 的 episode 终局稀疏信用天然完成去相关——S3-E"稀而准"获得第二重理论解释。
3. **群体先验闭环的存在性与死刑判决**（#08/#10/#15/#21）：每用户 d 个证据即可辨识群体先验、新用户适应成本可压到"先验已知"水平（远期 warm-start 包的理论存在性）；但估计速率随维度以 `T^{−Θ(α²/d²)}` 崩塌——**群体级个人化在原始残差空间是数学死刑，16 维 typed readout / rank-3 z_t 低维架构因此获得统一辩护**。#10 可辨识性定理证明 P2 盲判归属的多 probe 成对设计是必要而非偶然。
4. **保留/衰减二分**（#11 ↔ #12）：环境漂移（身份稳定）→ 全保留 + 补覆盖；目标漂移 → 有界窗口 + 衰减。可接入 reflection 的 consolidation 决策依据。

### 3.3 Readable

簇 4 把 volvence 已有的证据纪律（预检零新增 GPU、formal 才烧大预算）升格为第一性框架：

1. **testing ≪ learning**：验证一个性质的固有代价与学出该对象的代价是两个量，前者常低一个多项式量级——"先花小钱确认值得花大钱"是定理不是口号。但 dictator 反例警示"验证便宜"须逐性质论证，被动只读预检的预算下限是 √ 型。
2. **预检的预检**（#14 testing dimension）：不变量 7 的分辨力预检本质是两假设族判别问题，冻结门槛时应附功效论证（给定 n 与效应量，判别功效 ≥ 1−δ）；A1 的 v1→v2 教训（d=0.315→0.592）可读作"换观测通道降低有效 testing dimension"的实例。每个预检配 shuffled/swapped 负对照臂（不变量 8 同模板）。
3. **验证预算量级公式**（#23）：learn-then-validate 分解——validate 预算 O(1/ε·log(1/δ)) 与被验对象复杂度无关；heldout 全对按 rule of three（err ≤ 3/n）反推最小可检效应；带噪双标注按 ε⁻²(1−2η)⁻² 定对数。
4. **单侧错误公理**（#14/#05）：审计工具优先"报告违规必真、报告通过存疑"的单侧保证——与 `evaluation.md` 的"未触发 ≠ 安全证据"合流。

### 3.4 Steerable

1. **结构同构参照系**（#03 reliable active apprenticeship，ALT 2025）：与 steering gate 的"大量自主行动 + 极少昂贵可信查询 + 可靠性要求"结构同构成立，但六处失效点必须随引随注，其中最要害的是 **reliable 语义漂移**——论文的 reliable 是"不查询时动作最优"（最优性），volvence 的 strict noop 是"不干预时零改动"（安全性），混同即夸大 Steerable 的保证等级。正贡献：Theorem 9 查询下界 `Ω(e + Δ⁻²log(1/δ))` 证明任何可靠性主张必然消耗查询预算——C2 pilot 范围限定的理论正当性。
2. **判词纪律元定理**（#01 bandit 不可判定，COLT 2023）：完备可学习性刻画在 ZFC 内不存在 ⇒ 主张只能是"子族 × 判据 × 判词"三元组。volvence 的"可以说/不能说"口径（charter §8、A1 判词限定为"v1 readout 下无净增益"）由此从工程审慎升格为数学必然。引用即驳回一切全称学习能力判据提案。
3. **远期表示候选**（#18 椭球二阶摘要）：低秩椭球（中心=决策、形状=不确定性）是连续 DIS(V) 的实现路径，登记备查，无近期落点。

## 5. 明确不借鉴项（与理由）

1. **#03 的核心环路"查询 → 收缩版本空间 → 学习"**——被 C2 的 `learning_use_authorized=false` 在契约上切断（`steering-human-anchor.md` §1）；一切专家反馈进学习环路的转写近期不合法，只能落在验证侧。
2. **#34 原文的"主动选出的标注直接用于后验更新"**——同上，违反 Learnable 轴"只从 PE/credit 学习"；只迁移其选样思想，不迁移其更新步。
3. **#31 的加权多数投票与在线自适应预算**——独立错误假设对双专家标注系统性失效（共享文化偏差；κ 门恰是独立性假设的替代品而非近似）；且跑中调整预算违反 prereg 冻结纪律（§0 不变量 3），curriculum 只能作为静态阶梯预注册。
4. **#33 的"表示与下游任务联合优化"路线**——volvence 刻意走反面（冻结基底 + lineage 冻结 reader，R2），用联合最优性换可审计性与可回滚性；#33 作为对照系登记，帮助说明这是自觉选择。
5. **#18 的满秩椭球更新**——高维残差上 O(d²) 不成比例，且换学习器须走新 prereg，无证据显示 REINFORCE 是瓶颈。
6. **#05 的图算法向"快照依赖图审计"的字面迁移**——查询模型与距离语义均无对应物，当前 slot 图数十节点全遍历平凡；只保留方法论三件套（局部见证分解、倍增分桶、预算封顶显式 ⊥）。
7. **#17 的 Subroutine 1 式"标签清洗"**——信用分布保真优先于逐点清洗；tournament 候选选择模板仅当裁决标签取自 N+1 PE 免费面时合法。
8. **一切把本论文集速率/常数当保证引用的做法**——见 §6 总注。

## 6. 诚实边界（合并禁语清单）

对外表述（thesis、README、评审抗辩）中**不能讲**：

- "主动学习一定省标签"——改善与否是（噪声模型 × 假设类结构 × 目标形式）三元函数；s=∞ 的类 realizable 下与被动同阶（#09）。
- "高噪声下省标签是指数级"——只有多项式因子；对话域现状正处高噪声 regime（#09）。
- "连续信用/PE 改善量的估计可以靠主动调度省预算"——凸目标 proper AL minimax = 被动率（#25）。
- "小样本专家标注可以顺便当学习信号"——熵下界判死（#16）；这也是 C2 定位的信息论根据。
- "记忆系统能让平均误差随时间趋零"——恒速漂移用户上数学为假；充要条件是 ΣΔ_t = o(T)（#12）。
- "个人化增益可以任意大"——被 `√(dΔ)` 地板与 O(d log T) 无记忆基线双向压缩（#11/#12）。
- "每 turn 更新一定比隔拍更新学得多"——相关流有效样本 = m/k（#06）。
- "旧数据多多益善"——超窗口历史是负资产（#12/#06）。
- "我们的验证已经便宜"——testing ≪ learning 是设计原则不是现状背书；被动预检预算下限是 √ 型（#14）。
- "系统能在线持续主动学习"这类全称判词——不可判定性时代主张只能是"子族 × 判据 × 判词"三元组（#01）。
- 把 volvence 的 strict noop 说成 #03 意义的 reliable——安全性承诺 ≠ 最优性承诺（簇 2 失效点 3）。

**总注（适用于全部引用）**：本论文集定理普遍假设 i.i.d. / 独立性 / 固定分布 / 无噪 oracle / 显式假设类，volvence 的对话流、有噪人类锚、冻结 embedding 空间逐条违反；除 #06/#11/#12 显式放松非平稳、#12 扩窗统计量无需先验外，一切引用只做**量级/结构参照**，不做保证引用。理论迁移 ≠ 证据：Gate 5 / 七日 formal / Gate 4 后继的判词仍须由 prereg run 产出，本项目不改变 scorecard 一个字。
