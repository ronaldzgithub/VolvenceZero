# Basecamp Research — 深度分析

- **分组 / 成熟度**：C 生物基础模型（数据底座 / 数据飞轮）｜ 成熟度中（BaseFold 为 bioRxiv 预印本，未经同行评审；核心资产是专有数据 BRD/BaseGraph，非新模型/新方法）
- **一句话主张**：用全球生物多样性尺度的专有元基因组序列库（BRD，6B 关系知识图谱）在**推理期**补充 AlphaFold2 的 MSA 输入——**完全不动 AlphaFold2 权重**，仅靠更丰富、更进化多样的条件化输入即获得大幅结构预测提升。杠杆是**数据质量与多样性**，不是架构。
- **主要创作者 + 血统**：Geraldene Munsamy、Tanggis Bohnuud、Philipp Lorenz（BaseFold 通讯，phil@basecamp-research.com）；联创 Glen Gowers、Oliver Vince。血统出自合成生物 / 元基因组测序与数据供应链工程，而非认知/RL 一脉。
- **为何与 VZ 共振 / 对立**：**共振于 R2，且是全 roster 最干净的一例**——它把基底（AlphaFold2）整体冻结，增益**纯粹来自输入端的更丰富条件化**，是"改进输入/条件化，不改冻结基底"的跨模态硬证据。**但必须诚实**：这是有客观 oracle（晶体结构 RMSD）的**监督式单轮结构预测**，与 PE / 关系 / 双轨 / regime / 在线适应**全部无关**；公司的真正护城河是**专有数据**，不是任何可迁移的认知方法。本分析以**反证为先**，把"R2 跨模态背书"的边界与"数据即唯一杠杆"叙事的不可迁移性讲清楚。

## 1. 核心逻辑（论文级 · PDF-grounded）

### Improving AlphaFold2 with a global metagenomic & biological data supply chain（BaseFold, bioRxiv 2024.03.06.583325, 2024）
- **问题**：公共序列库（UniProt / NCBI / MGnify）据 scaling law 估计只覆盖地球生命的 <0.000001%，且偏向人/哺乳类/实验室模式物种、缺一致环境元数据；AlphaFold2 在**孤儿蛋白**（无法生成深层 MSA 的序列）上表现差 [ref 19]。能否不改模型、只用更具进化多样性的序列**补充 MSA** 来提升 AF2？
- **方法/机制（关键：冻结 AF2）**：Basecamp 在 23 国 5 大洲、覆盖 50% 全球生物群系、温度 −9~99℃、pH 1~12 的环境采样，遵循 Nagoya/ABS 协议，建成含 **6 billion relationships** 的 neo4j 知识图谱（BRD）。将 MGnify 与 BRD 用 MMseqs2 Linclust 在 50% 同一性阈值聚类，得约 **1.01 billion** 序列（239GB）的合并环境库。推理时把这些多样序列**补充进 MSA**喂给 AlphaFold2。**Methods A.5 明文："we utilized AlphaFold's default settings changing only the environmental database and template search date when computing the BaseFold structures."** —— 即**只换 MSA 检索的环境数据库 + 模板日期，AF2 权重与结构模块一字未改**。模板搜索截止日设为 2022-01-01 以与原始 CASP15 提交一致、避免泄漏。推理在 8×A100(80GB) 上跑。
- **关键结果（PDF 内具体数字）**：
  - **CASP15**：49 个常规单体靶标中 **61.22%** pLDDT 提升（增幅 0.08~24）；未提升子集平均仅差 **3.1%**；对所有 pLDDT 提升的靶标，RMSD 降低 **0.02~3.33 Å**。Table 1 头部样本如 **T1176 69.94→94.61（+24.67）**、T1113 +20.81、T1147 +18.64。
  - **CAMEO**：26 个中-难靶标中 **57%** pLDDT 提升（0.03~10.04）。
  - 整体 **RMSD 最高降低 80%**（摘要 / 讨论）。
  - **扩展性**：用 BRD@50% 与 @90% 两个库跑 395 个中-难 CAMEO 靶标，"为速度做低阈值聚类基本不损精度"（Fig 6）。
  - **下游 docking**：CASP15 T1124（MFnG）MSA 补充版与 SAH 结合打分 **−6.6 kcal/mol（AF2 仅 −3.9）**，DockRMSD **2.85 Å（AF2 9.12 Å）** —— 结构精度提升外溢到底物对接。
  - Table 2 显示多个靶标里 BRD 对 MSA 的序列贡献数显著超过 MGnify（如 T1137s2：MGnify 44 vs BRD 456）。
- **局限**：（a）只在**有晶体结构 ground-truth** 的子集上评测，提升是**部分靶标**（61%/57%），近 4 成靶标几乎无改善——补充更多序列**非单调有益**；（b）依赖大量算力构建 MSA（"large compute, time consuming"），靠降低聚类阈值换速度；（c）核心增益来自**专有不可公开复现的 BRD**，外部无法独立验证数据本身；（d）未经同行评审；（e）BaseData 白皮书（98 亿序列、Tree of Life ×10）为公司材料，**UNVERIFIED**。

## 2. 与 VZ 的关系（三视角）

> **纪律：先反证，后确证。** BaseFold 极易被读成"印证 R2 + 数据即一切"，但它只在 R2 一条轴上成立，且其"数据杠杆"叙事在 VZ 的关系域**不可迁移**——先把边界钉死，剩下的 R2 背书才可信。

### 2.1 确证（先进性背书）

- **R2（强 · 跨模态最干净样本）**：BaseFold **整体冻结 AlphaFold2**（Methods A.5 明文：只换环境数据库与模板日期，权重与结构模块不动），增益**纯粹来自 MSA 输入端的更丰富条件化**——这是"**冻结基底，靠改进 INPUT/条件化而非改基底来提升能力**"的最干净、且发生在**非语言（蛋白结构）模态**的独立验证。可直接写入 [`multi-timescale-learning.md`](../../../docs/specs/multi-timescale-learning.md)，作为 R2 命题"增益可来自更丰富输入，不必动基底参数"的跨模态合法性论据。**这是 BaseFold 对 VZ 唯一但极有价值的硬背书。**
- **R5/R6（弱-中 · 仅"数据/记忆规模与质量是杠杆"层面的呼应）**：BaseFold 证明**喂给冻结基底的检索内容质量/多样性**直接决定输出质量——与 VZ"记忆连续谱的质量决定基底可用信息量"在隐喻层共振，但 BaseFold 并无分层记忆、反思、沉淀机制，背书强度有限 → [`continuum-memory.md`](../../../docs/specs/continuum-memory.md)。
- （**诚实声明**：R-PE / R3-R4 / R7 / R9-R10 / R11 / R12 / R14 / R16-R20 在 BaseFold 中**全部缺席**。它是离线监督式结构预测，不产生运行时 PE，无 latent 控制器，无双轨，无可命名内部状态。把它读成"印证 VZ 三公理"是确证陷阱。）

### 2.2 反证（红队）

**反证 A（headline · 拆穿"BaseFold 广泛印证 VZ"的误读）：BaseFold 是有客观 oracle（晶体结构 RMSD/pLDDT）的监督式单轮结构预测，对 R-PE、关系、双轨、regime、在线适应全部沉默；它只在 R2 一条轴成立。**
- **裁决：survives（不适用）**。BaseFold 从未声称做运行时认知；它的"学习信号"是离线的、靠外部晶体结构校验的精度指标，不是 VZ 运行时持续产生、被 needs/credit 读出的一级 PE。它既不证实也不证伪 R-PE/R7/R12 等——是**沉默**，不是反例。
- **边界（写入 spec）**：引用 BaseFold 时**只取 R2 的"冻结 + 条件化"骨架**，不得据其推断任何 PE/关系/评估结论；R-PE 背书须来自 active inference / ICM 一脉（见 99），不得挂到 BaseFold 名下。

**反证 B（最值得红队的一条 · "数据即唯一杠杆"对立 VZ 的方法/控制器中心）：Basecamp 的整体叙事是——能力的主杠杆是专有数据的规模与多样性，不是架构或控制器设计；"把更好的数据塞进冻结基底"就够了。这表面挑战 VZ 在控制器/方法上的重投入。**
- **裁决：needs-boundary-condition**。在 BaseFold 的域里这是对的，但成立**前提有三**：(i) 存在客观 oracle（晶体结构）可验证"更多数据是否真的更好"；(ii) "更丰富输入"是**与目标蛋白同源、带可验证进化信号**的序列，不是任意数据；(iii) 基底已是强通用折叠器。VZ 的关系/EQ 域**三者皆缺**：没有 ground-truth oracle，"更多对话数据"不等于可验证的条件化信号，且需求是长程养成而非单轮预测。
- **边界（写入 spec）**：在 [`multi-timescale-learning.md`](../../../docs/specs/multi-timescale-learning.md) 写明——"改进输入而非改基底"(R2) **可迁移**；但"数据规模本身即足够、可省略控制器/评估层"这一推论**不可迁移**到无 oracle 的关系域。把数据杠杆与控制器学习视为**互补**而非替代。

**反证 C（"richer input 总是更好"被 BaseFold 自身数据证伪）：补充更多多样序列并非单调有益——CASP15 仅 61%、CAMEO 仅 57% 靶标改善，近 4 成几乎无变化（甚至有未提升子集）。盲目加大输入可能稀释/加噪 MSA。**
- **裁决：needs-boundary-condition**（对 VZ 是真实可借鉴的告诫）。这恰恰说明**输入丰富化必须有质量门控与适用性判据**，不是越多越好。
- **边界（写入 spec）**：VZ 在用记忆/上下文丰富化冻结基底输入时（R5/R6），必须有**只读评估**判断"本次丰富化是否真的改善输出"，并对"何时该补充、补充什么"做门控——否则会复现 BaseFold 那 39% 的无效/反效果。这点直接喂入 [`evaluation.md`](../../../docs/specs/evaluation.md) 与 [`continuum-memory.md`](../../../docs/specs/continuum-memory.md)。

**反证 D：BaseFold 的护城河是不可公开复现的专有数据（BRD），外部无法独立验证数据本身——与 VZ R8/R11/R15"可发布、可命名、可回滚"的治理理念在"可验证性"上相悖。**
- **裁决：survives（不适用）**。BaseFold 是商业数据资产，不以可治理运行时为目标；它不挑战 R11/R15，只是不提供其证据。
- **边界**：借鉴 BaseFold 时只取"冻结基底 + 条件化输入"的方法骨架，**不**借入"关键能力锁死在不可审计黑盒数据里"的形态——VZ 的丰富化来源应是可发布、可回溯的快照（R8/R11）。

## 3. 一句话定位
Basecamp Research 是 VZ **R2 在非语言模态上最干净的"改进输入而非改基底"单点背书**——BaseFold 明文冻结 AlphaFold2、只换 MSA 输入库即获大幅提升，干净证明"冻结基底 + 富化条件输入"是跨模态规律；但它是有 oracle 的监督式单轮预测、护城河是不可复现的专有数据，对 R-PE/关系/双轨/regime/在线适应全部沉默，因此它教给 VZ 的不是"更多公理被印证"，而是三件事：**把输入/记忆富化确立为与控制器并列的一级杠杆、对数据稀缺区做定向补充、并用只读评估门控"富化非单调有益"的风险**。
