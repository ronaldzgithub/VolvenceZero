# Skild AI — 深度分析

- **分组 / 成熟度**：D 前沿架构（通用机器人"基础脑"）｜ 成熟度中（公司 stealth；创始人 ICM/RMA 血统极强）
- **一句话主张**：单一通用"机器人脑"基础模型做跨形态控制，内禀动机/自监督学习是核心杠杆。
- **主要创作者 + 血统**：Deepak Pathak（ICM/好奇心）、Abhinav Gupta（CMU）。
- **为何与 VZ 共振**：ICM 是整份调研里**最直接的 R-PE 工程算子**（内禀奖励 = 前向模型预测误差）；其 54 环境大规模研究又暴露了 **noisy-TV 问题**，恰好为 VZ"epistemic / aleatoric PE 必须分离"提供了实证教训。

## 1. 核心逻辑（论文级 · PDF-grounded）

### ICM: Curiosity-driven Exploration by Self-Supervised Prediction（1705.05363, 2017）
- **问题**：稀疏/无外部奖励时如何探索；且预测误差作内驱会被环境中**不可控、不可预测**的部分（噪声）误导。
- **方法/机制**：**内禀奖励 = 前向模型预测误差**，但关键是**在何种特征空间里算**：先用**逆动力学模型**（从 s_t, s_{t+1} 预测 a_t）学一个**只编码"智能体能影响的量"**的特征空间 φ；前向模型在 φ 空间预测 φ(s_{t+1})，其误差作为好奇心奖励。这样自动**过滤掉智能体无法控制、且不影响它的环境噪声**。
- **关键结果**：在 VizDoom / Super Mario 上，几乎无外部奖励也能有效探索、跨关卡泛化；逆动力学特征显著优于原始像素/随机特征作内驱基底。
- **局限**：逆动力学特征不能保证排除所有"可观测但无关"的随机性。

### Large-Scale Study of Curiosity-Driven Learning（1808.04355, 2018）
- **问题**：纯预测误差好奇心能走多远？在多少环境里有效？失败模式是什么？
- **方法/机制**：在 **54 个环境**（Atari、Mario、Roboschool、Unity 等）上**仅用**预测误差内驱（无外部奖励），系统比较不同特征空间（像素、随机特征、VAE、逆动力学特征）。
- **关键结果**：纯好奇心常能学到有意义行为、与外部奖励常对齐；**随机固定特征意外地强**。**关键失败模式：noisy-TV 问题**——若环境含一个不可预测的随机源（如随机电视），智能体会**对噪声上瘾**、永远停在那里刷预测误差。
- **局限**：预测误差不区分**可减小（epistemic）**与**不可减小（aleatoric）**的不确定性，是 noisy-TV 的根因。

### RMA: Rapid Motor Adaptation for Legged Robots（2107.04034, 2021）
- **问题**：足式机器人需对地形/负载/磨损等**环境外参**实时适应，但这些外参在部署时不可直接观测。
- **方法/机制**：两阶段。①仿真里用特权信息（地形/摩擦等 e_t）训基策略 π(s,z_t)，z_t=μ(e_t) 是外参的 latent 编码；②训一个**适配模块** φ，仅从**近期本体感觉历史**在线估计 ẑ_t，运行时基策略冻结、只跑 φ 实时供 ẑ_t。
- **关键结果**：真实四足上**无需重训基策略**即对新地形/负载快速在线适应（毫秒级），sim-to-real 直接迁移。
- **局限**：适应被限制在 z_t 的低维流形内（这正是其安全性来源）。

## 2. 与 VZ 的关系（三视角）

### 2.1 确证（先进性背书）
- **R-PE（核心，最直接）**：ICM 把"预测误差"做成可优化的一级内禀奖励，且**在学到的、只含可控量的特征空间里**计算——与 VZ"PE 是一级信号，且应来自有意义的内部表征"几乎同构。
- **R2 + 控制器适配（强，RMA）**：RMA = **冻结基策略 + 小型在线适配控制器（只更新 z_t 估计，不动基策略）**——R2"冻结基底 + 有界自适应控制器"的干净非语言样本。
- **R3/R4（中）**：逆动力学 latent 特征空间作为控制表示，呼应"在表示空间而非原始观测上控制"。

### 2.2 反证（红队）

- **反例 A（headline）｜noisy-TV：纯预测误差是危险的一级信号**：大规模研究实证，若直接把预测误差当奖励，智能体会对**不可减小的随机性**上瘾。
  - **裁决：genuine-risk（若 VZ 不分离 PE 则真实风险）**。**边界**：VZ 的 PE 必须显式拆成 **epistemic（可减小，驱动动机）** 与 **aleatoric（不可减小，不驱动动机）**。用户行为天然含大量随机性（情绪波动、随口闲聊），若不分离，系统会"对用户的随机性永远好奇"或反复纠缠无意义波动。写入 `prediction-error-loop.md` 作为一级设计约束。
- **反例 B｜ICM 的特征空间是逆动力学学出来的、不可命名**：对立 R11 可发布内部状态。
  - **裁决：survives（不适用）**。**边界**：借"在可控量特征空间算 PE"的思想，但 VZ 的 PE 须挂在可命名的语义 owner 上（user_model / relationship_state），而非不透明 φ。
- **反例 C｜RMA 的适应只在仿真特权信息下训得**：VZ 关系域无"特权信息 + 仿真"。
  - **裁决：needs-boundary-condition**。**边界**：RMA 的"冻结基 + 低维 z_t 在线估计"结构可借，但 z_t 的训练信号在 VZ 须来自真实交互 + 软验证器，不能依赖特权仿真。

### 2.3 局部算法借鉴（算法级解耦）

1. **ICM：内禀奖励 = 前向模型预测误差，且在"只含可控量"的特征空间计算** → `prediction-error-loop.md` → 给 VZ 的内禀动机一个被验证的算子（"对能改善的关系理解保持好奇"）；**前提**：必须配 epistemic/aleatoric 分离，否则触发 noisy-TV。
2. **epistemic / aleatoric PE 分离（noisy-TV 修复）** → `prediction-error-loop.md` + `credit-and-self-modification.md` → 从根上防 reward hacking 与"对用户随机性上瘾"；**收益**：这是本 lab 对 VZ 最重要的一课。
3. **RMA：冻结基底 + 低维 z_t 在线适配模块** → `temporal-abstraction.md` + `credit-and-self-modification.md` → online-fast 控制器只在低维 latent 流形内快速适应、基底不动，天然有界安全；**前提**：z_t 维度/范围作为安全包络，越界 fail loudly。

## 3. 一句话定位
Skild 用 ICM 给了 VZ **R-PE 最直接的工程算子**（PE = 可控特征空间里的前向预测误差），又用 54 环境的 **noisy-TV 失败**给了 VZ 最重要的护栏教训——**PE 必须分离 epistemic/aleatoric**；RMA 则示范了"冻结基 + 低维在线适配"这一 R2 控制器范式。
