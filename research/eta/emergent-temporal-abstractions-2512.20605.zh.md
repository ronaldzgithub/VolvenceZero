# 自回归模型中的涌现时间抽象使层级强化学习成为可能

## 摘要

大规模自回归模型先通过下一个 token 预测进行预训练，再用强化学习微调，已经在许多问题域取得了前所未有的成功。在强化学习阶段，这些模型通过逐 token 生成新输出来探索。然而，逐 token 采样动作会导致学习效率很低，尤其是在奖励稀疏时。

本文表明，可以通过在自回归模型的内部表征中行动与探索来克服这一问题。具体而言，为了发现时间抽象动作，作者引入了一个高阶的、非因果序列模型；该模型的输出控制基础自回归模型的残差流激活。在具有层级结构的网格世界和 MuJoCo 任务上，作者发现高阶模型会把长激活序列块压缩到内部控制器上。关键的是，每个控制器都会执行一串具有行为意义、跨较长时间尺度展开的动作，并伴随一个学到的终止条件；因此，随时间组合多个控制器可以在新任务上实现高效探索。

作者展示了直接强化内部控制器的过程，即他们称为“内部强化学习”的方法，可以在标准强化学习微调失败的稀疏奖励问题上实现学习。结果证明，在自回归模型中生成和强化潜在动作是有益的，并提示内部强化学习可能是把层级强化学习实现在基础模型中的一条有前景路径。

## 引言

人工智能正在经历一场由自回归序列模型推动的革命。这类模型通常以 Transformer 为基础，先在前所未有规模的数据集上用自监督的下一个 token 预测训练。预训练后，再用强化学习微调自回归模型，可以得到在数学问题求解、科学与创造性工作助手等广泛领域中表现很强的智能体。当前，人们很关注把强化学习用于发现原始训练数据中不存在的新智能行为。

从强化学习角度看，从已经在广泛行为上预训练过的自回归模型开始，可以大幅提高强化学习效率。例如，大语言模型可以被看作拥有丰富行为先验的序列模型。自监督预训练可被视为部分可观测条件下的模仿学习：噪声被引入，中间步骤可能被遮蔽，而且任务描述、智能体奖励与目标、心理状态等潜变量都未知。这种设置使模型获得潜变量推断能力，也就是通常所说的上下文学习能力，从而能快速适应新任务和新环境。与此同时，预训练自回归模型也是丰富的动作先验，能够从一开始就采样出多样且有意义的序列，使探索更有效。

高效的长程探索是强化学习成功的关键，尤其在奖励稀疏时更是如此。这引出了自回归模型面对的一个重要问题：这些模型一次只生成一个 token，因此强化学习探索完全由 token 级变化驱动。若问题很难、奖励稀疏，并且必须先正确生成多个 token 才能得到奖励，那么仅依赖逐 token 变化进行探索往往不够。这一观察正是本文研究的中心，也解释了为什么层级强化学习长期受到关注。

层级强化学习试图利用真实世界问题通常具有层级结构这一事实：最终解可以由时间抽象动作表示，也就是能够运行较长时间、可复用的子程序，有时称为 options。人类解决问题时似乎也会使用这种时间抽象，这意味着它可能是一种高效学习方式。若这样的时间抽象子程序存在，探索就可以发生在更高的时间抽象层级上，相比逐 token 探索，搜索空间会急剧缩小。然而，通过深度强化学习发现合适子程序仍是长期难题。尽管 option-critic 等方法已经推导出策略梯度形式，但这些方法存在理论问题，并且实践中常常失败，收敛到退化 option。

本文采取另一种时间抽象动作发现路径，直接建立在自回归建模之上。基于自回归动作模型的上下文潜变量推断能力，作者假设：即使训练目标只是每次预测一个 token，自回归动作模型也会在内部激活中隐式学习时间抽象动作。由此，作者引入一个内部神经网络控制器，用来引导基础模型内部激活。关键是，该控制器通过无监督的变分推断算法学习，不需要逐时间步的抽象动作标签，这与标准模型 steering 技术不同。

## 图 1：研究概览

作者让一个元控制器 steering 预训练自回归模型的残差流激活。通过自监督的下一个动作预测，元控制器学会生成简单的线性内部控制器序列。这些控制器在时间上稀疏变化，变化由动态切换单元 `beta_t in [0, 1]` 控制。在层级结构任务中，每个内部控制器对应一个时间抽象动作，使基础自回归模型完成一个有意义的基本目标。

内部强化学习则是在元控制器发现的抽象空间中执行强化学习：把自回归模型并入环境，把残差流中的行动视为在收缩时间尺度上的动作。

## 主要结果

本文贡献可概括为五点。

第一，下一个动作预测器会自然发展出时间抽象动作表征。作者分析了 Transformer 和状态空间模型，它们被训练来预测目标导向智能体的动作，但并不知道智能体目标。结果显示，网络会在残差流激活中表示并在上下文中推断对智能体目标的信念。

第二，这些时间抽象表征可以被线性控制。在模型中层附近加入一个线性残差流控制器，就足以把序列模型转化为闭环的目标优化策略，并执行长程计划。

第三，残差流中的控制器可以按时间顺序组合，从而实现组合泛化。残差流控制器序列使智能体能以训练中未见过的方式组合多个目标。

第四，作者提出了一种新的自回归模型控制架构，可以在无监督条件下发现时间抽象动作。元控制器从序列模型残差流读取信息，并反过来对残差流施加线性控制。它学会生成目标优化控制器，且这些控制器具有时间抽象：在切换到新控制器之前，同一控制器会被应用可变数量的时间步。该方法依赖两个关键性质：一是从预训练自回归模型的残差流读取并写回；二是未来条件化，也就是训练时元控制器是非因果的，可使用通过整段序列第一遍前向得到的序列嵌入。

第五，作者提出“内部强化学习”范式。在层级任务中，它比标准强化学习微调快许多数量级。内部强化学习直接在基础模型残差流内执行强化学习：内部激活作为观测，元控制器输出作为动作。实验显示，它显著优于标准强化学习微调和强层级强化学习基线 CompILE，在层级结构任务中取得更高初始成功率和更高效的信用分配。

## 自回归模型中涌现出可线性控制的抽象动作表征

在介绍内部强化学习模型之前，作者先分析预训练自回归模型的内部激活。目标是验证：仅用下一个 token 预测训练的模型，是否能在内部激活中学习可被内部强化学习利用的时间抽象动作。

作者从零开始在行为数据集 `D` 上预训练模型。该数据集包含由不同专家智能体产生的观测-动作序列，这些专家用不同程度的随机最优策略解决任务。自回归模型可以被看作可能观测-动作轨迹的序列模型。数据集中每个样本为：

```text
(o_1, a_1, ..., a_T, o_{T+1})
```

其中 `o_1` 是初始感知观测，`a_t` 是智能体在时间步 `t` 采取的动作，`o_{t+1}` 是随后的感知观测。类似于大规模行为数据集，`D` 不包含奖励，也没有显式智能体目标或任务描述。作者希望判断自回归模型是否以及如何推断长程目标导向动作序列中的抽象模式。

实验使用两类导航环境。两类任务都具有层级结构：基础移动技能是前提，但任一任务都可以由若干子程序组合完成，而这些子程序又由常见的基础移动序列构成。具体地，作者研究了离散网格世界，以及在 MuJoCo 物理模拟器中实现的连续观测、连续动作任务，其中四足机器人 ant 必须在关节层级被控制。在两个环境中，智能体都需要按照指定顺序到达某些彩色位置。也就是说，智能体需要在子目标之间导航，同时忽略干扰物，并避开随机放置的墙。每个任务由一串子目标描述：在 ant 环境中是单个彩色位置，在网格世界中是两个连续彩色位置。本文中，抽象动作等价于向某个特定子目标移动，因此“抽象动作”和“子目标”有时互换使用。

模型在预训练任务集的行为数据上训练。网格世界使用标准因果 Transformer，ant 控制数据使用高效状态空间模型 Hawk。预训练目标为交叉熵：

```text
L(theta) =
sum_{(o_{1:T+1}, a_{1:T}) ~ D} sum_{t=1}^T
[- log p_theta(a_t | o_{1:t}) - lambda log p_theta(o_{t+1} | o_{1:t})]
```

对连续动作，`p_theta(a_t | o_{1:t})` 建模为带学习对角协方差的高斯分布；对离散动作，似然由输出 logits 的 softmax 给出。主目标是行为预测，也就是下一个动作预测；模型还被训练预测下一个观测，这相当于世界动力学建模。辅助损失权重由 `lambda >= 0` 控制。

为了判断预训练模型内部激活是否学习到与子目标相关的时间抽象，作者使用两种常见机制解释方法：线性 probe 和因果模型干预。

在线性 probe 中，作者训练线性分类器，从第 `l` 个模型 block 后的瞬时残差流激活向量 `e_{l,t}` 中解码网格世界中的智能体子目标 `g_t in {1, ..., G}`。图 3 显示，随着时间 `t` 增加，也就是当前子目标证据累积，线性解码器的概率质量逐渐集中到正确潜在子目标上。此外，线性解码似然随层深 `l` 增加而提高，并在接近 Transformer 解码器使用的最终 embedding 处达到峰值。因此，即使模型只用一步动作预测训练，也学会表示时间抽象子目标。这与序列预测器中上下文贝叶斯推断的无限数据理论一致，也为神经序列模型中的线性表征假说提供了更多证据。

在因果模型干预中，作者问：自回归模型内部表征是否可用于创建一个子目标优化策略。受 LoRA 微调有效性的启发，作者引入低秩线性残差流控制器 `U in R^{n_e x n_e}`，它在给定深度 `l` 的模型 block 之间修改瞬时残差流激活：

```text
e_{t,l} <- e_{t,l} + U_t e_{t,l}.      (1)
```

控制器参数 `U_t` 允许随时间变化。在该分析中，作者为每个子目标维护一个控制器集合 `{U^(g)}_{g=1}^G`，并使用 ground-truth 子目标标签 `g_t` 在每个时间步手动选择要应用的控制器。后续部分会去掉这些标签。

训练控制器时，在冻结 `theta` 的情况下，作者在更高最优性的行为数据集 `D*` 上，以正确子目标对应控制器为条件生成，并最小化动作预测交叉熵。`phi` 表示不属于预训练模型 `p_theta` 的控制器参数，`p_{theta,phi}` 表示受控模型。

作者在训练后 OOD 任务集上评估这些子目标优化控制器。该任务集要求长度泛化和组合泛化：子目标以预训练和控制器训练中都未出现过的顺序重组，并且轨迹更长。图 4 显示，只要按正确顺序激活相应子目标控制器，无需重新训练自回归序列模型，就可以以高成功率解决这些新任务。

进一步分析揭示了潜变量信念状态表征和内部表征控制之间的区别。线性子目标解码从中层到最终层都可行，但子目标条件化最好通过在预训练序列模型中间插入线性控制器实现。这一结果直观上合理：从跨许多时间步的抽象子目标到每步低层动作的映射，是在多个模型层中实现的。因此，除非特别说明，后文控制器都从自回归序列模型中层的残差流读取并写回。

## 无监督元控制器在自回归模型中发现时间抽象动作

上述分析表明，简单内部激活控制器可以 steering 预训练的下一个动作序列模型，使其执行时间抽象动作，也就是导航到一串子目标。到目前为止，实验假设可以访问子目标标签，这类似于当前模型 steering 方法使用详细监督信息训练。现在，作者转向更具挑战性的无监督设置：没有 ground-truth 标签，模型必须同时从未标注行为数据集 `D` 中发现时间抽象动作，并学习选择机制，生成合适的子目标序列和相关抽象动作，以达成更大目标。

为了同时学习抽象动作并编排其执行，作者在 `D` 上训练后冻结自回归模型，然后用一个元控制器增强它。元控制器可以为序列模型残差流激活生成控制器 `U_t`。如前所述，训练继续在 `D*` 上进行且 `theta` 固定。但现在不再用 ground-truth 子目标条件化控制器；元控制器必须学会在合适时间生成合适控制器。

元控制器是一个生成式随机循环神经网络，采用编码器-解码器架构，可以顺序采样控制器。因为它输出的是控制器参数 `U_t`，而不是直接输出控制向量，所以它可被视为循环超网络。解码器是前馈网络，从控制器代码 `z_t` 产生控制器 `U_t`。编码器基于 GRU，指定随机控制器代码的高斯分布均值 `mu_t` 和方差 `Sigma_t`：

```text
z_tilde_t ~ N(z_enc; mu_t, Sigma_t)
```

重要的是，编码器是非因果的，因为它接收整段潜在活动序列的嵌入 `s(e_{1:T})`。论文在附录 E.1 中用形式化潜变量建模论证了这种未来条件化。

元控制器还包括一个循环切换单元，位于编码器和解码器之间。该单元确定随时间变化的连续切换门：

```text
beta_t in [0, 1]
```

它控制前一控制器代码 `z_{t-1}` 与新采样代码 `z_tilde_t` 之间的插值：

```text
z_t = beta_t ⊙ z_tilde_t + (1 - beta_t) ⊙ z_{t-1}.      (2)
```

其中 `⊙` 表示逐元素乘法。尽管这个时间积分器很简单，但它对元控制器学会生成合适的时间抽象动作至关重要。后续消融实验证实了这一点。

元控制器参数 `phi` 通过最小化自监督目标训练。目标由低层下一个动作预测和先验匹配正则组成：

```text
L(phi) =
sum_{(o_{1:T+1}, a_{1:T}) ~ D*} sum_{t=1}^T [
  - log p_{theta,phi}(a_t | o_{1:t}, z_{1:t})
  + alpha D_KL(N(mu_t, Sigma_t) || N(0, I))
].                                                     (3)
```

其中 `D_KL` 是 Kullback-Leibler 散度。该正则项的权重由超参数 `alpha >= 0` 决定。它促使从标准正态分布采样控制器代码 `z_t` 时也能生成有意义序列；下一节内部强化学习正是利用这一性质。从信息论角度看，`alpha` 控制变分瓶颈，调节从非因果编码器流向控制器的信息量。后续分析显示，该瓶颈会把模型推向稀疏、与子目标对齐的切换模式，从而镜像底层任务结构。此外，无条件先验意味着下一抽象动作 proposal 独立于过去 proposal，这有助于形成组合表征，并与本文层级任务匹配。

最终，元控制器既发现了观测智能体行为背后的时间抽象动作，也通过切换门实现相应终止条件，从而学会在时间上正确排序这些动作。

图 6 和附录图 A3 分析了元控制器发现的残差流控制器：作者将切换门值 `beta_t` 与 ground-truth 抽象动作 `g_t` 对齐绘制。结果显示，元控制器恢复了 ground-truth 抽象动作切换时刻。训练后，切换门学会了近似二值、稀疏切换的行为，尽管目标中没有显式正则要求它这么做。考虑到层级强化学习中切换正则往往很关键，这一点尤其值得注意。对 ant 环境而言，即使观测和动作都是连续的，所得时间分段也几乎完美。此外，元控制器学会生成的潜在控制器代码对应有意义的时间抽象动作，例如“去蓝色位置”，并能泛化到新的任务配置和切换时刻。

接着，作者研究如果不冻结自回归基础模型参数 `theta`，而是把它与元控制器参数 `phi` 一起通过变分推断联合训练，会发生什么。这一基线在概念上接近此前使用变分推断从未标注示范中学习抽象的层级强化学习方法，但使用本文的神经架构。

为了比较冻结基础模型与联合训练基础模型时形成的抽象动作表征，作者进行 rate-distortion 分析：在很宽范围内改变公式 (3) 中控制 rate-distortion trade-off 的 `alpha`。对标准元控制器和联合训练元控制器分别追踪 rate-distortion 曲线。

结果很有意思：在冻结自回归模型的元控制器中，拥有子目标对齐切换的点和 rate 略低的点之间出现了水平 gap。这意味着在该 rate 水平附近，rate 的小幅增加会极大改善 distortion。相反，对联合训练元控制器而言，尽管变分目标被最小化，这种结构丢失了。对多数 `alpha`，模型收敛到退化解：只在序列最开始切换一次。

子目标对齐切换只在冻结自回归模型中对应 improved distortion，而在联合训练模型中不对应，这说明预训练会建立与抽象动作良好对齐的内部表征。它还有优化意义：对给定 `alpha`，变分目标在 rate-distortion 曲线上切线斜率为 `-1/alpha` 的点处最小。若曲线存在斜率不连续的 gap，那么对一大段 `alpha`，目标都会在子目标对齐切换区域取得最小。因此，控制冻结的自回归动作预测器是发现时间抽象动作的关键。

这一节整体提供了强证据：模型可以在自监督条件下同时学习时间抽象动作以及如何正确排序它们。下一节展示该模型如何在新且更难的任务中把探索速度提高多个数量级，使稀疏奖励强化学习成功。

## 内部强化学习

作者最后研究如何利用该模型通过层级强化学习学习更难任务。实验只考虑挑战性的稀疏奖励设置：每条轨迹最多只在完整子目标序列正确完成时得到一个正成功奖励。

首先，作者确认这些任务对标准强化学习后训练而言确实困难。他们研究了 GRPO 算法的一个适配版本，这是稀疏奖励设置中的强基线。对本文任务，从零开始直接用强化学习训练智能体几乎没有成功机会。因此，为公平比较，作者把 GRPO 应用于预训练自回归序列模型，类似当前对大语言模型所做的 RL 微调。即使如此，尽管预训练序列模型已经在与子目标相关的动作序列上训练过，通过输出 token 层随机采样生成成功轨迹的概率也极小，约百万分之一。这使 GRPO 训练失败，因为模型得不到足够学习信号。

检查自回归序列模型生成的动作序列可以看到：模型会复现训练数据中出现过的动作序列，却不能在更高时间抽象层面探索，而这正是解决这些稀疏奖励任务所需的。换言之，仅用策略梯度训练序列模型不会使系统探索新的子目标组合。

内部强化学习的关键步骤是把自回归序列模型视为环境的一部分；动作对应残差流干预 `u_t`，观测对应残差流激活 `e_{t,l}`。直接在残差流层执行强化学习本身很难。若从零学习一个策略：

```text
pi(u_t | e_{1:t})
```

其输出 `u_t in R^{n_e}` 加性控制残差流：

```text
e_{t,l} <- e_{t,l} + u_t
```

且不依赖反向传播穿过受控基础模型，那么这就是一个高维连续控制问题，是强化学习中极难的设置。

内部强化学习不直接学习残差流控制策略，而是在元控制器通过自监督训练后，在控制器代码空间 `z` 中执行强化学习。这假设元控制器已经学到有意义的切换单元 `f_switch`，以及一个控制器代码空间，使得：

```text
z_t ~ N(0, I)
```

成为采样抽象动作的有意义先验。

直观上，元控制器避免直接在残差流中做强化学习的两个问题：一是动作空间维度降低，`n_z < n_e`；二是元控制器在抽象时间尺度上运作，显著缩短困难环境中的有效时间 horizon。第二点是内部强化学习在层级稀疏奖励任务中更高效并成功的关键。

更具体地，内部强化学习会把使用特权未来信息 `s(e_{1:T})` 的无监督控制器编码器，替换为因果抽象动作策略：

```text
pi(z_t | e_{1:t})
```

然后通过强化学习训练它，同时固定所有其他模块及其参数。概念上，这等于把自回归模型以及元控制器的一部分并入环境。

为了生成离散切换事件，作者还对切换率做阈值二值化，即把公式 (2) 中的 `beta_t` 替换为：

```text
H(beta_t - beta_threshold)
```

其中 `H` 是 Heaviside 阶跃函数，`beta_threshold` 是超参数。这样，在元控制器发出切换信号之前，同一个抽象动作都会持续应用，使 `pi` 能在时间抽象尺度上操作。

图 8 显示，内部强化学习在训练后任务集上取得高成功率。利用自监督元控制器学习发现的时间抽象是成功的关键：当禁用时间积分单元，也就是强制所有时间步 `beta_t = 1`，内部强化学习失败。为了公平，该消融在自监督元控制器学习阶段就引入，而不是只在后训练 RL 阶段引入。

值得注意的是，`beta_t = 1` 消融也有较高初始成功率，在 log-scale 图中可以看到。但只有完整的时间抽象内部强化学习同时具备高初始成功率和高效信用分配，因此强化学习才能真正成功。附录 E.2 给出数学论证，比较内部强化学习与原始动作空间强化学习的策略梯度方差。

此外，为评估自回归动作建模形成的内部抽象，作者也比较了联合训练基线，即元控制器和基础模型共同通过公式 (3) 最小化训练。与 rate-distortion 分析一致，训练后内部强化学习成功率仍接近零。CompILE 也如此。CompILE 是此前提出的、也从未标注行为数据中用变分推断发现时间抽象动作的层级强化学习方法。结果再次确认：先进行自回归基础模型预训练，再冻结基础模型，对实现高效层级强化学习很重要。

## 讨论

本文提出的问题是：自回归序列模型的潜在表征能否用于发展强化学习技术，从而克服逐 token 探索与强化的低效。作者用包含多个可组合子目标的任务研究这一问题。首先，他们证明，在较简单任务上由智能体产生的动作和观测序列训练出的自回归序列模型，会在隐藏层中学习携带子目标信息的表征。然后，他们展示如果给内部控制器提供 ground-truth 子目标，这些潜在表征可被用于通过时间上的组合泛化解决更复杂任务。接着，他们开发了一个用元控制器在没有 ground-truth 子目标标签时选择合适时间抽象动作的模型。最后，他们证明，直接强化元控制器生成的内部激活控制器，可以在其他强化学习技术失败的更复杂层级稀疏奖励任务中实现学习。总体而言，结果证明自回归序列模型的潜在表征确实可用于高效层级强化学习。

关于自回归下一个 token 预测器能否形成一致时间抽象和计划，长期存在争论，有些研究者将其贬称为“随机鹦鹉”。本文为这个问题提供了正面证据。作者选择的强化学习环境具有智能体研究中的几个关键性质：要掌握这些环境，智能体必须能够重新组合既有行为、从稀疏奖励学习，并通过模仿学习推断与再利用其他智能体的目标导向行为来克服奖励稀疏。

从稀疏奖励学习可以说是强化学习的终极设置，涵盖数学推理、机器人操作和科学发现等最雄心勃勃的领域。在不依赖手工 reward shaping 的情况下解决此类任务，是迈向能在复杂开放搜索空间中自主行动的智能体的重要一步；在这些空间中，中间进展的定义往往未知。

尽管实验环境相对简单，它们对标准强化学习方法仍足够困难，包括 GRPO 和 CompILE 都失败了。本文报告的内部强化学习相对基线的巨大优势仍需谨慎看待，因为实验设置是受控的。把内部强化学习研究并适配到更大规模模型和任务，是重要未来方向。

已有许多工作分析自回归模型内部表征，寻找时间抽象与计划。近期研究为让 LLM 写押韵诗时存在计划提供了证据；更早的 probing 工作发现隐藏状态对短期未来 token 有预测力。另一类工作关注在受控环境中从零训练的模型，如 Othello 或国际象棋。作者认为，本文是首次考虑具有隐藏离散层级任务结构的连续环境。尽管模型通过梯度下降训练并只使用连续单元，基础 SSM 下一个 token 预测器和元控制器仍发现了底层离散潜在任务结构。特别是，元控制器发展出稀疏、近似二值的切换单元。

这些发现也补充了近期对端到端强化学习训练的卷积 LSTM Sokoban 策略的分析。那些研究显示，强化学习会形成跨多个时间步展开的规划子程序，这类似于本文在自监督自回归模型中发现的目标到达策略。本文的补充之处在于关注由下一个 token 预测训练的自回归 Transformer 和 SSM，这是当前人工智能系统的主力形式。

Schmidhuber 曾提出，一个 wake-sleep 训练循环若在自监督学习训练历史压缩器和强化学习利用压缩器内部表征生成新经验之间迭代，将获得越来越复杂的能力，包括形成和利用时间抽象与计划。本文给出了符合这一哲学的具体神经架构，并提供实验结果支持这些主张。有趣的是，大规模模型中也开始出现 SSL 与 RL 交替的收益。例如 DeepSeek-R1 训练也包含一次 RL-SSL 循环，尽管其 post-RL SSL 阶段还涉及人工筛选，且 RL 仍发生在原始输出动作层。

本文模型也与 LeCun 的 JEPA 有相似之处。本文元控制器类似 JEPA 中的 configurator 模块，二者都负责调制通用世界模型和策略以服务特定目标或任务。不过，JEPA 是一种不依赖自回归预测模型而学习抽象观测和动作表征的提案，而下一个动作预测恰恰是本文方法的中心。事实上，作者表明，学习原始动作预测器正是发现如何把任务分解为子目标序列的部分原因，而这正是 JEPA 提案中的开放问题之一。

本文中内部强化学习相对标准强化学习微调的巨大优势，需要在真实世界环境中进一步研究。一个尤其值得追求的方向是 LLM 推理。当前越来越多推理方法尝试利用 LLM 内部表征，主要探索神经激活空间中的循环迭代。本文元控制器模型与这些努力互补，也可能受益于额外循环。它的关键创新不是简单的 recurrent computation，而是发现能动态压缩时间的潜变量。这有潜力切缩推理问题的搜索空间，从而提高强化学习效率，就像在本文问题中显著提高效率一样。

最后，本文结果为大规模模型可解释性与控制开辟了新路径。类似稀疏自编码器，本文元控制器可以通过可扩展自监督学习训练，并使用编码器-解码器架构。但二者也有显著不同。稀疏自编码器训练目标是瞬时内部激活重构；元控制器则是预测性和干预性的，训练目标是通过干预残差流直接降低输出下一个 token 预测误差。此外，元控制器保持内部状态，而稀疏自编码器是瞬时的。因此，如果目标是基础模型控制，元控制器在设计上可能更适合，并提供了发现可解释、可持续一段时间的干预的可能性。作者期待研究这些能力能否迁移到 LLM 等更大规模模型。

## 附录 A：环境与任务设计

附录 A 详细说明了网格世界和 ant 连续控制环境。两个环境都把任务构造为一串子目标。智能体需要按顺序访问指定颜色目标，并忽略干扰颜色位置，同时避开墙体。网格世界是离散状态与离散动作；ant 环境是连续观测与连续动作，需要在关节层控制四足机器人。

任务被分为预训练任务和后训练任务。预训练任务用于收集无标签行为数据，其中只有观测-动作序列，没有奖励、任务描述或子目标标签。后训练任务使用更长的子目标序列，并以训练中未出现过的组合方式重排子目标，用于测试长度泛化和组合泛化。论文的核心实验故意使后训练任务在逐 token 探索下极难，因为成功轨迹需要先正确完成多个子目标才能得到奖励。

对 ant 环境而言，低层动作是关节力矩或连续控制信号；抽象动作是完成如“去红色位置”“去绿色位置”等子目标。对网格世界而言，低层动作是离散移动，抽象动作是访问一个或两个连续颜色目标。

## 附录 B：机制解释实验补充

附录 B 给出线性 probe 和因果干预的更多实验细节。线性 probe 训练线性分类器，从不同层、不同时间步的残差流激活中解码当前子目标。结果表明，随着观测历史增长，模型对当前子目标的隐式 belief 逐渐变准；随着层深增加，解码性能提升，并在中后层保持较强。

因果干预实验通过在残差流中插入低秩线性控制器来测试表征是否可被控制。若控制器只在输入层或过浅层注入，效果较差；在模型中层注入效果最好。这说明内部表征不仅可读，而且可作为可控接口，把抽象目标映射到低层动作生成。

附录还分析了元控制器发现的 controller code。结果显示，学到的 code 与语义上可解释的子目标相对应，并能在新空间配置和新切换时刻泛化。这一点对内部强化学习很重要：若 `z` 空间只是过拟合训练轨迹，后续在 `z` 空间探索不会高效；实验表明 `z` 空间具有可组合的抽象结构。

## 附录 C：训练、优化与强化学习细节

附录 C 给出数据收集、预训练、元控制器训练、GRPO 基线、CompILE 基线和内部强化学习算法的实现细节。

预训练阶段最小化动作预测损失，并可加入下一个观测预测辅助损失。作者比较不同 `lambda` 以分析世界建模辅助项的作用。元控制器训练阶段冻结基础自回归模型，仅训练控制器相关参数 `phi`。这一区分是论文的关键：rate-distortion 分析和后训练强化学习都显示，若不冻结基础模型而联合训练，抽象结构更容易退化。

内部强化学习的环境定义如下：

- 观测：基础自回归模型给出的残差流激活；
- 动作：抽象控制器代码 `z_t`，而非原始动作 token 或残差向量；
- 环境动力学：原始外部环境、冻结自回归模型、控制器解码器、切换单元共同组成；
- 时间尺度：由二值化切换门决定。切换之前同一 `z` 持续作用，因此策略只需在抽象段边界上选择新动作。

基线包括：

- 标准原始动作强化学习微调；
- CompILE，一种从未标注演示中学习层级结构的强基线；
- 禁用时间积分单元的内部强化学习，即强制每步切换；
- 元控制器与基础模型联合训练的版本。

实验显示，这些基线在百万 episode 规模内都无法解决任务，而完整内部强化学习可以成功。

## 附录 D：模型架构

附录 D 描述了基础自回归模型、元控制器和内部强化学习策略网络。

基础模型在网格世界上使用因果 Transformer，在 ant 控制上使用高效状态空间模型。模型接收观测-动作历史并预测下一个动作，有时也预测下一个观测。

元控制器由三个主要部分构成：

1. 内部序列嵌入器：对整段残差流激活 `e_{1:T}` 产生非因果序列嵌入；
2. 控制器编码器：基于循环网络，输出 `mu_t` 与 `Sigma_t`，定义候选 controller code 的高斯分布；
3. 控制器解码器：从 `z_t` 生成线性残差流控制器 `U_t`。

切换单元在候选 code 和前一 code 之间做时间积分：

```text
z_t = beta_t ⊙ z_tilde_t + (1 - beta_t) ⊙ z_{t-1}.
```

由于超网络计算是确定性的，同一个瞬时控制器 `U_k` 可以应用多个时间步，因而对应一个时间抽象动作。

内部强化学习策略使用循环网络，因为单层单步残差激活不一定包含完整原始输入历史。论文使用一个简单的一层状态空间模型作为策略，输出 `z` 空间中的动作分布。

## 附录 E：补充讨论与数学推导

### E.1 图模型与 ELBO 推导

作者用图模型推导无监督目标。记：

- `e_t`：时间 `t` 的残差流激活；
- `a_t`：动作；
- `z_t`：`a_t` 所属的抽象动作；
- `beta_t`：表示抽象动作是否改变的随机变量，即当 `beta_t = 1` 时 `z_{t-1} != z_t`。

假设生成模型为：

```text
p(beta_{1:T}, z_{1:T}, a_{1:T} | e_{1:T})
= product_t p(beta_t | e_{1:t})
            p(z_t | z_{t-1}, beta_t)
            p(a_t | z_t, e_{1:t})
```

其中：

```text
p(z_t | z_{t-1}, beta_t) =
  1_{z_t = z_{t-1}}, if beta_t = 0
  N(z_t | 0, I),     otherwise.
```

目标是最大化动作序列似然 `log p(a_{1:T} | e_{1:T})`。对任意变分分布 `q`，有证据下界：

```text
log p(a_{1:T} | e_{1:T}) >= ELBO.
```

根据图模型，变分分布可分解为：

```text
q(beta_{1:T}, z_{1:T} | e_{1:T}, a_{1:T})
= product_t q(beta_t | e_{1:t}, a_{1:T})
            q(z_t | z_{t-1}, beta_t, a_{1:T})
```

其中：

```text
q(z_t | z_{t-1}, beta_t, a_{1:T}) =
  1_{z_t = z_{t-1}}, if beta_t = 0
  N(z_t | mu_t(a_{1:T}), Sigma_t(a_{1:T})), otherwise.
```

于是 ELBO 可写为每个时间步的动作 log-likelihood 加上两个 KL 项：一个对应切换变量 `beta` 的变分分布与先验，另一个对应抽象动作代码 `z` 的变分分布与先验。最后一项可进一步分解为：

```text
D_KL(q(z_t | z_{t-1}, beta_t, a_{1:T}) || p(z_t | z_{t-1}, beta_t))
= 0, if beta_t = 0
= D_KL(N(mu_t, Sigma_t) || N(0, I)), if beta_t = 1.
```

为了训练稳定，作者对采样的潜变量 `beta` 做连续松弛。原则上可用 Gumbel-Sigmoid trick，但实验中直接用概率作为潜变量。连续松弛后：

```text
p(z_t | z_{t-1}, beta_t)
= N(z_t | (1 - beta_t) z_{t-1}, beta_t^2 I)

q(z_t | z_{t-1}, beta_t, a_{1:T})
= N(z_t | beta_t mu_t(a_{1:T}) + (1 - beta_t) z_{t-1},
          beta_t^2 Sigma_t(a_{1:T}))
```

当 `beta_t` 等于 0 或 1 时，这恢复离散情形。连续情形下，KL 散度仍化为：

```text
D_KL(N(mu_t(a_{1:T}), Sigma_t(a_{1:T})) || N(0, I)).
```

在实验中，作者还进一步修改 `beta` 的变分分布，使：

```text
q(beta_t | e_{1:t}, a_{1:T}) ~= q(beta_t | e_{1:t})
```

也就是去掉对未来的条件化。这样在内部强化学习阶段，切换信号可以因果地产生，同时消除切换模块的先验匹配项。作者在实验中做此假设，是因为他们认为在所考虑环境中，残差激活已经高度包含何时切换的信息。一般情况下，也可以保留未来条件化，再把切换蒸馏到无未来条件的模块中。

### E.2 内部强化学习与重参数化 trick 的原始动作空间强化学习

内部强化学习学习的是已发现抽象动作空间 `z` 上的策略。它把其余架构视为环境的一部分，并直接对 `z` 做强化学习，同时具有时间抽象。但也有其他利用已发现抽象动作的方法。一个更直接的方法是把元控制器视为整体架构中注入噪声的子模块，仍在原始动作空间用强化学习训练，并通过基础自回归模型反向传播到策略，例如使用重参数化 trick。

作者解析比较这两种选择。为简化分析，假设：

- 使用 outcome supervision：只有最后时间步 `T` 给出单个奖励 `r_T`；
- 切换发生 `M` 次，时刻为 `(t_m)_{1 <= m <= M}`；
- 抽象动作策略方差固定，输出 `z_t = mu(s_t) + epsilon_t`，其中 `s_t` 是到 `t` 为止的观测历史，`epsilon_t ~ N(0, 1)`。

若在原始动作空间做强化学习，并把抽象动作策略当作模型层，则策略梯度更新形式为：

```text
E[ r_T sum_{t=1}^T grad_phi log pi(a_t | s_t, z_t) ].
```

按抽象动作段分组后，该更新包含每个段内所有原始动作 log-prob 对 `z` 的梯度之和，再乘上 `mu(s_{t_m})` 对 `phi` 的梯度。也就是说，原始动作空间 RL 的估计器会在每个低层时间步累积噪声和梯度。

相反，内部强化学习直接在 `z` 空间做策略梯度：

```text
E[ r_T sum_{m=1}^M grad_phi log P(z_{t_m} | s_{t_m}) ].
```

在固定方差高斯策略下，这化为：

```text
E[ r_T sum_{m=1}^M epsilon_{t_m} grad_phi mu(s_{t_m}) ].
```

两种方法的前向轨迹和奖励分布相同，差别在于策略梯度估计器的方差结构。为简化，取 `M = 1`，即序列开始只采样一个 `z`。总方差分解显示，原始动作空间方法的估计器 `PG_raw(z)` 包含跨所有时间步和原始动作维度的梯度噪声，而内部强化学习的 `PG_z(z)` 类似一个 bandit 问题的策略梯度估计器。

权衡如下：

- `PG_raw` 的期望结构更丰富，在某些情况下对 `epsilon` 的方差甚至可能为 0；
- 但 `PG_raw` 的方差会随时间步数量和原始动作空间维度增长，因为噪声在每个时间步累积；
- `PG_z` 不随低层时间步或原始动作维度增长，它主要是 return 的方差，即 `O(1)`。

因此，若抽象动作发现成功，找到了紧凑 `z` 空间和长程抽象动作，则策略梯度估计器方差和相应信用分配可以显著改善，尤其在超长 horizon 任务中。

## 对 Volvence / ETA 数学实现的关键启示

1. 冻结基底不是工程偏好，而是发现时间抽象的数学条件。若基础模型与元控制器共同变化，rate-distortion 结构会退化，`beta_t` 更容易学到无意义切换。

2. `beta_t` 不只是 telemetry，而是时间抽象边界。延迟信用、segment closure、抽象动作复用都应围绕 `beta_t` 定义，而不是另造 action/outcome ledger。

3. 自监督阶段的核心是变分瓶颈。`KL(q(z_tilde_t) || N(0, I))` 不只是正则项，它决定 `z` 空间是否能成为可采样、可组合的抽象动作先验。

4. Internal RL 的优势来自两重压缩：动作空间从 `n_e` 或 token/action 空间压到 `n_z`，时间 horizon 从低层 time step 压到 `beta` segment。

5. 训练顺序应是 SSL 发现抽象结构，再在结构冻结或受限更新下做 RL。若在 RL 阶段随意改写 action family / encoder / base model，容易破坏已发现的抽象空间。

6. 对工程契约而言，`z_t`、`beta_t`、`closed_segments`、controller parameter fingerprint、runtime replay lineage 是必须可审计的最小公共面；完整 family bank 和网络张量应留在 temporal owner 内部。
