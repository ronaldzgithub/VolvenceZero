# Papers

本目录由上级 [`download_core_papers.sh`](../download_core_papers.sh) 归档合法开放版本。

- 正式元数据与 link-only 论文见 [`../SOURCES_AND_DOWNLOADS.md`](../SOURCES_AND_DOWNLOADS.md)。
- `download-summary.tsv` 记录每个目标的 `DOWNLOADED / PRESENT / FAILED / LINK_ONLY_ACCESS` 状态。
- `SHA256SUMS` 用于文件完整性复核。
- PDF 文件名的 `Pxx` 与 [`../02_CORE_PAPER_INDEX.md`](../02_CORE_PAPER_INDEX.md) 对应。

开放稿与正式出版版本可能存在排版或补充材料差异；研究断言以正式版为准。
