## 5. 下载纪律

`download_core_papers.sh` 只使用上述作者、机构、出版社、会议、OpenReview 或 arXiv 的开放地址：

- 不使用 Sci-Hub、非授权镜像或访问控制绕行；
- 已存在且通过 PDF 校验的文件不会覆盖；
- 下载先写入隐藏 `.part`，通过 `%PDF`、`%%EOF` 和 `pdfinfo`（若系统可用）后再原子移动；
- 每次运行生成 `papers/download-summary.tsv` 与 `papers/SHA256SUMS`；
- 个别站点拒绝自动下载时记录 `FAILED`；浏览器可读但自动端点受限的入口记录 `LINK_ONLY_ACCESS`，不尝试绕过，也不伪造归档成功。

复现：

```bash
bash research/bigai-songchun-zhu-2026-08/download_core_papers.sh
cd research/bigai-songchun-zhu-2026-08/papers
shasum -a 256 -c SHA256SUMS
```

## 6. 版本优先规则

1. 正式期刊/会议版决定题名、作者、年份、实验与结论；
2. 开放预印本用于本地全文检索，若与正式版冲突，以正式版为准；
3. BIGAI catalog 的年份用于“官网收录口径”，不覆盖 publisher 的 online/issue 日期；
4. 新闻稿只用于发现项目页或真实部署线索，性能数字回到论文核对；
5. 2026 预印本在后续同行评审后应重新核对版本和结论。
