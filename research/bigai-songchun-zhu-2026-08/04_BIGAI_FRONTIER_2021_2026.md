# 04｜BIGAI 前沿（2021–2026）：五条支线与证据边界

## 1. 总体地图

BIGAI 时期不是单一路线，而是五条互相靠近但尚未完全合并的支线：

| 支线 | 核心问题 | 代表论文 | 当前最强证据 | 主要缺口 |
|---|---|---|---|---|
| 少样本概念与因果 | 如何用少量示例形成可迁移概念 | ACRE、MEWL、Minimax concept induction | 对象中心任务、人类对照、跨设置泛化 | 依赖表示/任务设计，离开放世界仍远 |
| 社会智能与沟通 | 如何推断他人并双向教学/对齐 | ASI、Communicative Learning、in-situ alignment | 人机实验、形式化协议 | 心智模型假设与价值范围受限 |
| 3D 具身与机器人 | 如何把语言、场景与动作接通 | LEO、UniFP、IAIL、OmniXtreme | 仿真+真实机器人、跨本体 | 长期记忆、开放任务与安全门不足 |
| 多智能体与社会世界模型 | 如何建模异质 agent 和制度响应 | CivRealm、AdaSociety、SWM-AP、physical-social WM | 多环境基准、样本效率 | latent trait 可辨识性、sim-to-real、规范问题 |
| 可验证推理与 agent 自举 | 如何提出任务、搜索并验证 | CLOVA、Absolute Zero、TongGeometry | 工具/执行器/证明器闭环 | 强依赖可验证域，开放任务 judge 仍未解决 |

## 2. 少样本概念与因果

### 2.1 ACRE：相关性不等于抽象因果概念

ACRE 借鉴 blicket detector 范式：对象组合触发或不触发装置，模型需要从少量观测推断隐藏因果规则。它的意义是把“概念学习”从视觉相似性拉向干预/组合逻辑。

**证据到达：** 在论文构造的抽象因果任务中，模型需要处理 covariation 之外的规则和组合泛化。

**没有到达：** 真实世界因果发现、连续物理系统、隐藏混杂和长期反事实决策。

### 2.2 MEWL：指称不确定性下的词义学习

真实语言学习中，一个新词往往对应场景中的多个候选对象/属性。MEWL 用多模态、少样本和指称不确定性测试模型是否能跨例子消除歧义。

它与 communicative learning 互补：MEWL 更像“学习者从有限多模态证据恢复指称”，后者进一步建模“教师为何选择这些证据”。

### 2.3 2024 Minimax Concept Induction

论文在其设计的对象中心概念任务中与约 600 名人类参与者比较，并报告 human-level few-shot 结果。最值得注意的不是标题，而是三点：

1. 用对象中心表示缩小概念搜索空间；
2. 用 minimax entropy 选择能最大区分真实与当前模型的关系/属性；
3. 让生成式概念假设解释正负示例，而非仅拟合类别边界。

**严格边界：** “human-level”仅限论文的任务族、感知表示与实验协议。对象解析质量、候选关系库和搜索预算本身都提供了强先验；不能外推成一般人类级概念学习。

## 3. 社会智能、沟通与价值

### 3.1 Artificial Social Intelligence

该综述把领域按社会知觉、Theory of Mind 和社会互动组织起来，并强调物理理解不足以覆盖人类智能。它的价值是建立共同词汇和问题图，而不是提出一个统一可运行模型。

### 3.2 Communicative Learning

论文把三种常被分开的学习方式放入同一形式框架：

- passive：学习者观察自然产生的数据；
- active：学习者选择查询/实验；
- teaching：教师选择最能改变学习者信念的示范。

教师和学习者都可能递归模拟对方。该框架解释了为何同一个样本在“随机观察”和“有意教学”里信息量不同。

**对 agent 的直接启示：** 查询策略应考虑对方知道什么、愿意提供什么、如何解释自己的请求。

**风险：** 若把“理性教师”假设直接套在真实用户上，系统可能把噪声、犹豫或权力差异误读成精心设计的信号。递归 ToM 也会带来计算和可辨识性问题。

### 3.3 In-situ Bidirectional Value Alignment

该工作在交互式 `Scout Exploration Game` 中让三个软件 robot scouts 从用户反馈学习任务价值，同时解释自身选择，使人也能修正对机器人的预期。心理实验包含 135 名参与者、三个解释条件。这里的 “in situ” 指任务进行中的实时交互，不是实体机器人现场部署；“bidirectional”指双方通过交互减少对彼此目标/能力的误解。

**强点：** 对齐发生在行动后果与具体选择上，而不是一次性离线偏好数据；解释是互动的一部分。

**边界：** 学到的是任务内、实验定义的 utility/value；论文不证明普遍道德价值、长期关系价值或多文化规范已经对齐。

## 4. 3D 具身智能与机器人

### 4.1 LEO：3D 世界中的统一接口

LEO 把 3D 场景感知、语言理解、具身问答与动作任务接入一个 generalist agent。它的重要性是把“场景表示”和“语言/行动”放到同一模型接口，而不是为每个任务训练完全隔离的系统。

**证据到达：** 论文定义的 3D 任务集合与训练/评测协议。

**没有到达：** 不受限现实环境中的长期自主性、持续可追加记忆、社会价值与安全控制。

### 4.2 UniFP：接触任务中的统一力位控制

UniFP 处理腿足机器人 loco-manipulation：在不依赖外部力传感器的设定中联合学习力与位置控制，并使用力估计与策略训练应对接触丰富任务。该工作代表 BIGAI 机器人方向的一个重要变化：从“理解动作结构”走向“让结构经受真实接触动力学”。归档版报告四个真实 imitation-learning 任务总体成功率相对提高约 39.5%，并在四足机械臂和人形机器人上做 7 类实验。

其结果是具体机器人/任务上的控制证据，不应写成通用控制理论。归档 PDF 自身也有编辑不一致：摘要与实验节写“四个任务”，贡献列表写“三个任务”；本包采用详细实验节的四任务口径并保留该异常。论文还明确指出高频交互、工作空间边缘和 sim-to-real 力估计退化。

### 4.3 Cross-Robot Intention Alignment

IAIL 不直接复制异构机器人之间不兼容的关节轨迹，而把动作与自然语言意图映射到共享意图空间，再按目标机器人的本体和环境约束适配。论文报告 7 种机器人、30 个真实场景中的多步协作验证。

这是“语义不变量跨本体迁移”的强证据，但意图标注空间仍由任务和语言描述界定；它没有证明所有高层意图都可唯一、无损地恢复，也没有解决恶意/含混指令。

### 4.4 OmniXtreme

OmniXtreme 把运动表示/生成先验与执行器感知的 residual RL 分层，目标是让人形机器人覆盖更广运动分布。它与“冻结/慢基底 + 快残差适应”有结构相似性。

基准日它仍是 2026 预印本。可以作为工程方向信号，不能与同行评审后的生产安全证据等量齐观。

## 5. 多智能体与社会世界模型

### 5.1 CivRealm / AdaSociety：把制度与适应变成环境

两类环境把长程资源、协作、竞争、角色/制度变化纳入 benchmark，试图超越一次性矩阵博弈。它们的价值是提供可重复压力测试，而不是证明模拟社会等同真实社会。

### 5.2 SWM-AP：从轨迹到 trait，再到机制设计

SWM-AP 的链条是：

1. 从 agent 交互轨迹推断持久 trait；
2. 以 trait-conditioned 模型预测 agent 对机制的响应；
3. 机制设计 policy 在社会世界模型里生成大量训练轨迹；
4. 真实交互中继续在线推断 trait。

论文在税收政策、团队协调、设施选址等环境中报告相对 model-free/model-based RL 的累计回报和样本效率改善。

**关键限制：** latent trait 是预测工具，不是人格真值。若不同 trait 表示产生同样行为，它们可能不可辨识；若制度改变人的行为规律，所谓“持久 trait”也可能漂移。部署到真人场景还会引入公平、操纵与知情同意问题。

### 5.3 物理—社会世界模型 position paper

该论文主张世界模型不应把物理动态和社会动态分成孤岛，并提出 ACE 原则与路线图。其方向与朱松纯早期“力+效用”双反演高度连续。

但它是 position paper：可以支持“这是一个值得研究的缺口”，不能支持“统一模型已经实现并优于分轨模型”。工程上更安全的解释也不是把两轨塞进一个不可读 latent，而是保持语义 owner 隔离，通过显式交换建模相互作用。

## 6. 可验证推理与自举

### 6.1 CLOVA：工具使用后的闭环更新

CLOVA 强调 visual assistant 不只调用工具，还根据任务执行反馈更新工具选择或能力。它将 agent 从静态 router 推向执行—反馈—更新闭环。

需要区分：任务反馈可以更新工具策略，不意味着任何自然语言自评都可成为学习 reward；反馈的可验证性决定了闭环是否可靠。

### 6.2 Absolute Zero

Absolute Zero 让同一个模型提出代码推理任务并求解，以程序执行器验证答案，并用学习进度引导任务生成。标题中的 “zero data” 指不使用外部人工/蒸馏训练样本；它仍依赖预训练模型、代码域、执行器和设计好的自博弈过程。

它给出一个重要边界条件：**自生成训练在有可靠外部验证器时最可信。** 这一结论不能直接迁移到情感、价值或社会规范等无单一执行器真值的领域。

### 6.3 TongGeometry

TongGeometry 用学习先验引导符号几何搜索，同时生成可证明命题和求解奥赛题。正式论文报告：

- 建立 67 亿级可证几何定理库，其中 41 亿涉及几何对称性；
- 在 IMO-AG-30 上解出全部题目；
- 三个系统生成的问题被真实区域竞赛采用；
- 在论文报告的硬件/时间预算内运行。

这是一项强领域成果，因为 proposal、证明和问题生成闭环可被形式验证。但必须分开两种算力口径：求解 IMO-AG-30 使用 32 个 CPU 核与一张 RTX 4090、每题最长 38 分钟；生成 67 亿题库的搜索则使用 10,368 个并行 CPU 核运行 30 天，并以 196 道既有奥赛题统计作引导。论文限制节还承认多辅助点连续构造以及自然语言到几何 DSL 的转换仍困难。因此它不是“消费级机器从零发现全部数学”，更不是开放域通用推理的直接证明。

## 7. 证据强度排序

按“能否支持更大 AGI 主张”而非论文质量排序：

1. **领域闭环强证据**：TongGeometry、IAIL、in-situ value alignment、Minimax concept induction、UniFP。
2. **算法/基准强证据**：ACRE、LEO、SWM-AP、CLOVA、Absolute Zero。
3. **问题定义和研究基础设施**：MEWL、CivRealm、AdaSociety、X-VoE。
4. **框架/立场证据**：ASI survey、Communicative Learning 的一般纲领、Tong Test、physical-social WM position。
5. **前沿方向信号**：2026 预印本和未完成同行评审的系统。

这不是“前者重要、后者不重要”。区别在于：第一类能支持限定条件下的能力断言，第四类主要支持问题选择与实验设计，不能互换。

## 8. 对 2021–2026 进展的总裁决

BIGAI 已把朱松纯的结构化视觉路线推进到多种会行动、会沟通、会验证的局部系统。最显著的新东西是：

- foundation model 被放回 proposal/representation/interface 的位置；
- 形式证明、程序执行、物理接触和人类反馈充当不同类型的结算器；
- 社会动态与价值不再只是外部 reward，而成为待建模对象。

尚缺的一块是**持续、跨任务、跨 session 的统一适应链**：这些论文没有共同证明同一个 agent 能在长期生活史中追加记忆、读取稳定内部状态、只从合法信用信号学习，并以可回滚有界干预改变下一拍。这个缺口正是后续研究提案要检验的对象。
