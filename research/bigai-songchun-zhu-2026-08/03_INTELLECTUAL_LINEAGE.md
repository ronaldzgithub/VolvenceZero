# 03｜思想谱系深读：熵 → 文法 → 暗物质 → 小数据大任务

## 0. 总论

朱松纯路线可以压缩成一个反复出现的推理循环：

> 从观测与任务误差发现当前表示不够 → 选择新的统计量/结构变量 → 建立能生成观测的模型 → 通过解析或反演恢复隐变量 → 用恢复出的结构预测、解释或行动 → 在新误差下继续扩展模型。

这条路线的关键词先后变化很大：最大熵、Bayes/MDL、MCMC、图像解析、随机文法、AOG、物理稳定性、功能、意图、效用、Theory of Mind、沟通学习、DEPSI。但方法论上的不变量是：**智能不是直接从输入映射到标签，而是推断“是什么结构生成了当前世界，以及该结构允许什么行动”。**

## 1. 第一代：统计视觉与最小最大熵（1995–2002）

### 1.1 Region Competition：在结构空间竞争

`Region Competition` 不是单纯的分割算法改良。它把轮廓演化、区域生长与 Bayes/MDL 形式化放在同一目标里，让不同区域数、边界和统计模型竞争。关键思想有两层：

1. 分割不是固定标签空间上的分类，而是**模型维数也会变化**的结构选择；
2. 局部数据驱动更新必须由全局解释目标约束。

这为后来的 data-driven MCMC、parse graph 和 And-Or alternatives 提供了早期原型：系统不只优化连续参数，还要决定“世界里有几个对象、哪种结构存在”。

### 1.2 Minimax Entropy：小样本下选择“该知道什么”

最大熵原理在给定统计约束下选择最少额外假设的分布：

\[
p^* = \arg\max_p H(p) \quad \text{s.t.}\quad E_p[\phi_j] = \hat{\mu}_j.
\]

最小最大熵进一步关心：候选特征很多、样本有限时，应先加入哪个统计量。训练循环用模型样本与真实样本之间的统计差异选择最能减少不确定性的约束，再更新 Gibbs 模型。其重要性不是“熵越小越智能”，而是：

- 允许模型在有限数据下逐步扩充表示；
- 把特征选择、模型拟合与生成检验接成闭环；
- 明确区分观察到的统计约束和模型尚未解释的剩余误差。

2024 年少样本概念归纳论文重新启用这条思想，但加入对象中心表示、现代搜索/计算和新的心理学式任务。它支持“老原则仍有生命力”，不等于 1997 算法未经改变就解决了现代概念学习。

### 1.3 FRAME：分析与合成同一化

FRAME 把滤波器响应统计写进随机场/最大熵分布，并通过生成样本检验模型是否抓住纹理规律。“模型会分类”不够；模型生成的样本也应复现所选统计量。由此形成后来贯穿朱松纯工作的 `analysis by synthesis`：

- analysis：从观测推断结构/参数；
- synthesis：由结构生成观测或未来；
- discrepancy：生成与真实之间的差异决定模型还缺什么。

### 1.4 DDMCMC：bottom-up 提议，top-down 结算

Data-Driven MCMC 使用数据驱动算子提出高概率结构跳转，再用后验概率/接受率完成全局结算。它解决的是可变维、组合结构空间中纯随机采样太慢的问题。

最容易误读的地方是把它直接类比成现代“快模型 + judge”。更准确的结构是：proposal 提高搜索效率，接受规则仍属于同一个概率模型；不存在一个独立自然语言评审器给任意输出打分。对现代 agent 的启示是**提议和结算分层**，而不是引入不可校准的 evaluator。

## 2. 第二代：图像解析、随机文法与 AOG（2003–2012）

### 2.1 从标签到 parse graph

`Image Parsing` 试图统一 segmentation、detection 与 recognition。输出不再是一组互不相关的标签，而是一张 parse graph：对象、部件、区域、曲线、属性与关系共同构成对图像的解释。

与普通 scene graph 的差别在于：parse graph 是某个生成文法的一次实例化；它不只列出实体，还隐含“为何这些元素可组合成该场景”。

### 2.2 Stochastic Grammar / And-Or Graph

AOG 的基本角色：

- `And-node`：一个实体由哪些部件/关系共同组成；
- `Or-node`：同一概念有哪些可替代实现；
- terminal：可落到观测或基本动作的单元；
- parse graph：从 Or 选择并展开 And 后得到的具体世界实例；
- probability/energy：描述选择、属性和关系的不确定性。

它把三种能力放在一个结构里：

1. **组合性**：已学部件可重组为新对象/事件；
2. **可解释性**：推断结果有命名节点和关系；
3. **生成性**：结构可以合成观测、动作或未来序列。

### 2.3 文法路线的真正贡献

这条路线预见了当前 foundation model 的两个痛点：系统泛化和状态可读性。它的贡献不是证明所有知识都应手写成文法，而是提出一个严格问题：**如果模型不能说明哪些对象、关系、可替代方案和约束支持了结论，它是否真的学会了可迁移概念？**

### 2.4 文法路线的规模化难题

同样必须保留四个限制：

- ontology 和 primitive 从何而来；
- 大规模文法结构搜索的组合爆炸；
- 结构标注/监督成本；
- 手工结构可能把研究者偏见冻结成世界本体。

后来的神经符号闭环、对象中心学习和 LLM-guided search，正是在尝试让“proposal/primitive”更多地由数据和预训练模型产生，而让符号结构保留可验证性。

## 3. 第三代：物理、功能、意图与效用的“暗物质”（2013–2020）

### 3.1 为什么叫暗物质

像素只显示表面。要预测一个人会走向哪里、一个工具如何使用、一个房间是否安全，系统还需要推断大量不可直接观察的变量：支撑关系、力、可达性、功能、目标、意图、偏好和社会规范。它们不能从单帧标签完整读出，却对预测和行动有因果作用，因此被比喻成视觉世界的“暗物质”。

`Dark, Beyond Deep` 用 `FPICU` 概括六类缺失结构：

- Functionality（功能）
- Physics（物理）
- Intent（意图）
- Causality（因果）
- Utility（效用）

标题中的 “U” 与展开常见为 utility；“FPICU”是研究议程的助记框架，不是一个已经统一实现的固定 schema。

### 3.2 任务导向对象

`Understanding Tools` 的核心转向是：物体类别不应只由外观决定，还应由可供性、功能部件与任务关系决定。两件外观不同的工具可能在任务上等价；外观相近的物体可能因功能结构不同而不可替代。

这给对象表示加上了反事实问题：如果抓取点、受力方式或目标改变，它是否仍能完成任务？因此“概念”开始从静态视觉簇变成可行动的结构。

### 3.3 从运动反推力与效用

`Inferring Forces and Learning Human Utilities from Videos` 同时反演物理力和行动者效用。两者缺一不可：相同轨迹可能由不同环境力产生，相同物理环境也可能因不同目标产生不同动作。

这是物理轨与社会/自我轨的一次重要连接，但不能由此声称论文已经解决完整人类偏好学习。实验里的 utility 是任务化、参数化的潜变量；它是可检验模型，不是人的价值本体。

### 3.4 从对象文法到事件/社会文法

STC-AOG、social affordance grammar 和 human activity grammar 把 AOG 的对象层扩展为：

- spatial：对象与场景关系；
- temporal：事件阶段与动作顺序；
- causal：动作、状态变化与目标之间的依赖；
- social：他人角色、可供性、互动规范与共同任务。

至此，文法不再只是“看图”，而成为机器人学习、活动预测和人机协作的任务结构。

### 3.5 神经符号闭环不是串联流水线

`Closed Loop Neural-Symbolic Learning` 的关键在 closed loop：神经感知给文法解析提供 proposal，解析/符号推理的结果反过来生成训练信号或纠正感知。若只是“神经网络输出标签，再交给规则引擎”，没有反向约束，就丢失了论文最重要的部分。

## 4. 第四代：BIGAI 的小数据大任务（2021–2026）

### 4.1 从识别任务转向概念形成

ACRE、MEWL 与 2024 minimax concept induction 都把重点放在“少量例子下形成可迁移概念”，而非在封闭类别上提高一个百分点。这里延续的是：

- 对象中心表示；
- 候选解释竞争；
- 因果/指称不确定性；
- 与人类学习协议对照。

### 4.2 从单向监督转向沟通学习

`Communicative Learning` 把学习者和教师都视为带有心智模型的 agent。被动观察、主动查询与教学不再是三套孤立范式，而是双方对彼此知识/目标进行递归推断的不同协议。

其最强启示是：**示范的含义取决于示范者为何选择它，以及学习者认为示范者如何理解自己。** 其边界是：递归心理模型、教师理性和通信协议都带有假设；论文形式化不能直接保证开放世界中的真实人类符合这些假设。

### 4.3 Tong Test：从静态题库转向 DEPSI

Tong Test 主张在 Dynamic Embodied Physical and Social Interactions 中评估智能，把能力系统和价值系统并列，并通过持续生成任务避免固定 benchmark 饱和。

这是对 Turing Test 和静态排行榜的重要批评，但目前更像评测架构和研究计划：任务生成的覆盖性、不同能力层级的可操作测量、价值判断的一致性与抗 gaming 都仍需长期验证。

### 4.4 从结构搜索到神经引导的可验证搜索

TongGeometry 代表一个成熟回环：

- LLM/学习先验负责给巨大搜索空间排序；
- 符号几何系统负责构造与证明；
- 证明器提供明确验证；
- 系统又从可证明结构生成新问题。

这与 DDMCMC 的“数据驱动 proposal + 模型结算”有方法论同构，但结算器从概率接受率变成形式证明。它的优势来自可验证领域；不能直接外推到没有可靠验证器的开放社会决策。

## 5. 六个跨代不变量

| 不变量 | 早期表现 | 当前表现 |
|---|---|---|
| 小数据下选结构 | minimax feature pursuit | few-shot concept induction、communicative learning |
| 分析—合成闭环 | FRAME sampling | neural-symbolic loop、world model、self-play task generation |
| proposal—verification 分层 | data-driven MCMC | LLM-guided theorem search、executor-verified reasoning |
| 可组合表示 | image grammar/AOG | recursive machine、3D agent、social/causal models |
| 推断不可见原因 | latent region/model | force、intent、utility、trait、intention space |
| 由理解走向行动 | task-oriented object | robot control、mechanism design、multi-agent cooperation |

## 6. 与大模型路线的真实关系

把朱松纯/BIGAI 与 foundation model 画成“符号 vs 神经”的二元对立会误导：

- Interpretable CNN、closed-loop neural-symbolic learning 已长期使用神经网络；
- LEO、CLOVA、TongGeometry、Absolute Zero、OmniXtreme 都使用现代大模型、RL 或生成模型；
- 分歧主要在**什么算充分解释和充分能力**：仅有 next-token/像素预测及 benchmark 成绩是否足够，还是必须显式处理对象、物理、因果、他人心智、价值和交互。

因此更准确的定位是：foundation model 可作为感知、proposal、先验或接口；结构模型、交互和验证器负责约束它，避免把流畅输出当成完整世界理解。

## 7. 批判性裁决

### 站得最稳的部分

1. 结构化隐变量能改善特定领域的样本效率、可解释性或系统泛化；
2. bottom-up proposal 与 top-down verification 的分层在多个时代反复有效；
3. 物理与社会变量对预测行动不可或缺；
4. 可执行/可证明验证器使自举学习比自然语言 judge 更可靠；
5. 固定静态题库不足以证明通用智能。

### 仍未被整个项目证明的部分

1. 一个统一理论已将 BIGAI 全部方向接成单一可运行系统；
2. AOG/神经符号方法已在开放世界规模上普遍优于端到端大模型；
3. 显式心理变量等于真实人的内在状态；
4. Tong Test 已成为跨机构稳定、抗 gaming 的 AGI 标准；
5. “小数据、大任务”已在无强先验、无验证器的开放任务中成立；
6. 局部任务价值对齐等价于广义价值对齐。

最终评价：这是一套**异常连贯、问题选择深刻、局部证据不断增强的研究纲领**。它最有说服力之处是三十年里反复把“不可见结构”变成可计算对象；最需要继续证明之处，是这些结构能否在开放、持续、跨 session 的现实系统里共同生长，而不是停留在多个优秀但相互分离的实验闭环。
