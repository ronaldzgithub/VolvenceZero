# 02 · 对 Volvence 的启示：TTT-E2E 专项增量

前置：本篇在 [`../continual-learning-2026-07/02_VZ_DELTA.md` §F](../continual-learning-2026-07/02_VZ_DELTA.md) 已有裁决——**架构是 R2 反例（测试时改基底权重），不抄架构；三条工程经验（只更 MLP / 只更 1/4 blocks / mini-batch 而非单 token 梯度）是免费先验；"长上下文是持续学习问题不是架构问题"的框架转换是 R5（CMS 而非 context window）的外部证据**。本文件不重复、不推翻这些，只补专项深读后新增的七条。

---

## 1.（增量）终端损失击败层级代理损失 → R-PE 的域外定量证据

Table 1 的关键步：把 KVB 层级重建损失（"从 key 预测 value"的内部代理目标）换成**网络末端的真实 NTP 损失**，760M/DCLM 上 loss 2.819→2.806，是全表唯一显著的一步；且 Fig 6 里 TTT-E2E 是唯一全程低于 full attention 的方法，TTT-KVB 不是。

这与 R-PE 的主张同构：**学习信号应取自系统边界上的一级预测误差，而不是内部代理指标的 readout**。KVB 恰好是"消费者自造内部重建目标"的教科书案例——它模仿 self-attention 的 KV 存储语义，结果证明这个模仿对最终任务既非必需也非最优。

引用边界：这不是说辅助自监督目标一律无用（Tianmouc 的物理一致性监督就是反例），而是**当代理目标与终端 PE 可以互换时，终端优先**；代理目标只有在终端信号不可得时才有存在理由。

## 2.（增量）对 Nested Learning 的引用要加限定：范式强化、实现弱化

本仓库把 NL（`2512.24695`）当作核心设计源头（多时间尺度嵌套学习）。本篇带来一个必须携带的 nuance：

- **弱化的部分**：NL 论文（连同 Titans、MesaNet）的核心构造 KV Binding，被本篇在长上下文语言建模上用终端损失路线击败（同构裁决——直接评测的是共用构造的代表 TTT-KVB `2505.23884`，Titans/MesaNet/NL 本体未上桌）。
- **强化的部分**：TTT-E2E 本身就是最干净的两频嵌套学习实例——慢外循环（训练时，meta-优化初始化）+ 快内循环（测试时，NTP 压缩上下文），且论文用 TTT-naive 对照证明**没有慢环准备的快环几乎无效**（toy 里 TTT-naive 只比 bigram 略好）。"不同频率的学习循环互相咬合、慢环为快环准备初始条件"——这正是我们 R1 的主张，现在多了一个 3B/164B 规模的实证。

**行动**：今后任何 spec / 研究文档引用 NL 时，若涉及 KVB / HOPE 的具体机制，必须附带本条限定；引用嵌套频率范式本身则可同时引 NL 与本篇互为佐证。

## 3.（增量）"focus on the present" → R2 从安全约束升级为性能论证

Fig 6 的机制观察（优势在第一次梯度步之前、同计算图条件下就存在）+ 作者解释：**静态权重必须对所有可能的未来都好，这挤占对任何特定现在变好的容量；被更新的权重只需对当前 mini-batch 好**。

这给 R2（冻结基底 + 有界自适应控制器）补上了一直缺的**正向论证**：分层不只是为了安全和可回滚——冻结基底承担"对所有未来都好"的泛化职责，有界快层收割"只对现在好"的专化收益，两者的分工本身就有性能红利。此前我们论证 R2 主要靠反面证据（可塑性丧失、灾难性遗忘、sleeper agent）；这是第一条正面的、定量的分工收益证据。

## 4.(增量）NIAH 崩塌 → 压缩记忆与无损检索不可互替 → CMS 连续谱的外部证据

S-NIAH @128K：full attention 0.99/0.86/0.64 vs TTT-E2E 0.06/0.05/0.03。作者自己的归因：压缩必然丢掉"看似无关的细节"，而 needle 的定义特征恰恰是与语料无关。

对 R5/R6（记忆连续谱：瞬态/情景/持久/派生索引各自独立 owner）这是一条结构性证据：

- **压缩型权重记忆**（本篇的 fast weights、我们的 substrate carriers / 慢层聚合）擅长"经验改善预测"（Fig 6 前段优势），在无损回忆上崩溃；
- **无损情景存储 + 检索**（我们的 episodic stratum + 派生索引）承担 recall 查询，但自己不产生预测改善（CL-BENCH 已证明堆检索经常帮倒忙，见 [`../continual-learning-2026-07/README.md`](../continual-learning-2026-07/README.md)）；
- 论文结论段的记忆层级只有两级（权重=长期、窗口=短期），**恰好缺第三级**——它的 NIAH 表就是缺这一级的代价清单。

两篇负结果（本篇的 NIAH + CL-BENCH 的检索反噬）从两个方向夹出同一个结论：**压缩与检索是两种正交能力，CMS 把它们放进不同 stratum、各配 owner 是必然结构，不是偏好**。

## 5.（增量）block 内静态第二 MLP = 微型 frozen/adaptive 分层

为防 TTT 遗忘预训练知识，每个被更新的 block 里加一个**冻结的第二 MLP 当"安全存储"**，可塑 MLP 与冻结 MLP 并联。一个以"测试时改权重"为卖点的方法，自己内部也必须切出冻结通道才能稳住——这与 substrate（冻结）/ controller（有界可塑）分层是同一设计语汇，且与 Tianmouc 的"记忆读出 = 残差注入 + 一键关断"（[`../tianmouc-sensing-perception-2026-08/README.md`](../tianmouc-sensing-perception-2026-08/README.md) 单点事实 5）构成两条独立域的同构证据。引用 R2 时可并列引。

## 6.（增量）工程先验增补（§F 三条之上再加四条）

若未来在有界 adapter / 控制器层做任何在线快更新，这些是免费的避坑先验：

1. **\(k \ge b\) 协同设计**：滑动窗口必须 ≥ TTT mini-batch，让瞬态记忆在权重更新到位前兜住批内上下文。翻译到我们的结构：**在线更新的生效周期内，必须有瞬态层（State-KV / 窗口）覆盖间隙**——更新频率与瞬态容量是一对耦合参数，不能独立调。
2. **QK norm 稳外循环**：他们发现 QK norm 对 TTT-E2E 的训练稳定性关键（顺手还改进了所有基线）。任何含嵌套优化的训练管线值得默认开。
3. **\(b<1\)K 有硬件与稳定性下限**：在线更新的批粒度不是越细越好——"更实时"的更新粒度会同时打崩稳定性和硬件利用率。
4. **梯度的梯度是真实成本**：8K 预训练慢 3.4×、checkpoint-through-time 随 \(\log T\) 膨胀、cuDNN FlashAttention 不可用。meta-learning 式的"训练时为在线适应做准备"只配得上 rare-heavy 预算档；论文自己指出的省算力路线——**从预训练好的普通 Transformer 初始化、TTT 化只占总算力零头**——如果我们未来评估这族方法，这是唯一合理入口，且必须走 rare-heavy artifact + `ModificationGate`。

## 7.（增量）四能力轴映射：强机制证据，不是持续学习系统

按 [`../../docs/appendable-readable-learnable-steerable.md`](../../docs/appendable-readable-learnable-steerable.md) 的口径逐轴裁决：

| 能力轴 | TTT-E2E 现状 | 裁决 |
|---|---|---|
| **Appendable** | fast weights 逐序列生存（footnote 4 的重置语义），不跨文档、不跨 session，无恢复机制 | ✗——是序列内瞬态压缩，不是可追加记忆 |
| **Readable** | 状态 = 不透明的 MLP 权重增量，无命名读出、无快照发布，消费者无法知道"它压缩了什么" | ✗ |
| **Learnable** | 学习信号 = 终端 NTP 预测误差（与 R-PE 对齐，见 §1），且无 evaluation 回灌（干净）；但无 credit 分层、无学习时机选择 | △——信号来源正确，信用结构缺失 |
| **Steerable** | 每 mini-batch 无条件更新：无 gate、无 norm cap、无单字段回滚；作者自己把"门控/自生成过滤"列为未来工作 | ✗ |

**结论**：TTT-E2E 是"online-fast 权重压缩机制有效且可 scale"的最强单点证据之一，但四轴缺三轴——对外引用时不得把它说成"在线持续学习已被业界解决"的证据。它缺的三轴（可追加、可读出、可门控）恰好是我们的主张差异化所在。

## 8. 不该借鉴的三条（维持 + 细化 §F 的划界）

1. **测试时改 substrate 权重**：R2 反例，维持既有裁决。live 运行时的等价物只能是有界控制器层的 delta，不能是基底 MLP。
2. **把 token 空间内循环当长期策略学习**：TTT-E2E 的内循环只做压缩（SSL 半边），与策略无关。若有人想把内循环的 NTP 损失换成 reward——那就是 token-space RL，R3/R4 禁区。它对 R13 的支持只有"SSL 压缩"半边，RL 半边为零。
3. **无条件逐批更新**：无 gate 的写面（R10 反例）。作者自己承认缺门控并猜想 self-generated tokens 可以当隐式 gate——我们的显式 gate（sensor→executor→gate、norm cap、strict noop）就是这个缺口的正式答案，这一点可以在 steering 文档里作为"业界确认此缺口存在"来引用。
