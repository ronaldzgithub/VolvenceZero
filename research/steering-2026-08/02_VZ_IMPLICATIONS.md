## 2. 文献归因："可读却不可扳"是四重已知错配的叠加

把 S2 的设定逐条对照文献的成功前提，四条全踩雷：

| # | 文献前提 | 我们 S2 的做法 | 判定 |
|---|---|---|---|
| 1 | 行为须是**连贯线性方向**，且该性质**施加前可预检**（A1：余弦一致性 ρ=0.76、d′ ρ=0.71） | 只测了 probe 准确率 `0.9833`，**从未测**方向一致性/d′ | **未验证前提**——0.98 可读 ≠ 可 steer |
| 2 | 方向来源用 **diff-of-means / 学习式**（B1 CAA、D1 排序） | 用**判别式 probe 权重**当轴 | **方向来源错配**（probe 权重过拟合非因果特征） |
| 3 | 弥散多 token 概念须**因果中介定位**，非单 token 代理（B2 GCM） | 固定 layer20、单步位置读写 | **定位错配** |
| 4 | 在**有余量/模糊处**测建设性（A1 可分性、Marks&Tegmark） | 在信息饱和的揭示后位置测 | **测点错配**（无余量可 recover） |

**核心洞察（回答"为什么扳不动"）**：Braun (A1) 证明**probe 高准确率与可 steer 性是两回事**——
判别器可以在一个弯曲/发散的激活流形上做出 0.98 判别，而该流形不是一条可加的连贯方向；
此时"读得出"但"加上向量不动行为"，且约 1/3 样本会反向。**我们的 S2 null 落在 Braun 图 2 的低方向一致性区，是被预测到的结果，不是新死路。**

这也与 P1 诊断自洽：`incentive-bypass-via-free-bias` 说明 Stage-3 里"改善"是免费 bias 偷来的（96.32%），
一旦 S2 拿掉 free bias、拿掉可训练参数做**纯 matched 因果对照**，沿 probe 轴的真实因果性就归零——**正是"方向本身不因果"的表现。**

## 3. 出路：先预检，再换方向来源、换测点、换定位（S2' 配方）

文献给的不是"再赌一次"，而是**一道便宜的只读预检门 + 三处对齐修正**。

### 3.1 【先做】Steerability 预检门（只读，几分钟，来自 A1）

在任何 S2' 因果实验之前，先在子目标轴上量三个 Braun 指标，**用它预测而非试错**：

1. **方向一致性**：对每条 heldout 前缀算 per-sample 激活差（子目标=k vs ≠k 的对比激活），与聚合轴求余弦，取均值分布。
2. **可分性 d′**：沿 diff-of-means 线投影正/负激活，算 `d′ = |μ+−μ−| / sqrt(½(σ+²+σ−²))`。
3. **反向样本比例**：预演施加后 logit/行为差 < 0 的比例。

**判读**：若方向一致性低、d′ 小（对照 A1：可 steer 组均值余弦 ≈0.48、不可 steer 组 ≈0.19），
则 S2 null **被解释为"子目标在此基底不是连贯可加方向"**，无需再跑昂贵因果扫；
若一致性/ d′ 高却仍 S2 null，才说明是执行层（测点/来源）问题。**这道门把 S2 的解释权钉死。**

### 3.2 换方向来源：probe 权重 → diff-of-means（CAA/DiffMean）或学习式

按 B1 + D1，把 S2' 的轴从判别式 probe 权重换成**对比激活均值差**（子目标=k 的前缀激活均值 − ≠k 的均值），
每类用 ~80–100 对以上降方差（A1/CAA 样本效率）。这是最小改动、成本最低的一档。

### 3.3 换定位：固定 layer20 → 因果中介中段层扫（GCM 式）

按 B2，子目标是弥散概念，改为在轨迹上做因果中介，选中介最强的组件/层，而非相关性 probe 选层。

### 3.4 换测点：饱和揭示后 → 揭示前/模糊前缀

按 A1 + Marks&Tegmark，只在**尚未揭示下一子目标**的前缀上测建设性效应（那里才有余量可被 steer 恢复），
而非在信息已饱和处（那里模型本就答对，无余量）。

> S2' 仍是**独立 prereg**，五门与 S2 同构（target-plus vs noop / minus / shuffled + CI 不跨 0），
> 只有预检门通过后才跑，且**不改写 kill-eta**。

## 4. B screen 与 S3 的血统对齐（我们已经在最强路线上）

好消息：我们现有的两条活路，恰好压在文献的两个最优方向上。

| 我们的组件 | 文献血统 | 佐证 |
|---|---|---|
| **B screen**：GRU→16d `z_t`，rank-8 `A·diag(tanh(Cz_t))·Bᵀ·e_t`，无 bias，zero-z 严格 no-op（prereg `c247e82e…`） | **ReFT/LoReFT 家族**（冻结基底上学习低秩子空间干预） | C1；D1 排序把优化式列为全面最强 |
| **S3**：PE 门控 + 段信用 + 小动作空间（noop/±轴/几档 scale）学"何时出手" | **CAST 的学习式推广**（condition vector = 门控 readout）；训练目标可借 **RePS** 偏好式 | D2、C2 |
| **S1 readout owner**（冻结传感器，快照发布不回灌） | 综述把 steering 定为"局部可逆、需嵌入外层验证的模块" | D1 挑战③ |

**关键判断**：B screen 是把 S2' 的"来源+定位"问题一次性交给**学习**（而非手挑 probe 轴），
若 B screen directional screen 出现 gap，说明"学习式干预能在富残差上写入因果作用"——
这正是 S2 静态单点做不到、而文献预测学习式能做到的部分。**B screen 的结果应作为 A/B 路线的裁决点。**

## 5. 清醒剂（部署级，来自 A2/A3/D1）

即便预检通过、S2'/B screen 出现因果效应，仍有三个学界公认的开放风险，必须进产品域 gate：

- **跨模型不泛化**（A2）：0.5B 上修好不等于 production 基底可用，每个基底重测可 steer 性。
- **伪可控 + 能力税**（A3）：区分"真潜变量位移"与"prompt-conditional 对齐"；度量通用能力回退。
- **纠缠副作用**（D1 挑战①②）：沿子目标轴 steer 可能溢出到无关行为；需 off-target 评测 + 与既有对齐机制的交互检查。

这三条不是劝退，而是说明**我们已有的 gate-wise 证据文化 + 读出/执行器/外层验证分层**正是文献呼吁的方向（D1 挑战③）——是相对优势，不是负担。

## 6. 建议的下一步（供决策，不自动执行昂贵扫）

1. **先落 §3.1 的 steerability 预检门**（只读、便宜）——它要么便宜地解释掉 S2 null（子目标非连贯方向），要么定位到执行层问题。这是性价比最高的一步。
2. **等 B screen directional screen 出结果**——它直接检验"学习式写入有无因果作用"，是 A vs B 的裁决证据。
3. 若预检显示方向一致性可接受但 S2 static null，**按 §3.2–3.4 三处修正另立 S2' prereg**（换 diff-of-means 来源 + 中段层因果定位 + 揭示前测点），五门同构，通过才解锁 S3。
4. S3 落地时，门控用 **CAST 结构**、训练目标参考 **RePS** 偏好式 + PE 段信用，动作空间保持 `noop/±轴/几档 scale` 与稀疏 PE 信用兼容。

一句话给决策者：**A（steering）是对的方向，文献强背书；S2 现在扳不动是因为我们踩了四个已知坑，而不是路走不通。先花几分钟做预检把话说死，再决定是修 S2'（便宜）还是等 B screen（更强）裁决。**
