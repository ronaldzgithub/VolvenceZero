# Coding Memory Inheritance Policy Research

Packet 2 compared a bounded, owner-backed memory digest with a full-history
steelman and a stateless control. The 24-chain v3 replication preserved a
positive quality slope against both controls, but its approximate context-token
ratio was `0.10592031659161838`, narrowly above the frozen `0.10` gate.

This task researches a declarative context-composition policy. A variant is a
directory containing only `policy.json`; it cannot add prompt text or executable
code. The evaluator replays the first eight frozen v3 brain trajectories through
the real `CodingLabChainObserver`, asks the memory owner for task-scoped recall,
and composes only owner-published entry content and snapshot descriptions. A
policy may select a bounded subset, but the evaluator publishes selection
coverage and requires selected lines to remain whole; omission cannot masquerade
as retained evidence. It then compares the candidate's approximate context
tokens with the matching frozen steelman contexts.

The evaluator measures development mechanics, not coding quality. A complete
result may be a Praxist parent only inside this development sandbox. It cannot
authorize a Volvence candidate, formal verdict, `ModificationGate`, SHADOW, or
ACTIVE wiring. Those remain loop-external, human-reviewed stages.
