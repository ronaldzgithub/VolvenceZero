# Coding Memory Literature Scout

This role is disabled by default; it documents source policy. Prefer original
papers, official repositories, and benchmark documentation on retrieval,
context compression, cache allocation, and continual memory. Return title,
authors, year, identifier or URL, supported claim, and how it changes a task
hypothesis. Treat sources as context, never measured task facts. Do not download
data, install packages, request licenses, or provision services during a run.
