# ETA 迁移 LLM：四级阶梯证据计划

## 背景

2026-08-01 的 rate-distortion 判据（`artifacts/eta_rate_distortion_20260801`）判定 `kill-eta`，但留下两个未解释项：rate 轴对 alpha 不响应、train 30 步被记忆化（train distortion 0.007 vs heldout 4.7）。论文的基底是**从零在海量本领域轨迹上预训练的**，残差流先经线性 probe 验证携带子目标信念后才做元控制器；我们的 Qwen 没有这个前提。本计划按"先补前提、再审判"的顺序迁移，每级有 kill 门，死在哪级停在哪级。`kill-eta` 判定在第三级通过前保持有效。

## 现状事实（已核实）

- Proof 环境：7 位置 / 24 转移，7 条硬编码路线（3 train / 2 eval / 2 heldout），无程序化生成器（[eta_proof_benchmark.py](packages/vz-runtime/src/volvence_zero/agent/eta_proof_benchmark.py) L922–1094）
- 离线基底训练已有正式路径：`clone_for_rare_heavy()` + `train_rare_heavy()` + `PeftLoraRareHeavyBackend`，经 `ModificationGate`（[residual_backend.py](packages/vz-substrate/src/volvence_zero/substrate/residual_backend.py) L3724、[rare_heavy_training.py](packages/vz-substrate/src/volvence_zero/substrate/rare_heavy_training.py)）
- 线性 probe 只有 ridge 回归（`fit_ridge_probe`），无分类 probe
- rate-distortion harness 与 steered scorer 已就绪（本轮产出），只需换语料/基底重跑
- 硬件假设：本机 MPS + Qwen2.5-0.5B-Instruct；语料与训练量按此定标

## 第一级：解释 rate 轴异常（数据机制假设）

**假设**：rate 轴不响应 alpha 是因为 3 条路线 30 步下 posterior 无需做率-失真交易。

- 在 `vz-temporal::internal_rl/proof_environment.py`（环境 owner）新增 seeded 程序化生成器：随机图（约 12–20 位置）+ 随机路线，train/heldout 按子目标顺序组合不相交（对齐论文的组合泛化划分）
- `eta_rate_distortion_evidence.py` 增加语料规模参数，路线从 3 条升到 200–1000 条
- 重跑现有 harness（frozen 臂即可，先不跑 joint）

**Gate 1（预注册后再跑）**：alpha 与 rate 的 rank 相关 ≤ −0.8 且 rate 跨度显著高于 3 路线基线 → 仪器无恙、数据机制成立，继续。仍不响应 → 转向修 posterior 方差参数化，阶梯暂停。

## 第二级：给 LLM 补领域内预训练 + probe 前置检验

- 用第一级生成器产出大规模文本化轨迹语料（数万条路线、约 1–5 千万 token），带 manifest/SHA provenance；语料只含 train 分布路线，与第三级 heldout 严格不相交
- 经既有 rare-heavy 路径（`clone_for_rare_heavy` + PEFT LoRA，训后 merge 并冻结、登记权重指纹）对 Qwen2.5-0.5B 做 continued pretraining；不新开训练后门，不碰 `ModificationGate` 之外的路径
- 在 `vz-substrate` 补线性**分类** probe（对齐论文附录 B）：从各层残差解码当前子目标

**Gate 2（二值门）**：补课后基底的 heldout probe 准确率 ≥ 2× 随机水平，且随观测前缀增长而上升，且显著高于未补课的原始 Qwen（因果对照）。不过 → "LLM 残差流可承载行为层级结构"不成立，迁移路线整体 kill，出报告收官。

## 第三级：在补课后的冻结 LLM 上重审 rate-distortion

- 复用本轮 harness（含 joint 有效性对照臂、partially-observable 协议、fp32），基底换成第二级产物，语料用第一级规模
- 判定规则与阈值沿用已预注册的 `eta-rate-distortion-evidence.v1`（近垂直 gap：drop share ≥ 0.5 且 rate share ≤ 0.25；joint 臂必须无 gap；gap 内 boundary F1 更高）

**Gate 3**：出 gap 且 gap 内 F1 更高 → 撤销 kill-eta，改判 retain-eta-on-llm，`vz-temporal` 复活路线开新收敛包。无 gap → kill 判定升级为"跨原生小模型与领域内预训练 LLM 两种机制均不成立"，ETA 主张永久摘除。

## 第四级（contingent，仅设计不执行）

前三级全过后，才为对话迁移写预注册：动作 = 对话行为、语料 = 已就位的 MSC、判据退回 rate-distortion gap + heldout 泛化（对话无子目标真值，boundary F1 无法作门）。本计划内只产出预注册文档骨架，不跑实验。

## 治理与产出

- 每级跑前把 gate 阈值冻结进预注册 JSON（沿用 `artifacts/` 现行模式），跑后产出含源码 SHA/语料 provenance 的 artifact bundle
- 同步 [temporal spec](docs/specs/temporal-abstraction.md) 与 [evidence plan](research/eta/eta-segment-credit-evidence-plan.zh.md)
- 回滚：所有新代码为 evidence lane，不改任何 production WiringLevel；补课基底是独立 artifact，原始 Qwen 路径不受影响

## 成本预估

- 第一级：生成器 + 重跑约 1 天（扫描单臂约 1–2 小时）
- 第二级：语料生成数小时；LoRA continued pretraining 1–5 千万 token 在 MPS 上约数小时至一天；probe 训练分钟级
- 第三级：双臂扫描约 2–3 小时（与本轮同量级）
