## Phase 1 — Gate 11 四臂

四臂：

- `stateless`
- `correct-user-state`
- `swapped-user-state`
- `shuffled-history`

当前输入、source transition、共享 substrate fingerprint 与可见预算匹配。
状态只经 `MemoryStore`、`SemanticStateStore` 与
`OwnerHydrationStore` 公共 owner surface 写入、持久化和恢复。

Primary metric：

`continuity_composite = mean(callback, commitment, boundary)`

冻结门：

- correct - stateless 平均增益 `>= 0.20`
- correct - swapped 平均增益 `>= 0.20`
- correct - shuffled 平均增益 `>= 0.10`
- 三个 paired seed gain 的双侧 95% t-CI lower bound 均 `> 0`
- 每 seed settled transition count `= 510`
- constructor restart / hydration round-trip / delete / checkpoint rollback
  全通过
- cross-user read leakage、write leakage、key collision 均 `= 0`
- swapped state 不得误命中 target user 的 callback、commitment 或 boundary

失败则 verdict=`not-supported`，主张收缩为“共享模型 + 可持久化、隔离的
每用户状态”；机制/隔离门失败则 verdict=`invalid`。

## Phase 2 — Gate 5 longitudinal v2

沿用 v1 五臂及 owner：

- `nested-CMS(full)`
- `single-timescale`
- `no-ATLAS-replay`
- `no-PE-write-gate`
- `memory-only`

每个 arm/seed 每 10 条 transition：

1. `MemoryStore.save_to_backend()`
2. 丢弃当前 owner 实例
3. 用相同 arm 配置构造新 owner
4. `load_from_backend()` 并校验 checkpoint digest

Primary metric 与冻结门：

- locked `new_knowledge_absorption`
- locked `old_knowledge_retention`
- full 对所有 controls 在 `0.01` 容差内 Pareto 不劣
- full 相对 single-timescale 至少一维平均增益 `>= 0.02`
- 对应 paired seed gain 的 95% t-CI lower bound `> 0`
- cadence、matched parameter budget、lineage、frozen substrate、跨 session
  checkpoint、最终 rollback 全通过

失败则保持 Gate 5 `not-supported`，不得以调阈值或重跑 locked 续命。
