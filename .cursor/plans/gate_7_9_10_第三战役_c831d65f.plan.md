## 包 2：Gate 9 harness（从零建，两个子套件）

Owner 现状：M3 在 [packages/vz-temporal/src/volvence_zero/temporal/m3_optimizer.py](packages/vz-temporal/src/volvence_zero/temporal/m3_optimizer.py)，Titans/Hope PE-gate 在 [packages/vz-memory/src/volvence_zero/memory/cms.py](packages/vz-memory/src/volvence_zero/memory/cms.py)；两者都只有单测，无 matched 对照。

- **9a M3 optimizer suite**：预注册 non-stationary gradient 场景族（方向切换/尺度漂移/间歇反转），M3 对 `SGD / plain-momentum / Adam` 同预算对照；指标 overshoot、收敛时间、反向切换恢复、旧模式保持、计算成本。纯数值实验，CPU 分钟级。
- **9b PE-gated update suite**：在 Gate 8 已验证的 v2/v3 多 session 语料上，`pe-gated` 对 `no-update / always-update / random-gate`（同 seed 复现）；指标写入精度、无用写入、漂移、遗忘、收益、rollback 精确性。
- **预注册冻结（首次 Gate 9 run 前）**：seed 固定为
  `727 / 733 / 739`；9a 三场景固定为 direction-switch /
  scale-drift / intermittent-reversal，四臂各场景同 step budget。
  M3 primary 要求 tracking MAE 对每个 control 至少改善 `0.005`，
  overshoot 不劣于 `0.01`、settling/reversal recovery 不劣化、
  old-mode retention 不劣于 `0.01`，确定性状态成本不高于 Adam。
  9b 只消费 v3 `trace-train` owner plans（不再读取已消费的 Gate 7
  locked）；PE arm 对 always/random 的 write precision 与 unnecessary-write
  margin 均至少 `0.05`、benefit margin 至少 `0.01`、forgetting 不劣于
  `0.02`，并须优于 no-update benefit `0.01`。任一 lineage、frozen
  substrate 或 rollback 门失败则整体 `invalid`。
- 预注册失败语义：无稳定增益 → M3/Titans-Hope 降级为「实现候选/设计模式」，不得写成产品贡献（Gate 9 EXIT 原文）。
- 新脚本 `scripts/run_gate9_bounded_selfmod_evidence.py`，artifact `gate9_*`。DGD/真 Hope 自指递归是 backlog，明确不冒充。
- **2026-07-30 包 2 结果**：两套 mechanism gate 全绿，lineage、
  frozen-substrate 与 owner checkpoint rollback 无缺口；但 9a/9b 均
  `not-supported`。M3 与 plain momentum 的所有 primary 指标完全相同，
  且 tracking MAE 相对 SGD/Adam 分别低 `-0.203442 / -0.033642`；
  slow momentum 当前只作下游 signal，未带来 optimizer advantage。PE gate
  write precision=`1.0`、unnecessary write rate=`0.0`，但 held-out benefit
  相对 always/random 仅 `0.0000537 / -0.0000001`，未达 `0.01`。Gate 9
  按 EXIT 收缩为实现候选/设计模式；DGD/真 Hope recursion 继续 backlog。
  artifact：`artifacts/gate9_bounded_selfmod_20260730`。
