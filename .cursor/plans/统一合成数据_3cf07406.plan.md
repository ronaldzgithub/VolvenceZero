# 统一合成经验母语料 v1

## 1. 冻结边界与母 schema
- 新增 [`docs/specs/synthetic-experience-corpus.md`](docs/specs/synthetic-experience-corpus.md) 并登记到 [`docs/specs/00_INDEX.md`](docs/specs/00_INDEX.md)：该能力是离线数据工件，不新增 runtime slot/owner，不改 [`docs/DATA_CONTRACT.md`](docs/DATA_CONTRACT.md) 的运行时依赖图。
- 新建 proprietary [`packages/lifeform-synthetic-data/`](packages/lifeform-synthetic-data/)（模块 `lifeform_synthetic_data`）作为母语料唯一 owner；保持 [`packages/companion-standard/src/companion_standard/trajectory.py`](packages/companion-standard/src/companion_standard/trajectory.py)、[`packages/companion-trajgen/`](packages/companion-trajgen/) 和 held-out benchmark 不被扩宽或污染，`lifeform-evolution` 只消费派生视图。
- 以 frozen dataclass 为 SSOT，定义 `CorpusManifest / ScenarioBlueprint / ExperienceTrajectory / Session / Turn / LatentTruthFrame / SnapshotFrame / AnnotationRecord / ArtifactRef / QualityRecord`；提供严格反序列化、canonical JSON、稳定 SHA-256、JSON Schema 与 round-trip conformance。
- schema 明确分离三层证据：
  - `generator_truth`：人物私有状态、社会角色、目标/承诺/边界、环境事实与 FSM 转移，可作为硬标签；
  - `rendered_text`：LLM 仅按既定状态和 response contract 表达文本，不产生标签；
  - `runtime_observation`：从 `LifeformSession`/`BrainSession` 公开结果导出原始不可变快照及 hash，作为特征或学习轨迹，不冒充世界真值。
- 每条标注强制携带 ontology/version、target ref、owner/track/timescale/scope、source、confidence、evidence refs、adjudication 和 `training_use={target,feature_only,eval_only,quarantined}`。`MODEL_PREDICTION` 与 `EVALUATION_READOUT` 默认不可进入训练目标；不伪造 `HUMAN_ANNOTATION`。`z_t/beta_t` 只记录 owner 观测，不手工贴语义标签。

## 2. 设计 96 个场景
- 在 [`packages/lifeform-synthetic-data/src/lifeform_synthetic_data/scenario_packages/unified_v1/`](packages/lifeform-synthetic-data/src/lifeform_synthetic_data/scenario_packages/unified_v1/) 落 `manifest.yaml`、`ssot_fragment.json`、`scenes.yaml`、`test_suite.yaml`，并提供到现有 `vz-scenario-pack.v1`/Companion 场景格式的显式 adapter，避免把尚未对齐的两套 ScenarioPackage 当成同一契约；同时满足名称、路径引用、phase 顺序、negative routing 和 semantic-coherence 自检要求。
- 建立 16 个能力族，每族 6 个独立场景：关系连续性、rupture/repair、偏好与个性化、离开与重逢、边界/同意/自主性、目标与价值漂移、计划/承诺/open-loop、任务与工具执行、信念/不确定性/主动求证、情感支持与 regime 转换、多人身份与隐私、ToM/common-ground/group、记忆时间尺度与慢反思、环境 outcome 与延迟信用、学徒/ingestion/教学反馈、安全/依赖/jailbreak/危机场景。
- 每族固定 4 train + 1 val + 1 test blueprint；同一 persona、latent arc、翻译/paraphrase、counterfactual sibling 永不跨 split。跨场景正交覆盖中英双语/混合语、短中长 horizon、显式/隐式意图、成功/部分成功/失败/修复、身份/受众交换、延迟 outcome、噪声与矛盾。
- 场景选择只按显式 scenario id 或语义分类输出；不从文本关键词路由。每个场景声明可观察事实、私有真值、允许的 regime 集、owner 预期变化、response contract、反事实故障注入与安全限制。

## 3. 实现可恢复的生成管线
- 先由确定性 world/FSM compiler 生成事件、状态转移、分支和硬标签，再调用集中于 `prompts/` 的模板与 `schemas/` 的 JSON Schema 渲染 user/assistant 文本；模型输出只允许回填带稳定 ID 的文本槽，不能修改真值。
- 提供三种层级：零成本 structural/golden；高吞吐 rendered corpus；真实 `LifeformSession` 逐 turn live-through。live-through 仅消费公开快照并复用现有 [`packages/lifeform-evolution/src/lifeform_evolution/trace_collector.py`](packages/lifeform-evolution/src/lifeform_evolution/trace_collector.py) 的读数语义，不直接调用任何 owner。
- CLI 支持模型池、seed、并发、分片、append-only journal、幂等 resume、具体 HTTP 错误重试、失败 quarantine、调用/Token/费用统计、用户提供的 rate card 与 `--max-cost-usd` 硬上限；鉴权/配额错误 fail loudly，绝不静默退回假数据。
- 输出 `master/*.jsonl.gz`、content-addressed snapshot sidecar、可选 Parquet、run manifest、shard checksum、prompt/model/scenario/git fingerprint 和失败账本；大数据写入 gitignored 的 [`data/synthetic/unified_v1/`](data/synthetic/unified_v1/)，只提交 schema、场景与小型测试 fixture。

## 4. 从母语料派生训练/标注视图
- 所有视图由 master hash 可逆追踪，不维护第二份真值：
  - `relationship_encoder`：投影成现有 `companion_standard.InteractionTrajectory`；标签仍只来自 FSM/world truth；
  - `expression_sft`：只保留 response contract 一致且通过硬门禁的 teacher-rendered 文本；
  - `semantic_owner` 与 `social_cognition`：9 类语义 owner、身份/role/ToM/common-ground/group 的结构化 proposal/状态目标；
  - `memory_retrieval`：由事实时间线和 subject/audience scope 生成 query/positive/hard-negative；
  - `temporal_ssl` 与 `internal_rl`：仅从 live-through 的 snapshot/segment/PE/credit 链导出，强化发生在 `z_t` 空间；
  - `evaluation_only` 与 `human_review_queue`：judge/readout、盲审样本、待人工 adjudication，物理隔离于训练视图。
- 每个投影视图拥有独立 split manifest；关系编码器继续执行更严格的 scenario-family 隔离，Companion Bench held-out 永不加载。

## 5. 质量门禁与首批 10k+ 数据
- 添加 schema/immutability/hash、场景全覆盖、无孤儿 path、split 零泄漏、label lineage、judge 不入训练、held-out/版权语料禁止导入、PII/secret、精确与近重复、语言/长度/风险/标签分布、resume 幂等、API 故障等测试；在 [`tests/contracts/test_import_boundaries.py`](tests/contracts/test_import_boundaries.py) 补离线数据层只读公共 facade 的边界守门，并补齐现有文档已宣称但仓库缺失的 trajgen/encoder/standard conformance 守门测试。
- 分阶段执行并每阶段产审计报告：96 条 structural golden → 96 条 LLM pilot → 768 条扩容验证 → 10,240 条 rendered master（64 train×128、16 val×64、16 test×64）→ 1,024 条分层抽样 live-through（768/128/128）。任一硬门禁失败即停止扩容，失败样本进入 quarantine，不缩分母洗数据。
- 生成 dataset card、字段字典、annotation handbook、coverage matrix、费用与模型分布报告；semantic judge 仅做 `eval_only` 一致性审计。完整 LLM 批量运行前先输出基于实际端点/rate card 的费用预估并受硬预算上限约束。
