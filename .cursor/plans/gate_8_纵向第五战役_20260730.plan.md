## 目标与边界

本战役只把已经获得 `causal-supported` 的 Gate 8 wake/sleep 命题扩展到
fresh real-substrate、跨 session、每 seed 至少 500 条 settled transitions。
它不重跑 Gate 5，不修改 Gate 11 v1/v2，不重开 Gate 1/2/4/6/7/9/10，也不
授权 production/live promotion。

Gate 11 的 human-anchor debt #51 仍需外部盲评者；本战役不生成或代填人类
关系质量标签。

## Phase 0 — 冻结 source admission

- source：既有 immutable `gate11-longitudinal-settled-trace.v2`
- source root：`artifacts/gate11_longitudinal_source_v2_20260730`
- seeds：`1201 / 1213 / 1223`
- 每 seed：全量 `510` settled transitions，共 `1530`
- substrate：strict-local frozen `Qwen/Qwen2.5-0.5B-Instruct`，
  fallback deny
- source capture 与 Gate 8 consumer state 严格分离；Gate 8 是该 source
  的新 consumer，不重写 source、不重新标注 source，也不把此前 Gate 11 /
  Gate 5 的 verdict 当作 Gate 8 outcome
- consumer 必须验证 aggregate admission、逐行 digest、registry lineage、
  settled count、frozen substrate、fallback/mutation 为零

开发披露：冻结前仅用 seed 1201 的前 20 条做过一次旧 v1
non-cross-session adapter 可运行性 probe；它不产生正式 artifact、不进入
阈值选择、不进入 paired-seed 统计。所有效应阈值沿用 Gate 8 v1 的 `0.02`，
没有按该 probe 调整。

## Phase 1 — 四臂与跨 session 协议

四臂保持不变：

- `sleep-consolidation`
- `no-sleep`
- `memory-only-sleep`
- `policy-only-sleep`

每条 source transition 只通过正式 `SessionPostSlowLoopQueue`、
`SessionPostWritebackRequest`、memory owner 与 temporal owner surface
进入 slow loop。下一 session probe 只在对应 closed-session job 完成后执行；
所有 arm 使用同一 probe，sleep 不向 serving prompt 注入额外 token。

每 seed 的 510 条按时间顺序分成 51 个 consumer session。前 50 个 session
结束时必须：

1. memory owner 保存到 `FileSystemPersistenceBackend`；
2. temporal owner 导出 immutable parameter snapshot 并写入独立 filesystem
   checkpoint；
3. 丢弃两个 owner 实例并重新构造；
4. 从 checkpoint 恢复并核对 before/after fingerprint。

四臂 × 三 seed 共消费 `6120` arm-transitions，且每 arm/seed 必须有
`50` 次 constructor restart。

## Phase 2 — 冻结指标与判词

Primary：

- `cold_start_loss_reduction_vs_no_sleep >= 0.02`
- `callback_consistency_gain_vs_no_sleep >= 0.02`
- `delayed_payoff_gain_vs_no_sleep >= 0.02`
- full 相对两个 single-owner control 的最小 delayed-payoff margin `> 0`
- 上述四个 paired-seed gain 的双侧 95% t-CI lower bound 全部 `> 0`

Safety / integrity：

- 每 arm/seed settled transition count `= 510`
- 每 arm/seed constructor restart count `= 50`
- source lineage 与 owner writeback lineage coverage `= 1.0`
- prompt token increment、duplicate execution、turn-latency contamination、
  frozen substrate mutation、persistence mismatch、rollback mismatch全为 `0`
- full owner-state drift `<= 0.50`
- no-sleep 不得写 memory 或 temporal；memory-only 不得写 temporal；
  policy-only 不得把 memory 写进 primary memory owner

任一 integrity gate 失败则 `invalid`；integrity 全绿但 primary 任一失败则
`not-supported`；全部通过才是 `longitudinal-supported`。失败后不得以相同
source、机制或阈值重跑 locked consumer。
